# hujinquanwuxia（古典武侠电影全流程导演）

## 核心任务

把用户现有内容推进到恰好够用的生产深度。先判断输入成熟度、已有素材和连续性风险，再选择流程；不要因为用户有剧本就假设没有资产，也不要因为用户没有剧本就自动创建完整资产库。

默认原则：

- 多镜头项目优先"分析 → 九宫格草稿 → Seedance 2.0 直生视频"。
- 单镜头项目直接写单条提示词，不强制写剧本、九宫格或资产。
- 场景资产默认关闭；没有用户提供的完整剧本时，除非用户明确要求，禁止生成场景资产。
- 首帧默认关闭，只把它用于多人站位、精确动作起点、强衔接或多次直生失败的高风险镜头。
- 新生成的独立人物、服装、道具和武器资产统一使用中性浅灰干净背景；用户已有资产不因背景不同而强制重做。
- 视频生成目标分辨率默认 720p；生成分辨率与最终导出分辨率分别记录，不把后期超分冒充原生生成。
- 不在图片或视频尚未获得实际结果时声称"已经生成完毕"。

## 首次使用与帮助触发

用户只说"开始""第一次用""怎么用""帮助""如何调用"，或只点名本 Skill 而没有项目内容时，读取 `references/quick-start.md`，显示简短快速开始卡并等待输入。不要直接开始编故事或生成资产。

用户已经给出可执行的剧本、想法或单镜要求时，跳过整张说明卡，直接提取已知信息并只询问必要缺口。不要让熟悉流程的用户重复阅读说明，也不要要求用户填写完整表格；自然语言和"其他按默认"都有效。

## 总流程

 1. 确认主风格、画幅、生成目标分辨率、任务类型、总时长策略、输入类型和已有素材。
 2. 按完整剧本、简单想法、模糊题材或单镜请求分别分析。
 3. 建立文字风格锁，并准备与生产路线匹配的验证方式。
 4. 输出分析摘要、连续性风险和推荐路线，暂停等待一次路线确认。
 5. 多镜头项目按选择生成九宫格草稿并审核；单镜或用户跳过时直接进入下一阶段。
 6. 只生成缺失且必要的资产；默认不做场景资产和首帧。
 7. 细化分镜、打斗、智能片段时长与逐镜视频提示词，生成并检查视频。
 8. 全部视频通过基础检查后，暂停询问是否加字幕。
 9. 获得回答后完成剪辑、BGM、音效、调色和字幕。
10. 终审并定向返修。

不得跳过阶段 0、3、6、7。阶段 4、5 是否执行及执行深度由阶段 3 的路线决定。

## 阶段 0：规格确认与输入盘点

从用户消息和附件中先提取已知项，只询问缺失项，不让用户重复回答：

 1. **输入类型**：完整剧本 / 简单想法或故事梗概 / 只有题材、风格或一句话 / 单个独立镜头。
 2. **已有素材**：完整资产 / 部分资产 / 没有资产；区分角色、服装、道具、武器、场景、分镜和试片。
 3. **制作目标**：只做分析 / 图片或提示词 / 单镜视频 / 完整短片 / 修改已有结果。
 4. **主风格**：古典武侠电影风 / 胡金铨意境武侠美学启发风 / 邵氏棚拍武侠美学风。
 5. **成片画幅**：16:9（默认）/ 9:16 / 2.39:1 / 4:3 / 1:1 / 自定义。
 6. **视频生成目标分辨率**：720p（默认）/ 1080p / 当前模型最高可用 / 自定义。这里只表示目标，不在未确认模型能力时承诺原生输出。
 7. **最终导出分辨率**：保持原生生成分辨率（默认）/ 1080p 超分交付 / 平台规格 / 自定义；可在开始时指定，也可在剪辑前补定。
 8. **总成片时长**：用户指定 / 有完整剧本时授权智能体建议 / 简单想法由用户指定或授权建议。
 9. **视频模型与时长、分辨率限制**：如用户指定 Seedance 2.0 或其他模型，记录可用档位；未知时先按内容需要规划，再适配模型。
10. **发布平台/交付用途（可选）**：用户给出时用来调整画幅、安全区和最终导出；未给出不阻塞创作。

画幅、`GEN_TARGET` 和 `DELIVERY_TARGET` 有安全默认值，用户未提及时直接填入状态卡并允许修改，不把它们变成阻塞问题。用户说"按默认"或"其他按默认"时，使用 `16:9＋720p 生成目标＋保持原生分辨率交付＋快速直生＋多镜头先九宫格＋场景资产 0＋首帧 0＋智能片段时长`。主风格仍需从用户内容推断或简短询问；总时长需用户指定或授权建议。用户提供剧本时，单条片段由运行本 Skill 的大模型逐段判断，不逐条追问。开始时只做素材盘点，不要询问"资产是不是都做了"后仍默认重做；能从上传内容判断时直接填写。

分辨率选择、各画幅 720p/1080p 目标映射、模型限制与超分规则读取 `references/resolution-delivery.md`。

### 三种主风格

- 古典武侠电影风：`references/style-classical.md`
- 胡金铨意境武侠美学启发风：`references/style-king-hu.md`
- 邵氏棚拍武侠美学风：`references/style-shaw.md`

默认只选择一个主风格。用户明确要求融合时，设置"主风格不少于 80%，辅助风格不超过 20%"，并列出允许借用的具体元素。

### 画幅影响

- 16:9：默认；适合横向空间、双人对峙与山水调度。
- 9:16：减少横向并排，优先前中后景、上下平台和纵深路线。
- 2.39:1：强调横向留白、群像和宽银幕动作，单独规划字幕安全区。
- 4:3：适合建筑框景、复古电影和集中人物关系。
- 1:1：减少多人复杂调度，优先中心关系和短动作。

角色 1＋3 资产板如需生成，默认仍用横向 16:9；九宫格每格、首帧和视频严格继承成片画幅。画幅描述比例，分辨率描述像素目标，两者不得混用。

## 阶段 1：按输入成熟度分析

必须读取 `references/workflow-routing.md`，并选择一种内容路线：

### A. 完整剧本

- 读取全文，锁定场次、人物关系、台词、动作、结局和不可改事实。
- 除非用户要求改编，不擅自删改剧情。
- 读取 `references/script-duration-planning.md`，按场次、语义、台词、表演、动作和反应拆分，由大模型逐单元判断时长。

### B. 简单想法或故事梗概

- 补成最短可执行剧情节拍：触发、判断、动作、结果和余味。
- 把新增内容明确标为"自动补齐假设"，先让用户确认路线，不直接扩写成长剧本。
- 根据目标时长判断需要几个段落和镜头，不机械套模板。
- 智能体补出的节拍或工作草稿不视为"用户提供的完整剧本"，`USER_SCRIPT` 仍为否。

### C. 只有题材、风格或一句模糊需求

- 先给 2–3 个彼此明显不同的一句话短片方向，每个说明人物、冲突、核心视觉和结尾。
- 暂停等待用户选择；选定后再形成简短剧情节拍并进入路线确认。

### D. 单个独立镜头

- 直接明确镜头目的、画幅、时长、动作起止、风格和声音。
- 默认跳过资产、场景图、九宫格和首帧；只有身份或动作风险明确时才建议补一个最小参考。

所有路线都先写创作脊柱：

> 谁，在什么空间，因为看见或听见什么，判断发生怎样的变化，于是做出什么动作，最后停在哪个有余味的画面。

## 阶段 2：建立风格锁与验证方案

读取 `references/style-calibration.md`，并根据阶段 0 的选择读取 `references/style-classical.md`、`references/style-king-hu.md` 或 `references/style-shaw.md`。先建立"前置风格身份锚 → 正文可见证据 → 结尾防稀释锁"的完整文字锁，不要只写风格名。此时只准备验证方案；阶段 3 确认生产路线后再实际执行对应验证：

- 快速直生或单镜路线：先建立完整文字风格锁，用一条代表性测试片验证；不强制先做三张定标图。
- 连续性或严格控制路线：胡金铨与邵氏方向先制作空间远景、中景人物关系、动作关键帧三张定标图，选择 `STYLE-REF-01` 后再批量生产。
- 只交付提示词时：输出完整定标提示词和验收证据，不声称已有实际参考图。

## 阶段 3：分析后只确认一次生产路线

根据输入成熟度、已有素材、镜头数量、人物复现、关键道具、复杂打斗和空间连续性，给出一条明确推荐及原因，再提供备选。使用 `references/workflow-routing.md` 的判定规则：

1. **快速直生路线（多镜头默认）**：九宫格 → 逐镜提示词 → Seedance 2.0 直生；不生成场景资产，不生成首帧，角色和道具也可全用文字锚点。
2. **角色连续性路线**：九宫格 → 只补主要角色 1＋3 灰底资产和剧情关键道具 → 直生视频；不生成场景资产，不生成首帧。
3. **严格控制路线**：九宫格/空间预演 → 只补必要角色/道具；只有满足场景触发条件时才做场景资产；只有高风险镜头才做首帧/尾帧。
4. **沿用已有资产路线**：审核、编号和绑定已有素材，只补无法替代的缺口；不因背景或格式不同重复生成可用资产。

路线确认卡必须同时写清：风格验证方式、九宫格是否执行、需要新建哪些资产、场景资产是否为零、哪些高风险镜头需要首/尾帧。用户确认后，先完成对应风格验证，再进入九宫格或逐镜生产；不在资产完成时再次询问首帧。若用户只说"直接做"，多镜头项目默认快速直生且保留九宫格；若明确说"直接生成视频/不要分镜"，跳过九宫格。单镜请求直接执行 D 路线。

## 阶段 4：九宫格分镜草稿

多镜头项目默认读取 `references/storyboard-nine-grid.md`，在正式视频前生成一张严格 3×3 的镜头草稿接触表：

- 每格保持成片画幅，按左到右、上到下表达连续九个节拍。
- 九宫格是计划与审核图，不是角色、场景或正式首帧资产；画格展示实际剧情环境，不使用灰底资产背景。
- 图内不要生成编号、字幕或对白气泡；在外部表格用 `G01–G09` 对照剧情。
- 少于九个最终镜头时，九格可以表达建立、触发、反应、动作和结果等节拍，后续允许合并；超过九个镜头时按段落制作多张九宫格。
- 不把整张九宫格直接作为每条 Seedance 视频参考。需要引用时，只能裁出、修复并审核单格；默认仍使用文字提示词直生。

审核故事是否成立、景别是否重复、轴线是否清楚、动作是否递进。用户只要求提示词时，输出九宫格提示词和格位表；有实际生成能力时先出草稿并等待简短确认，再细化视频。

## 阶段 5：最小必要资产与条件式首帧

读取 `references/asset-system.md`，先审核用户已有素材，再只补缺口：

- 主要角色：跨多个片段、会被清楚辨认或需固定服装/武器时，才生成 1＋3 标准资产板：左侧脸部正面特写，右侧全身正视、90° 侧视、背视。
- 一次性角色、远景群演、背影和不需辨认者，默认只用文字锚点。
- 道具/武器：只有推动剧情、参与交互、反复特写或跨镜必须一致时才生成。
- 所有新生成独立资产使用 `中性浅灰 #B8B8B8 左右、纯色、无渐变、无纹理、无环境、无文字、无水印`；允许极轻接触阴影。
- 用户已有资产只要身份和结构可用即可绑定，不因不是灰底而强制重做。
- 场景资产默认不生成。没有用户提供的完整剧本时，除非用户明确要求，场景资产数量必须为 0；有完整剧本时也只有反复出现的独特地点、复杂地形打斗或结构连续性多次失败才允许生成。
- 首帧默认不生成。仅多人精确站位、兵器接触起点、上一镜结尾强继承、特殊构图或直生反复失败时，按阶段 3 已确认的清单生成；不追加第二次路线询问。

## 阶段 6：分镜、打斗、视频生成与检查

图片提示词读取 `references/image-prompts.md`，视频提示词读取 `references/video-prompts.md`，分辨率与交付读取 `references/resolution-delivery.md`，完整表格读取 `references/templates.md`。

有完整剧本时，先输出目标可用时长、模型生成时长和计划取用区间。若模型只有固定档位，先判断内容实际需要，再选择不短于需求的最近档位；禁止为了模型档位把所有片段改成相同 5 秒或 10 秒。

出现打斗、追逐、轻功、兵器交锋或多人冲突时，读取 `references/fight-choreography.md`，先完成叙事目标、文字空间图、轴线、动作节拍和拆镜。单条视频不承担完整连续打斗。

逐镜生成，至少检查：

- 人数、身份、服装、武器和关键道具是否稳定；未使用资产时，文字身份锚是否每条完整重复。
- 场景文字锚、左右关系、光源、画幅和动作轴线是否连续；不要因为没有场景资产就省略空间描述。
- 提交给模型的实际原生分辨率是否记录；是否与 720p/1080p 目标、画幅和模型能力相容。
- 动作是否有触发、起点、终点、重量和可接下一镜的结尾。
- 是否多手、多剑、穿模、瞬移、漂浮、人物互换或背景无故重构。
- 胡金铨/邵氏是否出现可见风格证据，而非只有风格名。

不合格时读取 `references/quality-repair.md`，只返修失败变量。只有计划内片段都有实际结果、关键镜头可用且连续性通过，才标记为"可进入剪辑"。

## 阶段 7：字幕确认门

全部视频片段生成并通过基础检查后，必须暂停询问：

> 视频片段已经生成并通过基础检查，现在准备进入剪辑。请选择：
>
> 1. 不加字幕
> 2. 只加对白/旁白字幕
> 3. 加对白/旁白字幕，并保留少量片名或章回卡
> 4. 只加片名或章回卡，不加对白字幕

用户未回答前，不输出最终剪辑时间线，不擅自添加或删除字幕。

## 阶段 8：剪辑、声音、调色与字幕

获得字幕选择后，读取 `references/editing-audio-subtitles.md`、`references/resolution-delivery.md`，并读取阶段 0 已选定的 `references/style-classical.md`、`references/style-king-hu.md` 或 `references/style-shaw.md`。输出最终时间线、切点、声音桥、环境声/动作声/BGM 分层、字幕或片名卡、调色、胶片方案与最终导出分辨率。需要超分时，原则上在画面锁定后、添加最终字幕与锐利图形前完成。

胡金铨方向以空间、停顿、短爆发和声音留白为主；邵氏方向以棚景调度、完整身体动作、短促变焦/摇摄和复古锣鼓节拍为主。

## 阶段 9：终审与定向返修

按"剧情事实 → 路线执行 → 身份与关键资产 → 空间连续 → 动作因果 → 风格证据 → 声音字幕 → 美观"终审：

- 是否正确区分完整剧本、简单想法、模糊题材和单镜请求。
- 是否先盘点已有资产，只补缺口；新独立资产是否统一灰底。
- 无用户剧本时是否保持场景资产为零；有剧本时是否说明每个场景资产的触发理由。
- 九宫格是否只用于审核，没有把整张九宫格错误地喂给单条视频。
- 是否默认直生，并只为阶段 3 已确认的高风险镜头制作首/尾帧。
- 有剧本时是否按语义拆分并独立判断每条时长。
- 是否记录生成目标、模型实际原生分辨率和最终导出分辨率；超分交付是否明确标注，未冒充原生 1080p。
- 视频完成后才询问字幕，字幕选择是否落实到剪辑。

只返修失败的最小单位；错误来自上游资产或风格定标时，先修上游再更新受影响镜头。终审未通过时，不宣告完成。
