# 新中式国潮 TVC（neo-chinese-aesthetic-tvc）

## 一、国潮子类型（从上传的产品识别子类型，拿默认；美学基调统一为新中式国潮）

本 skill 只做**新中式国潮**这一种视觉语言，不做欧美时尚片 / 赛博科技感等其他风格。以下按产品所属子类型给默认特点，但**色彩、纹样、器物、造型语言一律收拢到新中式国潮**（水墨留白、飞檐斗拱、榫卯窗棂、云纹/回纹/缠枝纹、宣纸绢帛、中国红与国潮金、瓷器漆器、书法印章、丝绸刺绣）。**置景偏好「潮」的一面**：优先让这些东方元素与未来主义/极简/银白/镜面/金属质感（不锈钢、雾面金属、亚克力透光、悬浮结构、极简大留白、冷光）碰撞出新意，而非纯古典复刻——传统符号打底，现代材质点睛。

- **茶饮 / 白酒 / 传统食品** — 特点：茶烟氤氲、酒液挂杯、器皿特写（茶盏/杯盏/瓷罐）、木质/竹编场景、慢镜头意境；默认创意手法：情感 + 演示；参考：茅台、观夫山、茶里
- **美妆 / 国货护肤** — 特点：微距质地流动、东方肤感、妆造融入国风元素（发簪/绒花/戏曲妆容意象）、奢华留白；默认创意手法：演示 + 情感；参考：花西子、毛戈平、观夏
- **服饰 / 新中式穿搭** — 特点：改良汉服/新中式褂衫、面料垂坠特写、庭院/园林走位、写意运镜；默认创意手法：故事 / 情感（视听奇观风格）；参考：盖娅传说、密扇、朋克大爷
- **家居 / 香氛 / 文创** — 特点：榫卯结构特写、香炉烟雾、宣纸/木质/铜器质感、静谧留白；默认创意手法：情感（视听奇观风格）；参考：观夏、失物招领
- **珠宝 / 配饰** — 特点：金银錾刻、玉石光泽、慢速环绕特写、暗调打亮细节；默认创意手法：演示 + 情感；参考：老凤祥、梦金园
- **地产 / 文旅 / 空间体验** — 特点：飞檐轮廓航拍、园林借景、光影漏窗、生活方式想象；默认创意手法：情感 / 故事；参考：中式合院项目、古镇文旅
- **国货 3C / 潮玩** — 特点：产品本体嫁接国风纹样、悬浮展示 + 水墨转场、传统与现代对撞；默认创意手法：演示 + 情感

> 定了子类型即拿到：默认特点 + 建议创意手法 + 一组旋钮默认档位（见第三节括注）；**东方美学基调与固定风格种子对所有子类型统一生效**，客户有特殊要求可覆盖具体细节，但不脱离新中式国潮的大方向。

## 二、五个维度（与用户对话逐项确认）

TVC 商业广告片的 5 个维度（制作方式不再询问，固定实拍）。定品类后多数已有默认值，对话只需补齐/修正，不重复问已知项；**视频比例与分辨率无默认值，必须问用户**。

**1. 广告目的**：产品 · 品牌 · 形象 · 促销 · 公益
→ 决定信息密度与收尾落点：促销=强 CTA；品牌/形象=主张/slogan 收尾；产品=卖点+CTA。（默认不加 logo，收尾以 slogan 字幕或画面/产品自然收束为主。）

**2. 创意手法**（＝ prompt 生成骨架）：故事 · 情感 · 演示

- **故事**：完整剧情，建立 → 冲突 → 解决，产品融入情节。
- **情感**：情绪弧打动人，建立人物/处境 → 情绪高点 → 产品作为解法 → 落主张。用 `{{Mixed N}}` 锁角色。
- **演示**：卖点直给，痛点/场景 → 产品登场 → 一镜一卖点 → 效果呈现 → slogan/CTA 收尾（默认不加 logo）。产品每镜清晰。

> 「视听奇观 / 时尚片」不是单独手法，而是**高制作美学风格**（运镜密集、美学优先、慢动作、大量留白），常叠加在 故事/情感/演示 上（服饰、美妆、珠宝、家居香氛），靠第三节拆解要素堆出来。

**3. 视频时长**：15s · 30s · 60s
→ 决定分镜数（15s≈3–5 镜 / 30s≈6–9 / 60s 更多），并触发**按 15s 分段生成**（见工作流 Step 4）。

**4. 视频比例**：16:9 · 4:3 · 9:16 · 3:4
→ 决定成片画幅（同时用于场景氛围图与 Seedance 生成的 `--ar`）：16:9 横屏（TV/OTT/横版）、9:16 竖屏（社媒竖版，前 3 秒更狠）、4:3 复古方屏、3:4 竖版。此项**必须让用户选**。需要多版时可一稿出双版（如 16:9 + 9:16）。

> **制作方式不再作为维度询问**——本 skill 一律走**实拍风格**（电影感商业片基底 + 新中式国潮实拍质感），不做动画/CG，风格锁定句固定为实拍基底。

**5. 生成分辨率**：480p · 720p · 1080p
→ 决定 SD2 调用时的输出分辨率参数，直接影响成片清晰度与生成耗时/成本；此项**必须让用户选择**，不套默认。

## 三、拆解要素（7 个旋钮 · 选项菜单）

每个维度选一档；斜体括注是「按品类默认」。

**1. 灯光设计**

- 光源：自然光 / 棚拍人工光 / 混合光
- 方向：顺光 / 侧光 / 侧逆光 / 逆光 / 顶光 / 底光
- 布光：主光 Key、辅光 Fill、轮廓光 Rim/Edge、背光 Backlight、发丝光、体积光/丁达尔 Volumetric、美妆光 Beauty dish、入画实用光源 Practical（灯笼/烛火/漏窗光）
- 色温：冷调(蓝白) / 暖调(金橙) / 中性 / 冷暖对撞
- 特殊光效：漏窗光斑、烛火烟雾体积光、绢纱柔光、水墨式明暗晕染、耀斑 lens flare
- *默认：茶饮/白酒/食品=暖调烛光感+体积光；美妆/国货=柔光通透暖调+发丝光；服饰=自然窗光+绢纱柔光；家居/香氛=暖木质光+烟雾体积光；珠宝=暗调侧逆光打亮细节；地产/文旅=暖柔自然光+漏窗光斑*

**2. 画面色调**

- 色温：暖调 / 冷调 / 中性 / 冷暖分离 split-tone
- 色调：水墨黑白灰、中国红与国潮金对撞、莫兰迪低饱和国风灰、青绿山水冷调、宣纸米白低饱和、复古做旧绢帛色
- 饱和度：高饱和(节庆/红金) / 标准 / 低饱和(水墨/文人) / 去色单色(水墨)
- 质感叠加：宣纸纹理、绢丝柔光晕、烟雾氤氲、胶片颗粒
- *默认：茶饮/白酒/食品=暖调+中国红与金对撞；美妆/国货=低饱和暖调+宣纸质感；服饰=水墨低饱和+绢丝柔光；家居/香氛=莫兰迪国风灰；珠宝=暗调高对比+金属光泽；地产/文旅=青绿山水冷调*

**3. 镜头语言**

- 运镜：固定、推/拉、摇 pan、移 dolly、升降 crane、环绕 orbit、跟拍 tracking、手持、稳定器、FPV 穿越
- 景别：微距/大特写、特写、近景、中景、全景、大远景、航拍
- 角度：平视、仰拍、俯拍、顶视平铺、荷兰角(倾斜)
- 构图：居中对称、三分法、框架式、大量留白、满构图、前景遮挡
- 镜头特性：广角畸变、长焦压缩、移轴微缩、鱼眼
- *默认：美妆/国货=微距+缓慢 orbit；服饰=庭院移动+跟拍+留白构图；珠宝=微距+缓慢环绕；茶饮/白酒=顶视+升格微距；地产/文旅=航拍+框架式构图（漏窗/门洞）*

**4. 音效音乐**

- **BGM 固定为"融合乐"，不开放选择**：「中国古典乐器演奏的电子音乐」——古筝/琵琶/笛箫/二胡/编钟等**传统乐器真实音色**为旋律主体，**深度融合现代电子**（节拍/合成器/低频律动/采样），是国风 × 电子的 fusion，非纯民乐、非纯电子，两者交织。关键词：`traditional Chinese instruments (guzheng/pipa/dizi/erhu) fused with modern electronic music, neo-Chinese electronic fusion`
- **BPM 跟片走**：由成片实际节奏/调性定——明快/卡点片偏快强律动，舒缓/情感片偏慢有空间感，片内可变速，不设固定 BPM。
- **生成时机**：**SD2 生视频阶段完全静音**——不生成 BGM、不生成音效/环境音、不生成旁白，只出纯画面；BGM 与旁白全部放到 Step 6 后期合成时加入。
- 音乐功能：驱动卡点 beat-synced、氛围铺底、情绪烘托——按子类型和创意手法选功能档位，但"古典乐器 × 电子融合"的音色基底不变。
- **不做音效层**：成片不含任何音效/环境音（SD2 静音、后期也不加音效）；成片声音只有 **BGM + 旁白（如有）** 两层。
- 人声：男/女声旁白 VO、无人声
- 混音：BGM + 旁白分层混音，旁白清晰度优先（BGM 不可盖过人声）。
- *默认：茶饮/白酒=国风电子融合（偏舒缓律动）；美妆/国货=国风电子融合（电子感更强、节拍清晰）；服饰/家居=国风电子融合（丝竹音色+柔和电子铺底）；珠宝=稀疏国风电子融合；地产/文旅=国风电子融合（大气、低频律动）+旁白*

**5. 剪辑节奏**

- 切换速度：快切、中速、慢长镜、一镜到底
- 节拍：卡点踩鼓点、自由叙事节奏
- 转场：硬切、淡入淡出、匹配剪辑 match cut、无缝变形 morph、遮挡甩切 whip、跳切 jump cut、液体/光效转场（**禁止叠画/叠化**）
- 时间处理：正叙、倒叙、平行剪辑、蒙太奇、定格强调
- 特殊手法：定格 freeze frame、变速 speed ramp、故障 datamosh
- *默认：茶饮/促销=中速卡点；服饰/家居/珠宝=慢长镜写意；地产/文旅=慢起渐快*

**6. 演员模特**

- **有无人物：强制有人像介入**——不管什么子类型、什么创意手法，每条广告都必须有人的存在（可以是正面出镜的模特，也可以只露手部/局部肢体，比如倒茶的手、佩戴首饰的动作、拂过面料的指尖），**不允许纯产品无人化呈现**。
- 人群定位：年轻、都市白领、家庭多代、儿童、运动人群
- 气质风格：高级冷感、亲和温暖、力量运动、潮酷街头、清纯邻家
- 多元：本土、国际化混搭、多元族裔
- 表演基调：克制写实、生活流、戏剧夸张（**表情务必自然可信，禁止夸张怪异表情**）
- 情绪焦点：面部微表情、眼神、肢体动作、互动关系
- 服装（按子类型）：贴合新中式国潮调性——**统一以改良汉服/新中式褂衫/立领盘扣等为基底，颜色取中国红、国潮金、青绿、水墨灰**；美妆 = 有一定露肤度但不暴露、妆造融入国风元素（发簪/绒花）；服饰 = 高级新中式成衣、面料垂坠感强；珠宝/家居/地产 = 得体新中式生活装
- *默认：美妆/国货=东方高级脸+面部微表情+**皮肤光泽是重点**；服饰=新中式造型+肢体仪态；地产/文旅=多代家庭；茶饮/白酒/珠宝=以**手部/局部人物动作**为主介入（如执壶倒茶的手、佩戴首饰的动作），器物/产品仍是视觉主角，但每镜保证有人的存在*

**7. 故事类型**

- 叙事类型：强叙事(完整剧情) / 弱叙事(氛围奇观串联) / 无叙事(纯展示)
- 结构：三段式、线性、非线性蒙太奇、单点演示、问题—解决
- 视角：第一人称、旁观者、产品视角、多线并行
- 题材原型：生活片段、英雄旅程、before/after 对比、证言代言、演示 demo、品牌宣言 manifesto
- 落点收尾：产品 hero、主张/slogan 字幕（有 slogan 时用视频模型直出）、CTA（**默认不加 logo 定版**，除非用户明确要求）
- *默认：地产/文旅=温情三段式；服饰=意境线性叙事；美妆/珠宝/茶饮=弱叙事(氛围奇观串联)；家居/香氛=弱叙事或纯展示*

## 工作流

### Step 1 · 用户上传产品

用户上传产品图（或产品描述 / 参考片）。从产品识别：所属子类型（查第一节表）、产品形态/材质/卖点、是否需要 `{{Mixed N}}` 角色。拿到子类型即带出默认特点 + 建议创意手法 + 旋钮默认档位。
**【强制步骤 · 不可跳过】上传后随即生成两张产品锚点图**（后续所有分镜产品一致性的基础）：**必须以【用户上传的产品图】作参考图（image reference / 图生图），绝不凭空文生图**——把原图喂给生成模型（建议 model14 保真），据真实外形/颜色/材质/比例/品牌标生成；多张则全部喂入。**白底、16:9**，作为锚点 `{{产品三视图}}`（正/侧/背）+ `{{产品细节图}}`（按功能取关键细节，如护肤品=瓶身/泵头/质地）。两张缺一不可，生成后与原图比对，外形/配色/logo 对不上就重出；进 Step 2 前须已产出这两张。后续分镜产品画面一律以此为准。

> 若**只给文字描述、无产品图**：先告知"只能按描述文生图、可能与真实产品有出入"，追问关键外观后再生成；用户补传图后须重做。
>
> **地产/酒店等"空间即产品"品类**：无实体产品，改让用户**上传 5–8 张实景图**（或 skill 虚拟生成 5–8 张，按 16:9），作为 `{{空间实景}}`——**替代产品三视图，并同时充当场景锚点**。后续分镜空间/布景/光线一律以此为准；空间本身无人，但仍须选定人物形象，让人以生活方式场景（漫步/品茶/伏案）出现，不通篇空镜。
>
> **反推参考片**：先 `scripts/extract_frames.sh` 抽帧读规格（前 3 秒钩子 / 节奏 / 运镜 / 落点 / 属于哪个子类型），再产同款，并统一改写为新中式国潮美学（不改变原片叙事结构与节奏，只替换色彩/纹样/器物/造型为国潮语言）；绝不凭空描述没看过的画面。**反推同样按 15s 一段整段生成（编号分镜，一段连续 prompt 出一整段），30s / 60s 拆成多个 15s 段顺接——不要拆成很多单镜分别生成。**

### Step 2 · 一张问询卡一次性确认所有维度（连续问询，统一记录）

**用一个** `ask_user_input` **问询卡把下列各项一次性抛给用户**（连续触发、一张卡收齐），**不要问一步停一步**；用户在同一张卡里填完，统一记录后再往下走。需要确认的项：

1. **目的**（品牌/形象、产品卖点、促销带货…）
2. **创意手法**（故事 / 情感 / 演示；制作方式不问，固定实拍）
3. **时长**（15s / 30s / 60s）
4. **视频比例**（16:9 / 4:3 / 9:16 / 3:4，单选，无默认，必选）
5. **生成分辨率**（480p / 720p / 1080p，单选，无默认，必选）
6. **品牌 slogan**（有则填、用于结尾落点字幕；无则留空。**默认不加 logo，不询问 logo**，除非用户主动要求）
7. **旁白**：是否需要旁白 → 若需要：人声（男/女/中性、风格、语言）+ **是否需要字幕（中文 / 英文 / 中英双语 / 不要）**。（旁白一律后期用 TTS/配音加入，无"写进 prompt"选项；字幕也在最后合成前加入；旁白文案不在此卡填，留到分镜表格阶段由 skill 先拟、给用户过目确认。**未选旁白则不问字幕。**）

品类已给默认的项只需确认有无修改、不重复追问；除视频比例/分辨率外各项可选"你帮我定"，用户说"全你定"就按默认填其余项，但视频比例、分辨率仍需明确选。**收齐这一张卡后，维度与旁白偏好一次性锁定，进入 Step 3。**

### Step 3 · 出 moodboard（先问参考图 → 逐项选文字 → 按分流生成图 · 需用户确认）

**0. 先问角色参考图（在选文字方向之前，问完必须停下等用户上传）** 若有模特，先用 `ask_user_input` 问一句：**"你有人脸参考图或造型参考图吗？（人脸照片、想参考的服装/造型图都可以传，也可以两者都传）"** 问完必须停顿，让用户把参考图上传到对话框（有的话）再往下走。

**铁律：人脸/人像参考图一律不喂 图片模型**（图片模型 只接受**造型参考图**作 image reference）；人脸图只在最后 SD2 生视频时与三视图一起喂，锁真脸真发。**三视图人脸是否遮挡只看有无真人脸图：有→用白色圆形贴纸遮脸+右下角中文标注（详见下方角色三视图），无→不遮**（图片模型 脸即身份，也作 SD2 人脸参考）。

按用户上传情况分四种（都先"理解参考图/文字意图 + 补写成完整国潮造型 spec"，不丢图照搬；流程统一为 **图片模型 出正面图 → LibImage 出三视图**）：

- **① 只有人脸参考图**：人脸不喂 图片模型，图片模型 按文字 spec 出图；三视图**贴纸遮脸+标注**，人脸图仅 SD2 阶段与三视图一起喂（锁真脸真发）。
- **② 只有造型参考图**：造型图**作 image reference 喂 图片模型**；三视图**不遮脸**（图片模型 脸即身份，也作 SD2 人脸参考）。
- **③ 人脸+造型都有**：**只喂造型图、人脸不喂**；三视图**贴纸遮脸+标注**，人脸图仅 SD2 阶段喂。
- **④ 都没有**：走「选模特形象文字」正常问；三视图**不遮脸**（图片模型 脸即身份）。

**先一步步用文字选定方向，全部选完再生成图。** 文字选择逐项 `ask_user_input`，一次一项，每项 3 个选项 + "换一批"口子：

1. **选模特形象文字（④都没有时必问；①③有人脸参考图时只问年龄段/气质/发型方向，长相以参考图为准，不必再选族裔）**：给 3 个形象选项，每个 =「族裔/地域（东亚 / 亚裔混血 / 国际化…）+ 年龄 + 性别 + 发型」，**此处先不写穿着**（服装/造型留到 图片模型 正面图环节，且统一为新中式国潮造型），例如：
   - 东亚青年女性，盘发簪花
   - 东亚中年男性，利落短发
   - 亚裔混血青年女性，长直发

   形象要贴产品/品牌调性，不随机。**本 skill 强制每条广告都要有人像介入，此项不可跳过**（即便以器物/产品为视觉主角，也要选定负责手部/局部出镜的人物形象）。

2. **选场景氛围**：给 3 个文字选项，每个把「场景/置景 + 色调 + 灯光 + 质感」综合成一句。**方向不走纯古典复刻，而是「中式美学元素 × 未来主义/极简/金属质感」的碰撞**——把东方符号（窗棂/月洞门/水墨/云纹/园林轮廓/器物）与现代材质语言（银白/镜面/不锈钢/亚克力/雾面金属/极简大留白/冷光/悬浮结构）结合，出新意。
   **尺度硬要求：必须是能容纳全身模特走位的大场景（全景 / 大远景尺度）**——是"可走进去的空间/建筑/环境"，不是桌面装置或局部台面；要有纵深、地面、可站立活动的余量，让后面含模特的分镜能把人完整放进画面。例如：
   - 极简银白挑高展厅，悬浮巨型月洞门镜面装置贯穿全景，冷调柔光 + 一线暖金描边，大留白纵深
   - 未来感金属长廊/水景大厅，水墨烟雾漫过不锈钢地面，冷白顶光 + 低饱和青灰，可容人行走
   - 雾面亚克力屏风矩阵围合的开阔空间，隐约云纹透光，中国红点缀于银灰冷调间，硬朗定向光 + 地面延展

   （若品类/客户更偏传统，也可给偏古典的一版，但同样须是大场景；默认优先给这种"新中式 × 未来极简"的创新置景。）用户挑 1。

**文字方向锁定后，按顺序生成参考图：**

- **场景氛围图**：**调用 图片模型 生成**。把选定的场景氛围**扩写成具体描绘**（场景细节/光线/色调/质感/构图）。**东方符号 × 现代材质碰撞**：东方元素（窗棂/月洞门/水墨留白/云纹回纹/园林轮廓/宣纸绢帛/中国红与国潮金等）**结合**未来主义/极简/金属语言（银白/镜面/不锈钢/雾面金属/亚克力透光/悬浮结构/极简大留白/冷光），避免纯古典堆砌。**尺度必须是大场景**：图片模型 prompt 里显式写全景 / 大远景 / 广角、挑高开阔、有地面与纵深（如 `wide establishing shot, expansive interior, high ceiling, spacious, deep perspective, room to fit a full-body figure`），确保这张空镜背景后续能完整塞下全身模特走位——不要出成桌面装置或局部特写。**必须纯空镜**：只有环境，禁产品/人物/人影/手部/动物/文字/logo，prompt 显式加否定词（`empty scene, no people, no product, no text, uninhabited`），供后续所有镜头复用为背景。**风格种子固定** `--sref 4608797467 --profile nn1ntrp` **+** `--v 8.1`（不询问、不展示代码），`--ar` 取 Step 2 所选比例。**最终 图片模型 prompt = 大场景描绘 + 空镜否定词 + 固定种子（含 `--v 8.1` 与 `--ar`）**。（默认出 4 张可挑；带出主体、或场景太小塞不下人，判不合格重出。用户自带参考图可叠 `--cref`/`--iw`，但不可去掉固定种子、不可放宽空镜与大场景约束。）
- **图片模型 造型图（若有模特）**：**图片模型 V8.1 + 固定风格种子** `--sref 4608797467 --profile nn1ntrp`**，** `--ar 3:4`。**只出一组正面图，构图尽量全身/大半身**（看清整套造型搭配/下装/鞋履/廓形，至少大腿以上，能全身则全身），脸部清晰；同一段 prompt 跑一次（默认 4 张），不拆分放大，直接 4 选 1。取景显式写"全身或大半身正面站姿，完整展示整套造型与鞋履"。**分流按①-④：仅②③把造型图作 image reference 喂 图片模型，人脸图任何情况不喂**；spec 结合场景氛围+模特形象+国潮造型语言（改良汉服/立领盘扣/中国红国潮金/云纹回纹）。**生成后停下，用 4 选 1 选项让用户挑**——选项须标明每张对应 图片模型 四宫格的位置：**1（左上）、2（右上）、3（左下）、4（右下）**（对应 图片模型 默认 2×2 出图顺序），选定后再往下。
- **角色三视图（每人一张，16:9）**：**用 LibImage 生成**（不用 图片模型），**据用户选定正面图扩写**——白底、**全身左/中/右（正/侧/背）三视，非头部特写**，比例/造型（含服装）与所选正面图一致。**人脸处理按 Step 3.0 分流**：①③有人脸参考图 → **用白色圆形贴纸完整遮住每个人脸（三个视图的脸都遮），并在图片右下角加中文小字标注"人脸单独提供 · 此图仅用于服装造型参考"**（真脸留给 SD2 阶段的人脸参考图去锁）；②④无人脸参考图 → 保留 图片模型 正面图的脸、不遮。三视图即 `{{Mixed N}}` 一致性锚点，表情自然。**造型参考图与 图片模型 结果有出入时，以用户选定的 图片模型 正面图为准。**

随图附一句概念关键词 + 锁定的旋钮档位清单（7 维各一档）。
**用户确认后视觉方向锁定，才进入下一步**——后面分镜严格按选定的模特、场景氛围来写。moodboard 是出 video prompt 前的把关闸口。

### Step 4 · 按时长分段（不问模式，统一 15s 整段生成）

**只有一种生成方式：以 15s 为单位，每段一条连续 prompt 一次性整段生成**（内部按 镜头1 / 镜头2 / 镜头3… 编号分镜，每镜写明景别 + 运镜 + 内容，格式见 Step 5）。**不做逐镜分帧生成、不让用户选模式。**

- **15s**：整片一张分镜表格（Step 5.0）→ 确认 → 展开 prompt 生成整段。
- **30s**：分镜表格**整片一次出完**（第1段 0–15s、第2段 15–30s 全列在一张表）→ 用户一次确认 → **两段 prompt 并发同时生成**（各段以统一 `{{Mixed N}}`/服装/场景/光线为锚点保持一致，按顺序可拼接）。**两段必须不同内容、推进叙事，不重复镜头或动作；前 15 秒结尾不做落点定版，落点（有 slogan 则 slogan 字幕，默认不加 logo）只放在后 15 秒结尾。**
- **60s**：分镜表格**整片一次出完**（四段全列在一张表）→ 用户一次确认 → **四段 prompt 并发同时生成**（统一锚点、可顺序拼接）。**只在最后一段结尾做落点定版（有 slogan 则 slogan 字幕，默认不加 logo），中间各段不收落点。**

> **两条必含镜头（见 Step 5，多段时按整片计）**：① 全片**至少一镜是产品使用特写**（可放在任意一段）；② **尾版（最后一段的最后一镜）必须是模特与产品同框的中近景**（能穿戴则佩戴、只能用/吃喝则手持）。

### Step 5 · 按 Seedance 2.0 格式输出（先出分镜表格 → 再展开 prompt）

**5.0 分镜表格确认（整片一次出完；确认关口在此）** 分镜表格一口气出完整片——该多少秒就列多少：15s 一段、30s 两段、60s 四段，**全部镜头列在同一张表里**（按 15s 分段标注段落，如「第1段 0–15s」「第2段 15–30s」），让用户一次看到全片全貌、一次确认或修改。**分镜表格是本环节唯一需要用户确认镜头内容的关口**；表格确认后，展开 prompt 与调 SD2 生成属于内部执行，**不再把 prompt 抛给用户二次确认**。表格列：**镜号 ｜ 段落 ｜ 景别 ｜ 运镜 ｜ 画面内容（`{{Mixed N}}`/产品动作）｜ 旁白/VO ｜ 时长(s) ｜ 备注**

- **旁白/VO 列**：把该镜对应的旁白文案写在这一行（按镜分行、画面与词对齐）；连贯长句跨数镜时可合并写在相应几行。旁白须贴合已确认的目的与落点、卡住时长（约 15s 30–40 字 / 30s 60–80 字 / 60s 120–160 字，按语速调整）。**不需要旁白**（Step 2 未选旁白）则此列留空/标"无"。
- 表格须体现两条必含镜头（产品使用特写、尾版模特与产品同框）与收尾落点。**每一镜（含产品特写）的画面/备注都要标明发生在选定场景内**，产品特写注明"场景内承托物 + 浅景深虚化"，不允许出现白棚/纯色底。

> 旁白的**是否需要 / 人声**已在 Step 2 问询卡确认；此处只是把文案随分镜一起过目。旁白**一律后期加入**（SD2 静音，不写进 prompt），留到 Step 6 配音。（BGM 也不在此处理：固定国风电子融合乐、BPM 随片，留到 Step 6 合成前生成；**SD2 生视频完全静音、无任何声音**。）

**5.1 展开 prompt 并多条并发生成（表格已确认；不逐段停顿）** 整片表格既已在 5.0 一次确认，**把整片按 15s 分成的所有段一次性全部展开成各自的连续 prompt，多条并发同时提交 SD2 生成**——**不再一段一段等用户确认**。各段仍以统一的 `{{Mixed N}}` / 服装 / 场景 / 光线为锚点保持一致、按顺序可拼接、衔接不穿帮；生成完成后一并交付、进入 Step 6 合成。15s 单段则单条生成。

**★ 产品一致性强约束（防飘核心，最高优先级）★** 产品"越到后段越飘、结构/比例走样"的根因是后续段落丢了产品参考。因此：

- **每一段 15s 生成都必须把同一组产品参考作为 image reference 喂给 SD2——不是只在开头喂一次**：每段输入都带上 `{{产品三视图}}` + `{{产品细节图}}`，**全片各段喂的是完全相同的这两张，不得替换、不得省略、不得只喂给第一段**。并发的每一条 prompt 都要独立带齐这组产品参考。
- **prompt 正文对产品显式锁定**：凡出现产品的镜头，都要写明"产品外形/比例/结构/配色/logo 严格以 `{{产品三视图}}`+`{{产品细节图}}` 为准，保持与参考图完全一致，不得变形、不得改色、不得挪动或杜撰 logo/文字"。
- **保证产品可对齐**：产品出现时**完整入画、清晰、不被过度遮挡**（使用镜可露手，但产品主体与 logo 要看得清），避免因残缺/糊/大面积遮挡让模型自行脑补而走样。
- 生成后**逐段比对**产品与锚点图，形状/比例/logo 一飘就**重生该段**（并检查该段是否漏喂了产品参考）。

严格按已确认的 moodboard + 分镜表格来写。**每条输出 prompt 的第一句固定为引用场景图**：

> 请参考 `{{场景氛围图}}` 作为场景氛围。
>
> **地产 / 酒店等需实拍图的品类**：第一句改为引用 `{{空间实景}}`，且**每个镜头必须发生在该实拍场景内**，不得使用虚构 / 想象的空间。

随后正文**只写品质锁定（电影感/广告级）+ 主体 / 动作 / 镜头 / 产品**，**不再文字描述场景氛围 / 环境 / 色调**（场景一律由选定的 `{{场景氛围图}}` 承载，写进正文会与图引用互斥；场景对错以选定图为准）。

- **所有镜头都在选定场景内，产品特写也不例外（禁跳白棚）**：**包括产品特写 / 微距 / 使用镜头在内的每一个镜头，背景都必须是选定的** `{{场景氛围图}}` **那个环境**，绝不能突然切到白棚 / 纯色底 / 与全片割裂的空间。产品特写可让产品"静置于场景中的合理承托物上"（如竹林里的展示台/石台、茶室的案几、展厅的悬浮台座）并对背景做**浅景深虚化**，既突出产品又保留可辨认的场景氛围。prompt 里对产品特写镜显式写"背景为 `{{场景氛围图}}` 的环境、浅景深虚化，非纯色棚拍"。
- **角色人脸锁定**：①③"有人脸参考图"时，`{{Mixed N}}` 首现写明"脸取自人脸参考图（真脸真发），造型/身形取自三视图"，并把人脸图+三视图一并作输入；②④"无人脸参考图"则直接以三视图（含 图片模型 脸）为准。
- **输出语言 = 中文。**
- **编号分镜格式**：一段 prompt 内按 **镜头1 / 镜头2 / 镜头3 / 镜头4…** 顺序排列，每个镜头写明：**景别**（微距/特写/近景/中景/全景/航拍…）+ **运镜**（固定/推拉/环绕/跟拍/升降…）+ **内容**（`{{Mixed N}}` 或产品的动作与画面）。
- **必含镜头 1 · 产品使用特写（不可缺）**：分镜里**至少要有一镜是"正在使用产品"的特写/微距画面**——刷子扫过眼影盒的粉、手指轻触乳霜抹过肌肤的质地、执壶将茶汤注入杯盏、指尖划过面料等，按品类对应产品的真实使用动作，突出质地/触感/功能细节。**此镜背景同样在选定场景内、浅景深虚化，不许跳白棚。**
- **必含镜头 2 · 尾版模特与产品同框（不可缺）**：**最后一镜（尾版）必须是模特与产品一起露出的中近景**——**能穿戴的就佩戴**（项链/首饰=模特佩戴后的中近景、服饰=上身效果），**只能用/吃喝的就手持**（美妆护肤=手持产品、茶饮酒水=举杯/持瓶），让产品与人同框收尾。此镜可与结尾落点句（slogan 字幕）叠合。
- **整段连续 prompt（唯一格式）**：每段 15s = 一条连续 prompt = 第一句引用 `{{场景氛围图}}` → 品质锁定句（电影感/广告级，不含场景氛围与色调描述）→ **镜头1 / 镜头2 / 镜头3…（每镜景别+运镜+内容）** → 收尾落点句（**有 slogan 则用视频模型直出该 slogan 字幕；默认不加 logo，除非用户明确要求**）。中文整条交付，一次性整段生成，不逐镜分帧。
- **两级节奏：表格一次确认、视频多条并发**：镜头内容的确认关口只有 5.0 的整片表格（一次过全片，prompt 不再二次确认）；**视频生成为多条 15s prompt 并发同时跑，不逐段停顿确认**，各段保持锚点一致、可顺序拼接。
- **声音处理：SD2 阶段完全静音（无任何声音）**：所有时长的 SD2 prompt 都**不写任何声音**——不要 BGM/背景音乐、不要音效/环境音、不要旁白、不要单音/音阶/乐器音/节拍等一切声音；**SD2 只生成纯画面（静音视频）**。旁白与 BGM 全部留到 Step 6 后期合成时加入。prompt 正文只写画面（主体/动作/镜头/产品），不出现任何声音描述。
- **旁白**：SD2 静音，旁白**一律不写进 prompt**，全部留到 Step 6 后期用 TTS/配音加入（文案已在 5.0 表格确认，人声按 Step 2 问询卡的选择）。
- **生成分辨率**：按 Step 2 确认的 480p / 720p / 1080p，调用 SD2 时设置对应输出分辨率参数（不写进 prompt 正文，作为生成调用的独立参数）。
- **视频比例**：按 Step 2 确认的 16:9 / 4:3 / 9:16 / 3:4，调用 SD2 时设置对应画幅（Step 3 的场景氛围图 `--ar` 也应与此一致，保证背景图与成片同画幅）；正文可在开头点明画幅（如"横屏 16:9"/"竖屏 9:16"）。
- **影调强化句（品质句后固定追加）**：如"广告级商业调色，画面通透明亮、层次分明，色彩饱和自然不发灰，高光与材质光泽锐利，避免发暗/发灰/对比不足的下沉感"，核心诉求（通透/明亮/锐利/不发灰）必留。
- **运动质量句（末尾固定加）**：运镜丝滑、帧率稳定、不掉帧/卡顿/抖动、自然动态模糊；环绕/旋转镜头额外写"缓慢匀速环绕、平滑连续旋转"并放慢（最易卡顿，宁慢勿快）。
- 详见 `references/seedance-output.md`（景别/运镜/Cut 词汇、续接写法、各手法范例）。

### Step 6 · 视频合成、旁白配音、字幕与配乐（成片输出）

用户用上面 prompt 在 Seedance 生成片段后，回到本步收尾成片：

- **剪辑合成**：**30s / 60s 的多段按分镜顺序拼接成完整成片**（用 ffmpeg / 剪辑管线），统一画幅与帧率、处理段间衔接；15s 单段可直接成片。
- **旁白后期配音（Step 2 选了需要旁白时）**：SD2 视频静音，按选定人声用 TTS / 配音生成旁白（文案已在分镜表格确认），对齐画面后混入。
- **加字幕（Step 2 选了需要字幕时）**：按选择加旁白字幕——**中文 / 英文 / 中英双语**，与旁白文案一致、随旁白节奏对齐上屏；样式简洁不抢画面（贴合新中式国潮气质）。字幕在本步合成前加入；未选字幕则不加。
- **生成配乐（所有时长都在此步统一生成，不随 SD2 出）**：镜头完成、拼接成片后，生成一段国风电子融合乐（古典乐器 × 现代电子，见第三节），**BPM 依成片实际节奏/调性定**（快片强律动、慢片有空间感，片内可变速），时长严格匹配成片；SD2 视频为静音画面，将 BGM 与后期旁白（如有）一并混入，旁白优先、BGM 不盖人声，输出最终带乐+旁白版本。

## 通用约束（速查 · 详见对应 Step）

- **产品锚点两图必做**：上传产品后、确认维度前，**必须以上传产品图为参考（图生图，非文生图）**生成 `{{产品三视图}}`+`{{产品细节图}}`（白底 16:9），外形/配色/品牌标对不上就重出，不可跳过；空间即产品（地产/酒店）以 `{{空间实景}}` 替代。
- **产品防飘（每段必喂参考）**：SD2 生视频时，**每一段 15s 都要把同一组** `{{产品三视图}}`**+**`{{产品细节图}}` **作 image reference 喂进去**——不是只喂开头一段；产品出现镜要完整清晰不被过度遮挡，prompt 显式写"产品严格以锚点图为准、不变形/不改色/不动 logo"；逐段比对，一飘就查是否漏喂并重生该段。
- **只做新中式国潮**：场景/道具/纹样/色彩/造型都不脱离国潮语言，不混欧美时尚/赛博等。
- **风格种子固定**：图片模型 统一 `--sref 4608797467 --profile nn1ntrp` + `--v 8.1`，不展示代码、不给选项、不许更换。
- **造型分流**：先问人脸/造型参考图，按①只人脸只造型③都有④都没有决定 图片模型 是否带 image reference 及三视图人脸是否遮挡（**人脸图永不喂 图片模型，只在 SD2 阶段喂**；有人脸图→三视图用白色圆形贴纸遮脸+右下角中文小字"人脸单独提供 · 此图仅用于服装造型参考"，无→留 图片模型 脸）。图片模型 只出一组正面图（尽量全身/大半身、`--ar 3:4`）跑一次 4 选 1（选项标 1 左上/2 右上/3 左下/4 右下），选定后 LibImage 扩写全身三视图锁 `{{Mixed N}}`。
- **场景氛围图必为纯空镜 + 大场景**：只有环境、禁产品/人物/人影/手部/动物/文字/logo，prompt 显式写否定词（no people/no product/no text/empty scene）；且必须是**能容纳全身模特走位的全景/大远景空间**（挑高开阔、有地面纵深，非桌面装置或局部台面），带主体或太小塞不下人即不合格重出。
- **场景由图承载**：分镜场景一律由选定的 `{{场景氛围图}}`（或 `{{空间实景}}`）承载，**正文不再文字描述场景/环境/色调**；实拍图品类每镜必须发生在 `{{空间实景}}` 内，不得另造虚构空间。**产品特写/微距/使用镜头也必须在选定场景内**（产品可静置于场景中的承托物上 + 浅景深虚化），**严禁跳白棚/纯色底**。
- **两级节奏：表格一次确认、视频多条并发**：镜头内容的唯一确认关口是 5.0 的**整片分镜表格**（该多少秒列多少、全片一次出、一次确认；prompt 不再二次确认）；**视频为多条 15s prompt 并发同时生成、不逐段停顿确认**，各段以统一锚点保持一致、可顺序拼接。prompt 中文交付、作模型内部执行层，不需用户手动粘贴。
- **两条必含镜头**：全片**至少一镜产品使用特写**（刷子扫粉/指尖抹乳霜/执壶注茶等真实使用动作，突出质地/功能）；**尾版必须模特与产品同框中近景**（能穿戴则佩戴、只能用/吃喝则手持），多段时按整片计（尾版在最后一段末镜）。
- **强制人物介入**：每条片必有人像（完整出镜或手部/局部肢体），绝不通篇无人；运镜仍丰富展示产品/空间。
- **默认不加 logo**：结尾不放 logo、不询问，除非用户明确要求；有 slogan 则视频模型随片直出字幕，无则产品 hero/画面自然收尾。
- **SD2 生视频完全静音、声音全后期**：SD2 阶段**只出纯画面，不生成任何声音**（无 BGM、无音效/环境音、无旁白、无单音/乐器音/节拍）；成片声音只有 **BGM + 旁白（如有）** 两层，全部在 Step 6 后期加：BGM 固定为「中国古典乐器×现代电子的国风电子融合乐」（非纯民乐非纯电子）、BPM 随片、不询问用户、合成前按成片节奏/调性生成；旁白按 Step 2 选择后期 TTS/配音；**不做任何音效层**；混音旁白优先、BGM 不盖人声。
- **字幕（选了旁白才有）**：仅当 Step 2 选了旁白时才可选字幕（中文/英文/中英双语/不要）；字幕与旁白文案一致，在 Step 6 合成前加入，样式简洁贴合国潮气质；未选旁白则不涉及字幕。
- **视频比例 + 分辨率必须用户选**：比例（16:9/4:3/9:16/3:4）与分辨率（480p/720p/1080p）无默认，Step 2 必问，SD2 按此设置画幅与输出。
- **影调强化**：每条 prompt 品质句后固定追加——通透明亮、层次清晰、色彩不发灰、光泽锐利，避免发闷/下沉，维持国潮高级通透感。
- **运镜丝滑**：末尾固定加运动质量句（不掉帧/不卡顿/丝滑+自然动态模糊）；环绕/旋转类尤易掉帧，写"缓慢匀速环绕、平滑连续旋转"并放慢。
- **镜头衔接**：不跳帧、不越轴（守 180°），机位与运动逻辑连贯；15s 段间续接保持 `{{Mixed N}}`/服装/场景/光线一致不穿帮。
- 角色用 `{{Mixed N}}`，首现写全、后续复用、主宾清晰；演示型确保产品每镜清晰。
- 一条片只承载一个核心信息点，前 3 秒抓人，结尾必有落点。
- **表情自然可信，禁夸张怪异**；**禁叠画/叠化转场**；**禁粒子特效**（太土，改用干净光效/无缝变形/材质质感）。
- 不做真实公众人物内容；不杜撰真实品牌虚假主张；保持适当无害。
