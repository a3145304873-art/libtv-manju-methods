# game-promo-video

做原创/用户自有游戏的宣传 Demo / 实机演示 / 开放世界类 gameplay 短片时用本 skill。含两种玩法，按用户需求二选一：

- **玩法一·三段式实机演示**：Video A 引导流 / Video B 剧情流 / Video C 战斗流，各约 15s、总 45s，每段单镜时长 ≤15s。全流程 = 背景风格定调 → 三段式剧本拆解 → 元素设计（角色原画→四视图→3D 形象卡 + UI/场景关键帧）→ 逐段视频生成 → 全段合片。
- **玩法二·开放世界都市类 gameplay 短片**：借鉴开放世界犯罪/都市题材的视觉语法、镜头组织与角色类型（只借鉴视觉语法/城市气质/镜头组织/角色类型，不复刻任何官方镜头、Logo、UI、商标、车牌或具体台词，不指名任何商业游戏 IP），产出 30-60s 的混合体验短片：热带度假广告感 + 犯罪纪录片质感 + 社媒荒诞感 + 开放世界城市展示。全流程 = 全局设定 → 双路径角色资产 → 分镜叙事（快节奏事件 or 单镜生活切片）→ 逐镜视频生成 → 音频层 → 剪辑合成。

本 skill 自带战斗动态/锁 UI/像素锚定/类 gameplay 镜头语言/卡点剪辑节奏等全部工艺，不外包给其它 skill。

## 本环境适配（源模型名 → 13 工具/SP）

image2 出图（画质参数由 Ask 用户确认） → 全部走 generate_image_v3（同一图像引擎保三段一致）；四视图/3D 形象卡可配 character_turnaround_3view 玩法；Seedance 2.0 → generate_video_v3；三段拼接 → composite_video（video layer + audio layer 均开）；Final_Video_Spec.md / 规范文档 → text_editor（写文件）；storyboard_designer → 内部分镜阶段；multimodal_analyze_tool → 多模态读图（3D 材质分析 / UI 像素锚定 / LUT 提取 / 用户照片特征提取）；Image_A1…A5 节点引用 → reference_nodes + {{NodeKey}} 占位符；暂停/审阅 → reply_to_user 或卡片；用户照片 ImageToImage 变角色 → reference_nodes 图生图路径。源无付费/会员语义需剥离（含"高级会员 1080p"）。

生图前，必须 Ask 用户确认本次用 image2 模型的什么画质参数发布，询问 4 个选项：1，2k标准画质（性价比高）；2，2k高画质（性价比适中）；3，4k高画质（土豪请随意）；4，其他。

生视频前，必须 Ask 用户确认本次用什么视频分辨率参数发布，询问 3 个选项：1，720p（性价比高）；2，1080p（性价比始中）；3，其他。

## 玩法一·三段式实机演示

### 流程与暂停

不要一次性跑完。在每一关键阶段后停下、与用户确认再进下一步（可用卡片或 reply_to_user 邀请审阅）：规格定稿后 → 故事板完成后 → 元素（角色卡+关键帧）完成后 → 分段视频生成后 → 音频/合片后。

### 1. 背景与风格定调

接收用户主题关键词，自动设定故事背景、确立全局游戏风格（如写实 / 奇幻 / 赛博等）。撰写 Final_Video_Spec.md（text_editor），字段：标题、类型、画幅比、时长、视觉风格、语言。

### 2. 三段式剧本拆解（核心骨架）

将演示内容划分为三段（各 15s）结构化脚本，逐段秒级 timeline：

**Video A（15s）引导流 — 系统交互与觉醒**
- 0–3s：封面图，模拟呼吸灯光效，执行 [Start] 按钮交互。
- 3–10s：选人/技能展示，模拟鼠标悬停高亮，展示角色 3D 待机 Pose 或招牌动作。
- 10–15s：第一人称 POV，场景切入，从特定视点（苏醒/转场）过渡到广阔环境的 HDR 效果。

**Video B（15s）剧情流 — 叙事交互与追踪**
- 15–25s：NPC 交互，呼出对话 UI，文字逐字显示，背景保持环境动画。
- 25–30s：场景追踪，镜头跟随角色快速移动至特定视觉地标，制造遭遇感。

**Video C（15s）战斗流 — 核心战斗与结算**
- 30–40s：实机战斗，快节奏对抗，UI 血条与技能槽实时动态变化。
- 40–45s：战斗结算，Boss 击败动作，弹出获胜 UI 及奖励结算特效。

### 3. 元素设计（资产链：原画 → 四视图 → 3D 形象卡 + 关键帧）

**角色设计（核心逻辑）**
- 原画：出角色大师级 2D 设计原画（主角 / Boss）。
- 角色四视图：基于原画 ImageToImage 生成白底四视图（推荐 2K）。布局规则：左侧为面部特写图（捕捉面部细节、皮肤质感、妆容），右侧依次排列全身正面图、全身背面图、全身侧面图（捕捉形体比例与装备层级）。所有视图须与原画造型、配色、材质严格一致（可配 character_turnaround_3view 玩法）。
- 3D 形象卡：将四视图转换为 3D 真实感人物形象卡。
- UI/场景关键帧：生成全链路一致的游戏 UI 界面与场景关键帧，覆盖：开始界面 / 选人界面 / 加载界面 / 第一人称起手视角 / 第三人称观察场景 / 进入 Boss 战。所有图强制同一图像引擎保一致。
  - Video A：出 5 张关联图（封面、选人页、技能页、场景起手点等）。
  - Video B/C：出对话 UI 图、行进场景图、带 HUD 的战斗首尾帧、结算图。

### 4. 分析约束（多模态读图，供视频生成用）

- **3D 资产分析**：深度分析 3D 形象卡的材质（金属反射 / 皮肤质感 / 服饰纹理），产出光影描述参数。
- **UI 像素锚定（核心）**：分析带 HUD 截图，记录血条、技能栏、对话框的精确像素位置，将其设为「视频生成禁止形变区」。
- **色彩与光影一致（LUT）**：提取全局色彩倾向，确保三段视频从头到尾色调、亮度高度一致，防止偏色。

### 5. 逐段视频生成（generate_video_v3）

详细编写每一场景的呈现内容、模拟鼠标点击后高亮的 UI 反馈、以及高强度 Boss 战斗动作。四条提示词指令：

- **交互段落指令（Video A）**：以 Image_A1…A5（reference_nodes+{{NodeKey}}）为节点，模拟真实键鼠交互反馈（点击、高亮、光效），保持 3D 模型在各界面视觉一致。
- **叙事对话指令（Video B）**：对话 UI 绝对清晰、不颤抖、不模糊，文字显示与角色状态同步。
- **动作战斗指令（Video C）**：以战斗对峙图为首帧、获胜结算图为尾帧。
- **核心指令（贯穿全段）**：强制锁定 UI，禁止血条和技能图标产生任何位移、伪影或形变（对齐第 4 步禁形变区）；动作描述包含高频位移、粒子特效、震屏打击感。

### 6. 全段合片与音频（composite_video）

将三段 15s 视频按逻辑拼接为完整实机演示 Demo，统一输出高画质（设定分辨率、帧率、动作平滑度渲染标准）。合片时同步匹配对应音效：UI 音、环境音、打击音。video layer 与 audio layer（背景音乐）均开启。

## 玩法二·开放世界都市类 gameplay 短片

面向"开放世界都市犯罪/街头题材类 gameplay 实机感短片"的独立玩法：只借鉴公开题材通用的视觉语法、城市气质、镜头组织和角色类型，不复刻任何官方镜头、Logo、UI、商标、车牌或具体台词，不指名任何商业游戏 IP。

### 1. 全局设定初始化

创建并锁定 Final_Video_Spec.md（text_editor）：画面比例默认 16:9；主题定位为"受开放世界犯罪/街头题材启发的主题视频、分镜、提示词和视觉审查"。视觉风格不是单纯"霓虹犯罪"，而是"热带度假广告 + 真实犯罪纪录片 + 社交媒体荒诞短视频 + 开放世界城市展示"的混合体：画面表层热闹、性感、阳光、夸张；底层始终有追捕、债务、人情、走私、音乐产业、帮派和情侣逃亡的压力。时长默认 30-60s 的小篇幅游戏实机展示 demo，除非用户明确要求更长故事。

### 2. 双路径角色资产

设计分镜大纲时，角色创作提供两条路径，由用户选择：

- **方案一（经典角色原型）**：使用内置角色原型库创建人物（见下方原型库），直接生成符合本风格、3D 游戏实机质感的 3D 渲染参考图（generate_image_v3）。
- **方案二（用户定制角色）**：用户上传个人照片（仅作创意参考）。多模态分析只提取性别与大概形象/气质（如：性别、大致年龄范围、面部大致轮廓或核心神态眼神），不描述或提取发型、妆容、服装穿着、配饰等具体细节——生图阶段由 ImageToImage 视觉参考路径（reference_nodes 图生图）自适应提炼这些细节，无需在提示词中生硬规定。输出极简英文特征词，例如：`A Hispanic male in his 20s, with sharp facial features and determined eyes`。强调将用户现实基础形象抽象为"该风格 3D 游戏角色、第三人称游戏实机、UE 渲染"的底色，剔除照片背景与光照干扰。若用户另上传第三方视频/动图作为动作或色调参考，需分析其镜头运动（第三人称跟随、低机位车辆追逐等）和色彩成分，转写供故事板与生成阶段使用。

### 3. 角色原型库 + 场景模板库

设计故事板 key_elements 时，可预定义以下高频角色、场景原型，支持灵活自定义扩展（原型均为通用化命名，非项目专属）：

**角色原型库**
- MALE_LEAD：典型男主角（如热血驾驶者、街头青年），结实、疲惫警觉，擅长极限临场反应。
- FEMALE_LEAD：典型女主角（如冷静决策者、干练女强人），强硬、果断，在困境中寻找出路。
- UNDERGROUND_BOSS：地下产业巨头/幕后大佬，常戴墨镜、穿着奢华，眼神深不可测。
- INFLUENCER_STREET：社媒网红/街头喧嚣者，追求流量与关注，经常举手机直播或热衷派对。
- MASTERMIND_PLANNER：行事缜密的行动策划者，经验丰富，老练且难以捉摸。
- REGIONAL_SMUGGLER：老派海岛/边界走私者，粗粝、不羁，代表旧时代的犯罪遗留规则。
- PARANOID_MONITOR：偏执监听者，松弛体态，擅长在满是屏幕与电台的暗室中获取线索。
- CUSTOM_USER_HERO（方案二专用）：根据用户照片分析转换而来的定制主角，继承用户核心外形与眼神特征，具有极强的身份代入感。

**场景模板库**
- METROPOLIS_NEON：热带霓虹都市、繁华海滩、高架桥梁、粉紫街道、积水路面。
- COASTAL_ISLANDS：海岛走私带、蓝绿海水、码头、白色游艇、黄昏跨海长桥。
- WILD_SWAMP：湿地荒野、沼泽芦苇、直升机探照灯、泥水雾气。
- DECAYED_HARBOR：廉价港口城、汽车旅馆、Motel 停车场、旧加油站。
- INDUSTRIAL_TOWN：工业外围镇、钢架厂房、烟囱、摩托车队、滚滚尘土。
- STORMY_MOUNTAIN：山地国家公园、森林幽暗山路、暴雨闪电。

### 4. 叙事结构（二选一）

分镜数量默认控制在 1-3 个 shot，除非用户明确要求更长更复杂剧情，优先精简体量以保证渲染效率和单镜质量。

- **结构 A：快节奏事件叙事**（多切镜组合，适合预告片或动作场面）——与用户确认核心剧情后按三段展开：
  - 开场段落·氛围铺垫：多用广角俯视、天际线慢移，声音融入环境音、远处警笛或电台，展现"平静外表下的暗流涌动"。
  - 中段段落·冲突失控：动作局部特写、角色争执、追逐碰撞，穿插社交媒体手持/直播视角。节奏由平缓切到高频，多机位频繁切镜。
  - 收尾段落·悬念悬挂：特写眼神、车门关闭、倒后镜等，音乐突歇，只留引擎、呼吸或单调音效，留下戏剧悬念。
- **结构 B：单镜头生活/玩法切片**（一镜到底，5-12s）：强调高可读性、单一连贯动作（如：给车加油、站在积水路口看棕榈树、在影院门前步行、慢速车辆碰撞金属挤压物理瞬间、手机拍摄游戏屏幕的"泄露质感"）。必须严格规范：单镜头内禁止切换时空或拼接蒙太奇，保持极度流畅的类游戏第三人称跟随相机延迟。

### 5. 五类专有视角

镜头语言分类，按叙事需要选用：

- **类 gameplay 第三人称视角**：机位偏低、偏侧，处于角色身后，保留第三人称空间感，带有轻微延迟，隐去游戏 UI。
- **车载/车旁混合视角**：镜头处于副驾驶肩后、后视镜、或后保险杠极低位置，前景为车体，霓虹灯光在湿车身和玻璃上高速滑过。
- **社交媒体竖屏视角**：模拟手机自拍、手持直播，偶发抖动、短暂失焦与边缘失真，画面长宽比可转为 9:16 插入。
- **监控/警方 bodycam 视角**：CCTV 固定广角、带压缩与噪点；bodycam 强烈晃动、带有近距离鱼眼畸变。
- **亲密逃亡双人视角**：车窗、Motel 门框、百叶窗遮挡构图，营造"犯罪压力下的温情与防备"。

**音频层**：全局配置一条主题音乐音轨（BGM：合成器波、现代说唱、南部电台摇滚）；对话使用 key_element_audio 保持主角嗓音的粗粝/沙哑或拉丁语调。

### 6. 单镜设计规则 + 多切镜规则（4-Cut 公式）

**单镜头一镜到底（生活切片/单一动作）设计规则：**
- 核心设计意图：适合 5-12 秒的稳定短镜头，核心是"一件事从开始到结束"，动作绝不复杂，镜头绝不乱切，以此建立开放世界的真实生活与 gameplay 质感。
- 动作设计限制：只保留 1 个主行为（例如：给车加油、递热狗、拿啤酒、打开车门、扫码付款、擦挡风玻璃、点烟、把现金塞进口袋）。禁止在单镜头内同时设计多项并行或连贯的复合剧烈动作（如不要让角色在加油的同时打电话、掏枪、奔跑）。
- 镜头运镜限制：只保留 1 种运动方式（如慢速推近、侧向横移跟拍、类 gameplay 固定或浮动视角、车内轻微手持摇晃）。
- 音频配合设计：音轨需提供极具临场感的环境音锚点，如车流声、远处警笛、夜店低音、便利店门铃、加油枪滴答声。

**多切镜事件（追逐/冲突/抢劫/混乱事件）设计规则：**
- 核心设计意图：推荐将每个多切镜事件统一设计为 15s 的单个 shot，最大化发挥视频生成模型在单次 15 秒生成中产出丰富内部切镜、流畅场景过渡和饱满信息密度的最佳性能。
- 分镜结构公式（4-Cut 经典流）：
  - Shot 1（环境与威胁）：交代所处场景、地点环境以及面临的突发威胁/对手。
  - Shot 2（动作细节特写）：展示高动态动作局部特写（如猛踩油门、换挡、推搡、枪栓拉动）。
  - Shot 3（反应与阻碍）：展现角色的受阻反应、路人荒乱、物理撞击或警灯闪烁等不同机位画面。
  - Shot 4（悬念/终局冲击）：展现逃脱、撞击瞬间或极具张力的定格画面，留下悬念钩子。
- 空间连续性限制：高动态镜头必须维持空间、时间、光影的一致。角色、车辆须在相同街区或空间，朝一致方向运动，避免画面跳跃穿帮。
- 切镜与音频配合：每个短镜头只承载 1 个明确的信息点。镜头要全景、车内、低机位、特写、社媒画面交替混剪，并为每次碰撞、轰鸣、破碎声在音轨中预留精准的音效对齐点（如引擎轰鸣、玻璃碎、警用广播、轮胎摩擦）。

### 7. 逐镜视频生成绑定规则（generate_video_v3）

- 角色 3D 渲染优先用 generate_image_v3；方案二在图生图路径下输入用户照片，生成定制主角的专属 3D 渲染全身照与面部侧写。
- Shot 视频统一生成时长 15s（多切镜事件），以发挥最出色的多镜头内部切镜与自然转场渲染效果；分辨率默认 720p（源"高级会员优先 1080p"语义剥离，不落地）。
- 参考绑定规则：
  - **视觉参考**：必须绑定镜头内出现的角色 asset_id（自定义主角或经典原型）；必须绑定当前所在的场景 asset_id。
  - **连续性参考**：若属高强度多切镜追赶/撞车场景，生成 Shot N 时须绑定 Shot N-1 的视频作为参考，确保车辆颜色、受损程度和光影平滑过渡。
  - **声音绑定**：若镜头内包含角色对镜头说话，须在音频信息中绑定该角色专属声线资产，实现音画同步。

### 8. 提示词构建（write_the_prompt）

通用构建原则：绝对禁止包含具体商业游戏名称、版权标志或品牌 Logo；采用"导演与调色师"视角，多用动作描述和具象材质词，不写情绪猜测。

**四色调口诀：**
- 都市霓虹夜晚：pink and purple neon, wet black asphalt reflections, cyan highlights, dynamic sodium lights
- 热带海岸黄昏：golden hour glow, teal sea, distant silhouette of palms, hazy sunset sky
- 晨雾湿地沼泽：olive green muddy water, dense morning fog, silver gray, intense helicopter searchlight beam cutting through haze
- 白日光照：harsh tropical sunlight, overexposed edges, deep dark hard shadows, heat shimmer

**角色 3D 渲染 prompt 结构**：统一采用该风格、3D 游戏、第三人称游戏、UE 渲染的高清写实 3D 游戏质感风格，生成一张全身+侧面特写的"角色 3D 实机渲染图表"（horizontal side-by-side layout）：

> A 3D game character render of [character name], a [gender] with [hair/face features], wearing [outfit], open-world game style, 3D game model, third-person game gameplay character, Unreal Engine 5 render, high fidelity, realistic game engine shaders, wet skin texture, high contrast tropical lighting.

**视频 prompt 结构**：统一格式化为 镜头机位 + 视觉参考占位符 + 动作运动堆栈 + 环境声学标记。

格式范例：

> [Camera: third-person trailing angle with slight delay] <<<image_1>>> [Character: young male protagonist] is fueling his dusty muscle car at a neon-lit gas station, simple action of holding the gas nozzle. [Background: wet asphalt, pink and cyan glowing neon signs, swaying palm trees, humid metropolis night atmosphere]. [Audio: (ambient club bass), <distant police siren>]

**运动堆栈设计**：从相机运动（Camera）开始描述，接着是主体人物/载具动作（Action），再到空间环境变化（Environment），最后用括号包装音效或对白细节。视频内对白用 {dialogue} 包裹（例：{We are in this together, okay?}）；音乐氛围声用 (music) / (ambient club bass)；动作音效用 <tire screech> / <siren>；视频 prompt 尾部默认带 `no music, no subtitles, no logo, no branding, photorealistic game trailer concept` 负向过滤词，背景音乐交由音频轨道统一合成，防止音频重叠。

### 10. 剪辑合成三段节奏（composite_video）

- **快节奏事件叙事（多切镜组合）**：开场阶段单镜头时长 4-5 秒，画面淡入淡出，切镜平缓；中段关系网失控，剪辑点密集（0.8-1.5 秒一剪），采用无过渡硬切与闪白，模拟高速心跳；结尾逃亡悬念，镜头拉长到 6-8 秒，淡出至黑色。
- **类 gameplay 生活切片**：一镜到底，全长 5-12 秒无任何剪辑点。
- **音视频精确对齐**：
  - 音轨 1（环境音效/SFX）——枪声、碰撞声、引擎轰鸣与视频画面动作发生帧严格对齐，车辆物理碰撞瞬间音量瞬时调大 6dB 并加低音震动效果；
  - 音轨 2（对话语音/Narration）——对话开始前 0.3 秒 BGM 自动衰减 12dB（Ducking），对话结束后 0.5 秒平滑回升；
  - 音轨 3（背景音乐/BGM）——视频最后 10 秒（悬念部分）BGM 突然抽空或做低通滤波处理，仅留沉重呼吸声与单调警笛残音，强化末路张力。
- **输出规格**：导出阶段严格遵循 Final_Video_Spec.md 中的参数，不允许包含黑边或拉伸画面。

## 边界（勿用本 skill，改道）

- 2D 动画风格宣传 → cartoon-flow。
