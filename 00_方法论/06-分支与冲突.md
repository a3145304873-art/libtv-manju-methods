# 来源分歧与本库决策

来源原文保留；下表是适配后的决策规则。多份文档重复某做法只表明多源主张，不证明效果或最佳值。

| 问题 | 来源分歧 | 本库采用方式 |
|---|---|---|
| 分段时长 | I01/I03/I04 常按 15s；I05 按语义；节点样本有多种时长 | C13 按动作、对白、节奏和当前模型限制选择。15s 作为来源配方选项，不是通用硬单位 |
| 尾部处理 | I03 有短尾舍弃；其他流程重视结局与接续 | 保留叙事必要内容；裁短必须符合当前任务范围与用户确认，不能自动砍掉结尾 |
| 声音 | I04 生成静音；I01/I02 生成动作声后配乐；I03 单段可带音乐；W08 音乐驱动 | C08 分静音、音效、人声/音色、音乐表演和后期配乐分支，不强制全库静音 |
| 多格故事板 | I02 可作故事板指导；I05 只审核/裁单格；W09 仅存在测试图、未作为视频输入 | C10 区分审核图、单格首帧、真实故事板输入；依据工具支持和试片决定 |
| 资产范围 | I04 强锚点/场景图；I05 按需、可用文字锚 | C04/C12 按辨认度、交互和连续性风险选择。已有合格资产不默认重做 |
| 场景描述 | I04 图像承载、避免文字重复；I05 要明确空间文字 | 图像与文字不得冲突；动作方向、位置、轴线必须有可用表达 |
| 表演 | I02 夸张卡通；I04 自然；W07 克制喜剧 | 在 S0/S1 确认表演基调；不同时强加夸张和克制 |
| 影像质感 | 原文多处有 8K/IMAX 品质词，快照常为 480p/720p | 诉求、请求规格、输出元数据、后期导出分别记录 |
| 数值 | 网格数量、镜头比例、音量、字数、固定种子 | 标作来源建议；采用条件和结果需验证，不全局固化 |
| 节点身份 | W08 同一 ID 在正文/表中有身份冲突；W09 部分文字绑定疑似串位 | 保留 unknown 和原文；消歧前不生成可执行绑定 |

## 能力编号统一

工作流研究已有 **C10 多宫格分镜预演**。行业文档曾把“15s 分段”也候选命名为 C10，本库保留原 C10，将分段策略规范为 **C13 语义分段与模型档位**；C11 为收尾信号，C12 为输入路由与生产深度。历史名称仅作来源别名，不新增两个同号能力。

## 缺失 Skill 依赖

I04 原文提到 `references/seedance-output.md` 和 `scripts/extract_frames.sh`，I05 提到多份 `references/*.md`；未提供的文件记入来源清单。没有上游地址时不猜仓库、不伪造附件。本库独立方法不依赖这些缺失路径，但不能自称已安装其原始完整发行版。

## 解释层纠偏

此前整理中“所有来源均以 15s 为硬单位”“有节点图就是成品证据”“音画必须全部分离”等概括不作为本库规则。当前仅能以已读文字/快照证明相应结构与主张，质量和可迁移性另需观看及复现。
