# 从来源学习到原创制作

## 方法库的五层

1. **来源层**：W01–W11 的工作流文档/快照，I01–I06 的行业技能原文，R01–R02 的格式参考。保存事实、作者主张、版本与缺口。
2. **能力层**：C01–C18。记录解决的问题、触发条件、前置输入、学习位置、方法分支、验证与退出条件。
3. **配方层**：为一次任务确认的组合。一个主参考负责整体体验，辅参考只解决明确问题；不混合互相抵触的表演、声音或视觉要求。
4. **生产层**：项目 → 集 → 场 → 镜 → 生成候选 → 剪辑采用片段。用版本、依赖和状态使修改可追溯。
5. **验证层**：参考输出、尝试、失败、采用区间、成本与创作者判断。允许结论是“当前条件下不可用”。

查方法从能力/阶段索引开始，证据不足再读原文；不把全库塞进一次提示词。

## 输入成熟度

| 输入 | 推进方式 |
|---|---|
| 仅题材或模糊感受 | 提供少量不同的体验方向、主参考候选；由用户确定本轮目标 |
| 一个简单想法 | 补成触发—判断—动作—结果—余味；明确哪些是补写假设 |
| 完整剧本 | 锁定角色关系、台词、动作、结局与不可改事实；先检查可执行性，不擅自重写 |
| 单镜请求 | 直接确认该镜目的、参考、动作边界、画幅/时长与声音，不强制扩成整剧 |
| 已有片段或失败结果 | 进入对照/返修，先定位具体问题和来源版本，不默认重做全部上游 |

输入路由参考 I05，按任务需要选择；“不建场景资产”“必须固定网格”等原文约束保留为其分支条件，不升级为所有任务规则。

## 学习与采用

先确定问题，再选择来源，确认本阶段学习范围，产出阶段结果。原机制小段复现 → 相邻两段接续 → 换主体迁移 → 短成片对照 → 评估是否批量化。步骤只在相应任务需要时进入。

当前全部来源方法按候选使用。来源里存在任务成功记录或成片资源，并不证明完整影片质量、商业成功或方法因果效果。

## 实际任务启动

建立任务简报和阶段记录，确定现有输入与缺口；向用户提交当前阶段参考包。用户确认的主张和约束进入该任务文档，能力库只保存可复用方法及证据。
