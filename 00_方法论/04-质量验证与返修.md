# 从研究候选到可用配方

## 证据独立记录

每例分别记录：结构读取范围、原文精读范围、媒体观看范围、采用版依据、原条件复现、换主体迁移、成片验收。未知留空并说明；不要把这些阶段折算成一个“完成百分比”。

用户确认参考是创作决定；任务 status 是技术记录；成片验收是结果判断。三者互不替代。

## 验证次序

1. 找到用户认可且可播放的基准，标出具体时间码和质量点。没有媒体时只能作结构研究。
2. 复现一个完整的动作、反应或音乐表演单元，保存所有候选、实际成本和失败。
3. 验证相邻段切点和状态传递，再换主体/场景测试迁移。
4. 做短成片，整体看听，判断节奏和情绪是否成立；再决定批量化范围。

## 对照表

| 维度 | 观察点 |
|---|---|
| 叙事/情绪 | 动机、因果、转折、反应和收束是否可读 |
| 身份/视觉 | 脸、比例、服装、装备、材质和光线是否连续 |
| 动作/空间 | 接触、视线、重量、持物与方向是否成立 |
| 镜头/节奏 | 信息顺序、切点、运动和停顿是否服务内容 |
| 声音 | 台词、音色、口型、动作声、环境与音乐是否贴合 |
| 生产可用性 | 实际可用时长、候选数、费用、人工修复量与失败条件 |

可以标“接近/略弱/明显不足/不适用”，必须附画面或声音时间码。关键失败不能被平均分掩盖；漂亮静帧不能替代正常速度播放。

## 返修定位

身份/装备持续漂移先查资产与绑定；动作不成立查接触点和时长；空间乱查地图与轴线；串声查说话人与音频角色；局部可修则比较局部重拍与整段重生；上游错误则先修上游并复核受影响镜头。

每轮记录问题、源版本、保留项、改动、比较对象、结果、副作用和采用决定。尽量减少同时变化的变量；多因素修改不能归因于某个单词。使用[返修模板](../05_模板/返修记录.json)。

配方记录可用条件和失败条件；尚未通过迁移时只标“原条件可用”。采用结果不覆盖失败证据，后期增强不冒充原生清晰度。
