# 方向设计标准｜空白模板

依据 R01 的文档格式与组织逻辑整理。请将本目录复制到新作品工作区的 `script/<方向标识>/` 再填内容，不在方法库里写正式故事。

| 文件 | 用途 | 来源属性 |
|---|---|---|
| [skeleton.md](skeleton.md) | 方向总纲与全剧承诺 | 原包实际栏目，去掉题材内容 |
| [data/characters.md](data/characters.md) | 人物身份、动机、关系、弧光与认知 | 本库建议补充；原包此文件重复总纲 |
| [data/locations.md](data/locations.md) | 戏剧空间、行动限制与可复用动作位 | 原包实际字段；ID/状态为本库补充 |
| [data/props.md](data/props.md) | 物件戏剧作用、使用边界与出场 | 原包实际字段；ID/状态为本库补充 |
| [arcs/ARC001/arc.md](arcs/ARC001/arc.md) | 展开一个故事分段 | 本库建议补充；原包只给路径未附文件 |

模板中的 ARC001、EPxxx、角色/地点/道具占位符都是结构示例，尚未决定任何具体方向、集数或剧情。分段实际创建后再加行和链接；状态为候选/待填的内容不视为作者确认。

填写顺序：S0 确认方向体验和参考范围 → 概要与简述 → S1 规则、分段及追看递进 → 三类预设表 → 必要人物/地点/道具 → 分段展开 → 一致性检查。已有内容按需接入，不强制重写。

具体来源、缺口与检查方法见 [R01 格式拆解](../../07_格式参考/R01-方向设计格式与逻辑.md)。
