# 词表 · 运镜与景别（写提示词时查）

> 2026-11-05 v1｜提炼自 [R03](../../04_原始资料/format-references/R03/README.md)（A53 资料包，教程词表**非运行证据**）
> 服务对象：V 叙事段逐拍机位槽、G 分镜图、K 首帧。大招线五拍运镜见 [R02](../../07_格式参考/R02-大招演出提示词格式.md)（C18），不用本表。
> **三条口径**：① 数值是参考起点，换线先短试，与实跑冲突以实跑为准；② 「情绪→运镜」对照只供人选镜，**情绪词不进提示词**（[00](00-公共基底.md) §二#6），提示词只写动作描述；③ 标「噜噜已验证」的条目来自噜噜画布实跑，可信度高于教程条目。

## 一、运镜动词＋数值（逐拍机位槽用）

| 动词 | 参考写法（数值为教程参考） | 备注 |
|---|---|---|
| 推 | 缓慢推进，全景推至中景/近景，每秒 10–15 厘米，止于面部或核心细节 | 情绪递进用；急推见情绪对照表 |
| 拉 | 从特写拉开至全景，0.5 秒内完成「填满画面→主体占比 10%」 | 疏离/揭示用 |
| 摇（水平） | 匀速慢摇，左→右扫过场景，约 8 秒，画面边缘保持水平 | 探索/巡视 |
| 摇（垂直） | 快速急摇，地面→天空，2 秒内 | 揭示高差/主体 |
| 移 | 与主体保持约 2 米平行侧移，每秒约 50 厘米，主体居中 | 陪伴/行进 |
| 跟 | 与主体步速（约 1.2 米/秒）同步，前后左右偏差 ≤30 厘米 | 纪实临场 |
| 升 | 从腰部高度升至高空全景，约 6 秒 | 崇高/场面展开 |
| 降 | 高空降至主体上方约 1.5 米，约 3 秒停稳 | 收拢/聚焦 |
| 环绕 | 以主体为圆心、半径约 3 米，每秒约 30°，约 12 秒一周 | 噜噜已验证写法：环绕＋转速（每秒 5°）按段声明 |
| 固定 | 同侧固定，镜头基本不动 | 噜噜已验证；做菜线默认（「不加速、不炫技运镜」） |
| 跟焦/焦点转移 | 焦点从 A 平滑移到 B（rack focus） | 双层深度换主角时用 |
| 甩镜 | 快速横甩切换视点（whip pan） | 转场用，需声明落点 |

镜头规格写法（噜噜已验证）：焦段＋光圈（65mm/F4、50mm/F5.6、85mm/F4、40mm）；切镜三明治＝关系镜→短特写→关系镜，回切接同一次未完成的动作。

## 二、特殊场景参数（教程参考）

| 场景 | 写法 |
|---|---|
| **美食（做菜线可用）** | 50mm＋特写推进（0.5 倍速俯视），聚焦酱汁纹理与食材色泽 |
| 雨景 | 120fps 慢镜头＋手持微晃，从肩头移至积水 |
| 舞蹈 | 3–5 米半径环绕跟拍（腰高机位）＋节奏变速 |
| 夜景 | 约 30cm 低角平移＋15° 上扬（1–2 秒长曝光观感） |
| 跑步/运动 | 前跟拍（2–3 米距、肩下角度）＋动作起伏 |
| 微距（昆虫/小物） | 1:1 倍率，左右 10° 摇镜，浅景深虚化背景 |
| 风光 | 无人机环绕上升（约 50m→100m，每秒 5°） |
| 宠物跳跃 | 与主体平齐跟拍＋起跳瞬间快速对焦 |

## 三、景别层级定义（G/K 标注用）

| 景别 | 定义 | 常用缩写 |
|---|---|---|
| 远景 LS | 主体占比极小，环境氛围主导 | LS |
| 全景 WS | 完整主体＋核心环境，比例平衡 | WS |
| 中景 MS | 主要活动区域，动作＋局部环境兼顾 | MS |
| 近景 MCU | 压缩环境，细微动作/手势/眼神 | MCU |
| 特写 CU | 微小局部（眼/手/纹理），几乎排除环境 | CU |
| 大特写 ECU | 极小细节占满画面 | ECU |
| 俯拍 | 自上而下，呈现布局与包围关系 | — |
| 仰拍 | 自下而上，向上延伸感 | — |
| 微距 | 纹理极致放大，背景高度模糊 | — |

跨项目既有口径不混用：噜噜用 CU/MS/ECU＋焦段；做菜线用中文景别＋「保留结构」（如「中景、保留灶身」）。

## 四、情绪→运镜选镜对照（**选镜用，不进提示词**）

| 想传达 | 选 | 提示词里只写（动作部分） |
|---|---|---|
| 沉浸、递进 | 聚焦式推进 | 镜头从宽视野缓慢推近主体，止于细节 |
| 疏离、释然 | 抽离式后拉 | 镜头平稳后拉，主体占比缩小 |
| 追寻、好奇 | 探索式横摇 | 镜头水平缓摇，景物依次入画 |
| 陪伴、流动 | 陪伴式平移 | 镜头与主体平行等速移动 |
| 崇高、希望 | 升华式上升 | 低角度起，缓慢上升展开空间 |
| 压迫、聚焦 | 压抑式下降 | 高位缓慢下沉，收拢至主体 |
| 混乱、眩晕 | 迷幻式旋转 | 镜头绕主体旋转（按需，慎用） |
| 突发、爆发 | 急推/急拉 | 快速推近或拉开（情绪转折点） |
| 真实、慌乱 | 纪实式手持 | 手持轻微自然晃动（幅度写轻） |
| 觉醒、转折 | 静→动转换 | 先静止再起运镜 |

## 五、转场与衔接规则（进块 02 G/K 与 V 逐拍）

1. **出画/入画方向延续**：前一镜出画方向＝后一镜入画方向（同向剪辑）。
2. **匹配剪辑**：前后镜在形状/颜色上呼应。
3. **道具引导运镜**：镜头随观众注意的道具走（道具→桌面→手部→出口）。
4. **硬切声明**：段内切点写明（噜噜已验证：「镜号间按所述切点硬切，动作不重演」）。
5. **静帧预留动态**：G/K 是静帧时，可写「动态模糊」「运动轨迹暗示」「连续动作瞬间」为视频化留空间；K 帧构图优先级仍以静态清晰为先。

## 六、动作＋镜头反应词例（选摘，写逐拍时对照）

- 主角突然转头，镜头紧跟其动作快速切换
- 母亲轻抚孩子头发，特写两人温柔互动
- 舞者旋转跳跃，镜头缓慢环绕她的身体
- 演员回头一笑，镜头停在面部微表情
- 两人握手，镜头聚焦在交握的手上
- 人物奔跑穿过巷子，镜头从侧面跟随
- 孩子挥手告别，镜头缓慢推远
- 男孩拿起一张照片，眼神从疑惑转为悲伤
- 老者擦拭祖传茶壶，动作缓慢充满仪式感
- 老人坐在窗边慢慢翻书，阳光洒在书页上

写法要点：**动作是主语，镜头是反应**——先写清楚谁做什么（起点→终点、接触点），再写镜头怎么接；不要写「镜头怎样所以人物怎样」。完整词库见 R03 `分镜-画面提示词词库.txt`。
