# 提示词模板（骨架式，按类别一块一块定）

目标：每一类提示词有一张固定模板——段落骨架不变、公共块逐字复用、只换集级槽位，出品更稳定。设计原则与公共块见 [00-公共基底](00-公共基底.md)。

## 使用规则

1. 写任何一条提示词：先从 00 取全局块与已登记的线级/角色块，再套对应类别骨架填集级槽位。
2. 公共块只在一处维护：角色块改角色卡，全局/线级块改 00；类别模板只引用不改写。
3. 新翻车：检查器层（cookline 线记 `failures.json`）与提示词层（00 §六补负向句）同步记。
4. 做菜线的提示词由 cookline 生成：模板定稿后，把生成器的拼装逻辑回写成同一骨架，两边说同一种话（另行排期，不改现行卡）。
