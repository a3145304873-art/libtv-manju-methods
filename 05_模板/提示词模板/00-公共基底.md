# 00 · 提示词公共基底（骨架式）

> 2026-11-04 v1｜状态：proposed（用户逐块确认后升 confirmed）
> 来源：[心易·跨项目角色规范](../../08_作品/_共享角色/心易/README.md)、心易做菜 EP01 八条自检与 02_画布硬约束、[编排契约 §2](../../00_方法论/03-提示词与节点编排.md)、[R02 §2](../../07_格式参考/R02-大招演出提示词格式.md)、EP02 画布实际拼装文本、cookline 拦截器。
> 用途：所有类别提示词模板（V 视频段／G 分镜图／K 段首帧／A 角色图／S 场景图／P 道具图／大招）的公共块都从这里取。类别模板只写骨架与槽位，**块原文只维护一处**：角色相关在角色卡，跨角色通用的在本文件。两边都不复制，防漂移。

## 一、四层块模型

| 层 | 谁定 | 原文在哪 | 每集换吗 |
|---|---|---|---|
| 全局块 | 本文件 §五、§六 | 本文件 | 不换 |
| 线级块 | 本文件 §三、§四 登记 | 本文件 | 开线时登记，不逐集换 |
| 角色块 | 角色卡 | `08_作品/_共享角色/<角色名>/README.md` | 不换 |
| 集级槽位 | 类别模板的骨架 | 各类别模板 | 每集/每拍换 |

## 二、骨架总则（所有类别都遵守）

1. **段落顺序固定**，用【】小节头，按类别模板排；V 类按 [01 模板](01-V叙事视频段.md)五区：绑定 → 主体 → 规则 → 逐拍 → 收束。基底风格句是线级可选首槽（做菜线现行为无独立风格句）。不重排全局顺序。
2. **基底只写风格**（材质、色彩、光线、画幅、动作质感、运镜气质），不写剧情（R02 §2 同规）。
3. **公共块逐字复用**：角色句、眼睛句、禁令句不在每集重写、不改写、不缩写。
4. **负向必须带主语**（如"心易的黑瞳"），不写无主语负向误伤同场其他角色（角色卡 §三同规）。
5. **字幕只进 SRT**：提示词里只有禁令句，不出现任何具体字幕文案（EP01 V1 烧字教训）。
6. **只写看得见的**：动作、位置、接触点、数量、材质、光；不写"感觉/氛围/情绪"类抽象词。
7. 与[编排契约 §2](../../00_方法论/03-提示词与节点编排.md) 八模块的对应：基底↔风格证据；绑定↔输入绑定；场景状态+逐拍动作↔段落任务+空间与动作+段落边界；负向↔局部限制；声音↔声音；摄影与节奏在逐拍动作的景别/运镜槽内。

## 六、全局块 ②：通用负向库

用法：负向分**两层**——固定基座（每类一套、逐字全带，覆盖本库全部风险类＋§五禁令；cookline 线由生成器拼装，与 `failures.json` 检查项同步）＋ 本段追加（按本段风险点名 2–4 条）。角色特异性负向（如心易眼睛）从角色卡逐字取，不抄进本库。

| 风险类 | 负向/正写句 | 依据 |
|---|---|---|
| 肢体 | 只有两只短手、两只圆脚；不出现多余手臂、第三只手、多双手 | EP01 V2 四条手臂 |
| 道具数量 | {道具}只有{N}个，全程数量不变；不凭空出现、不凭空消失；不同时出现在两处 | EP01 三颗土豆 |
| 道具替代 | {工具}是{形状}，不是勺子/刀/锅铲（点名替代物） | EP01 木棍变木勺 |
| 道具入场 | 后面要用的道具首帧就在画面里，或由可见动作带入；取出前先有开盖/开箱动作 | EP02 盐碟、F30 |
| 景别拆景 | 正写：{景别}、保留{主体结构}；负向：{会拆掉的形态}（如"火塘/石圈/锅放地上"） | EP01 V3 灶变火塘 |
| 动作完整 | 取→放每一步都有镜头；用"拿住/接住/举到"，不用"滚/落" | EP01 土豆滚落、V3 凭空出现 |
| 动作节奏 | 不全程慢动作；按时间表推进，不平均分拍 | C13 |
| 动线 | 本拍起点接上拍终点；离开{台地}后不回拍；全身背影走路改特写或正面/3-4 中景 | EP01 V2 回溪边、长手 |
| 参考打架 | 构图以 {K帧} 为准；不把上一段整帧当构图参考（补一致性裁角色不挂整帧） | 心易做菜 §三 |

新翻车处理：cookline 线先记 `failures.json`（检查器层），同时在本库补一行负向句（提示词层）——两层同步，只记一层不算完。

## 七、角色块（原文不在本文件）

取文规则：`08_作品/_共享角色/<角色名>/README.md` 是唯一来源。组装顺序（与 EP02 实际拼装一致）：

1. 外形锁句（卡 §二表格逐条转写为一段正写）
2. 眼睛正写块（如【心易眼睛·仅限心易】，卡 §三，逐字）
3. 表演约束（情绪走身体：歪头/点头/蹲/耳朵动；中景为主，不做眼睛大特写）
4. 声音约束（如心易：不说话，只发咔啵 2–4 声，后期配）

其他角色豁免句照角色卡写（黄蛋正常眼睛不受限）；多角色同场时，负向主语逐个点名。

超警戒先压字（删重复修饰），再谈加约束；公共块是复用块，压字不压公共块。模型参数以 `libtv model <名>` 实查 schema 为准，历史记录仅说明当时口径。

- [ ] §五禁令在场；全文无具体字幕文案
