## 2. 通用基底（放在开头；只写风格，不写剧情）

```text
【通用基底】[类型/质感]，[色调/主光]，[画幅/帧率]，[动作质感]，[运镜气质]，[负向：无字幕/无UI/无水印/无穿模]
```

## 3. 五拍（15s 默认；4 拍/3 拍按 §5 删）

| 拍 | 时间 | 景别+运镜 | 主体动作（起点→终点） | 主推特效层 | 声音 |
|---|---|---|---|---|---|
| 1 蓄势 | 0–2s | 特写（眼/手/剑格） |  | L2 身器 | 环境声抽空、低频、剑鸣 |
| 2 展开 | 2–5s | 拉远/环绕/仰拍 |  | L1 场 | 风、符文、金属共振 |
| 3 释放 | 5–9s | 跟随发力方向 |  | L3 发 | 破空、龙吟、雷鸣 |
| 4 碰撞 | 9–12s | 中景/特写 |  | L4 撞 | 爆响 + 低频下潜 |
| 5 收势 | 12–15s | 远景/定镜 |  | L5 环境余韵 | 余响、风回来 |

每一拍只填一个主动作；其余层写“响应”，不写“同时爆发”。

## 4. 五层特效栈（选 1 主 + 2 辅，不要全满）

| 层 | 本次用什么 | 主/辅 | 写法（动词+方向+结果） |
|---|---|---|---|
| L1 场（阵法/天象/领域） |  |  |  |
| L2 身器（护盾/武器形态/蓄力） |  |  |  |
| L3 发（剑雨/光束/掌风/龙） |  |  |  |
| L4 撞（碰撞核心/冲击波/受击） |  |  |  |
| L5 环境余韵（尘/水/云/衣袍/旗幡） |  |  |  |

常用模块（按需取，不要全部堆上）：

- **符文剑阵**：脚下铺开多层魔法阵与神圣几何图形，逐符文引燃，金色符文顺着笔画亮起，灵气粒子受向内旋涌之力汇聚成剑阵。
- **流动黑气**：释放墨色暗影卷须与吸光暗影团，暗影沿石阶和柱面蔓延并吸收周围光线。
- **剑阵发射**：剑阵发射时，相干光束与带状剑迹分层交错。
- **黑盾生成**：暗影护盾产生，缓慢凝实。
- **技能碰撞**：两股力量对撞形成不稳定光束碰撞核心，云雾被压力波排开，悬浮尘埃、衣袍和旗幡按距离延迟响应。
- **剑雨/剑冢**：百万仙剑悬浮列阵 → 拖曳流光倾泻 → 斜插遍地成剑冢。
- **雷阵**：长剑悬停为阵眼 → 太极/八卦阵展开 → 雷光汇聚剑尖 → 下劈。
- **领域收束**：琴/棋/书/墨逐层展开 → 最终收进一幅水墨画卷/棋盘。

## 4.5 玄幻仙侠专项校准（可选，参考 I07）

先选这一场的主任务，不默认套用攻防轮数或反杀剧情：

| 分支 | 重点写清 | 结果承载 |
|---|---|---|
| 展示型大招 | 人物/兵器辨认、力量来源、招式规则与尺度 | 地面、结界、天象或遗物承受力量 |
| 对抗斗法 | 双方位置、先后手、攻击方向、阻挡/闪避/受击 | 对手姿态、护盾变化、场景破坏 |
| 群战/法阵/法相 | 画面几何、人物比例尺、群体层次、阵法形成顺序、机位 | 阵形变化、战场空间或法相的状态 |

|---|---|
| 力量从哪里发出，沿什么方向运动 |  |
| 明确目标与命中/阻挡位置 |  |

能量效果写成可观察的形态和变化（附着、脱体、成群、尾流等），再指定主材质与辅助响应。固定比例、数值、开场撞击、反杀和攻防轮数均按来源条件判断，不能自动变成本场要求。来源及证据边界见 [I07](../03_行业Skill/I07-漫剧老李玄幻仙侠打戏.md)。

## 5. 时长变体

### 15s（4 拍，展示型，无明确对手）

```text
0-2秒｜蓄势：[特写+运镜]；[蓄力动作]；[L2]；[声音]
2-7秒｜展开/释放：[拉远/环绕]；[领域或剑雨]；[L1+L3]；[声音]
7-12秒｜巅峰：[震屏/跟随]；[命中地面/结界]；[L4]；[声音]
12-15秒｜收势：[远景定镜]；[回鞘/负手/剑冢]；[L5]；[余响]
```

### 15s（5 拍，有对手/有碰撞）

用 §3 的五拍表。

### 5–8s（3 拍，短版）

```text
0-1.5秒｜蓄势：[特写]；[认人/蓄力]
1.5-4秒｜出手：[中景/跟随]；[一击命中]
4-6秒｜结果：[远景/定格]；[坑/剑冢/回鞘]
```

## 6. 负向（按本次风险点名）

```text
无字幕、无UI、无水印、无Logo；不出现多余手臂/第三只手/多双手；武器只有[数量]把，不凭空出现/消失；不换左右手；不穿模；不把剑画成刀/把刀画成剑；不把光刃画成实体剑；不全程慢动作；不平均分拍。
```

按兵器补充（通用要领；项目内可再挂各自的招式库，工艺入口见 [I05 古典武侠流程](../03_行业Skill/I05-古典武侠流程.md)）：

- 剑：不握在刃根、不从掌心穿出、不折腕、该用压把时不使剑尖下垂。
- 刀：不刃口朝内、不刀背当刃、不双手握单手刀。
- 枪：不握枪杆中段、不双手过近、不枪身弯曲。

## 7. 交付前检查

- [ ] 五拍/三拍各有起止姿态，能接上下拍。
- [ ] 蓄势拍有人物镜头；不是纯特效。
- [ ] 展开拍读得出空间：人、阵、镜头方向。
- [ ] 释放拍有发力起点（脚/腰/手/剑）。
- [ ] 碰撞拍双方都有反应；单边打地面也有反作用。
- [ ] 环境响应有延迟/方向，不是全屏同时动。
- [ ] 收势留下可见结果（坑/剑冢/裂缝/画卷/回鞘）。
- [ ] 武器/手数量锁定，负向点名。
- [ ] 基底只写风格；剧情不在基底里。
- [ ] 需要台词/字幕时另记，不写进画面。
- [ ] 声音每拍有主声，收势有余响。
- [ ] 时长按语义分配，不平均分（C13）。
