# 兵器到大招（空白模板）

> 用法：拿到一件兵器，先填 §1 的 6 个槽，再套 [R02 的五拍/四拍](../07_格式参考/R02-大招演出提示词格式.md)（C18）。模板只给判断顺序，不预设题材。
> 核心：**兵器的形制决定它怎么出手，属性决定它留下什么，握法决定蓄势时藏在哪里。**

## 1. 六槽（先填这个）

| 槽 | 本次填写 | 它决定什么 |
|---|---|---|
| 兵器/形制 |  | 出手方式、镜头距离、能不能做“阵” |
| 属性/材质 |  | 特效的颜色、粒子、碰撞结果 |
| 握法/发力链 |  | 蓄势时手在哪、力从哪来、负向写什么 |
| 角色/场景 |  | 领域长什么样、收势留下什么 |
| 出手方向/明确目标 |  | 招式朝哪运动、作用于谁/何处、如何显示受力 |
| 尺度参照/摄影机位置（大场面选填） |  | 让观众读懂阵法、法相或剑群的体量和空间关系 |
| 大招名（暂定） |  | 只用于文档；不要写进画面 |
| 时长/画幅 |  | 3 拍（6–8s）还是 5 拍（12–15s） |

## 2. 四步判断

换武器时：只改 §1 的六槽和 §3 的倾向行，**五拍/四拍的结构不变**。先定“这件兵器怎么出手”，再定“它留下什么”，最后才写形容词。

1. **形制 → 出手方式**
   - 长兵（枪/棍/长刀）：镜头拉远，先给“长度”和“范围”，大招偏“扫/砸/一点突破”。
   - 短兵（剑/刀/双刀/扇）：镜头贴近，先给“刃”和“手”，大招偏“斩/刺/连击”。
   - 软兵（鞭/索）：镜头环绕，先给“轨迹”，大招偏“缠/抽/领域”。
   - 远程（弓/暗器）：留出空间，先给“瞄准”，大招偏“一箭/箭雨/贯穿”。
   - 拳掌：没有兵器，先给“发力链”，大招偏“震地/掌风/气劲”。

2. **属性 → 特效层**
   - 冰/霜：冰裂纹、霜爬、冰晶对撞；收势留冰坑。
   - 雷：雷阵、雷光、焦土；收势留雷击坑。
   - 火：火线、爆炸、余烬；收势留焦黑。
   - 墨/暗：墨线、墨龙、墨浪；收势留墨痕/画卷。
   - 金/光：光束、金属粒子、符文；收势留光斑/裂缝。
   - 一件兵器最多主推 **两种** 属性；第三种只做点缀。

3. **握法 → 蓄势**
   - 写清：哪只手、虎口在哪、剑柄占全长多少、腕直不直。
   - 另一只手做什么（垂在身侧/掐剑诀/扶鞘），避免“多一只手”或“换手”。
   - 负向点名该兵器的典型错法（见 §4）。

4. **角色/场景 → 领域与收势**
   - 领域要跟角色/兵器有关系，不是随便加一个魔法阵。
   - 收势必须留下“这里发生过什么”：坑/剑冢/裂缝/焦土/画卷/回鞘。
   - 仙侠大招补问：力量从哪里发出、沿什么方向、打到哪个明确目标、目标/环境怎样反馈？群战或法相再补人物比例尺、画面几何与摄影机观察位。

## 3. 兵器 → 大招倾向（速查）

| 兵器 | 大招倾向 | 主推层 | 收势 | 常见错法 |
|---|---|---|---|---|
| 剑 | 剑阵/剑雨/墨龙；劈或刺 | L1 场 + L3 发 | 剑冢/回鞘/冰裂坑 | 剑整体发光、第二把剑、换左手 |
| 刀 | 刀气墙/横扫/巨刃 | L3 发 + L4 撞 | 裂地/收刀 | 刃口朝内、刀变剑 |
| 枪 | 一点突破/枪雨/枪龙 | L3 发 | 钉地/回枪 | 握枪杆中段、枪身弯 |
| 棍 | 横扫/定海/山崩 | L4 撞 | 地裂/拄棍 | 双手距离过近、棍变软 |
| 双刀 | 交叉斩/双刃风暴 | L3 发 | 双刀交叉/回鞘 | 多出一把刀、左右手互换 |
| 弓 | 一箭/箭雨/贯穿 | L3 发 | 箭钉/收弓 | 弓弦不拉满、箭反向 |
| 扇 | 开扇成阵/风卷 | L1 场 | 合扇/收势 | 扇骨变剑、扇面变盾 |
| 鞭/软兵 | 缠/抽/领域 | L1 场 + L3 发 | 鞭梢回手 | 鞭身变直棍、缠住自己 |
| 拳掌 | 掌风/震地/气劲 | L4 撞 | 收掌/负手 | 多手、拳变爪 |

## 4. 负向（按兵器点名）

```text
无字幕、无UI、无水印、无Logo；不出现多余手臂/第三只手/多双手；武器只有[数量]件，不凭空出现/消失；不换左右手；不穿模；不整体发光（只留一道高光）；不出现[与设定冲突的颜色]；不把[兵器]画成[替代物]。
```

- 剑：不握在刃根、不从掌心穿出、不折腕、该用压把时不使剑尖下垂。
- 刀：不刃口朝内、不刀背当刃、不双手握单手刀。
- 枪：不握枪杆中段、不双手过近、不枪身弯曲。
- 弓：不三指反扣、不弓弦松、不箭尖朝自己。
- 鞭：不鞭身变直、不缠住自己的手。

## 5. 短版/长版怎么选

| 条件 | 选 |
|---|---|
| 6–8s、一条或两条 4s 段、只展示一个动作 | **3–4 拍**：蓄势 → 阵开/起手 → 命中 → 收势 |
| 12–15s、要“领域 + 连续释放 + 碰撞 + 余韵” | **5 拍**：蓄势 → 展开 → 释放 → 碰撞 → 收势 |
| 已有 3s 冲击帧 | 把 3s 当“命中拍”插入，不要重做全部 |

## 6. 交付前检查

- [ ] 六槽填完；兵器只有一件，手只有两只。
- [ ] 蓄势拍能看出“这是什么兵器”。
- [ ] 出手方式符合形制（剑不砸、枪不扫、弓不近身）。
- [ ] 属性不超过两种；颜色不与角色设定冲突。
- [ ] 命中拍双方都有反应；打地面也有反作用。
- [ ] 收势留下可见结果。
- [ ] 大招写清出手方向、明确目标和受力结果；大场面有尺度参照且结尾空间关系可读。
- [ ] 负向点名了该兵器的典型错法。
- [ ] 时长按动作定，不平均分（C13）。
