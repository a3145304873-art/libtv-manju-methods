# 实际任务模板

模板是通用空表，不是已创建作品或已确认参考。按本次任务实际需要复制到作品工作区。

- [制作任务](制作任务.md)：项目、集、场、镜与作者约束。
- [阶段确认](阶段确认.json)：当前阶段主/辅参考及范围。
- [镜头与节点](镜头与节点.json)：动作、输入、实际参数、输出与依赖。
- [返修记录](返修记录.json)：问题、源版本、区间与对照。
- [剪辑使用](剪辑使用.json)：候选到成片的采用区间与声画计划。
- [新来源接入](新来源接入.md)：以后新工作流或 Skill 按同一逻辑整理。
- [方向设计标准](方向设计标准/README.md)：总纲、角色、场景、道具与分段展开；由 R01 提取结构，缺失部分的建议补充另行标注。

未知字段保持 null 或空列表，并说明原因。模板中的 proposed/unreviewed 不能自动升级为确认或通过。
