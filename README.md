后续新增：**R01 方向设计格式参考**，由用户提供的文档包提取格式与逻辑，原题材正文未导入。[查看格式拆解与空白模板](07_格式参考/R01-方向设计格式与逻辑.md)。**W10 锅气交响美食短片**（2026-10-29 按统一接入流程入库，首个无角色美食广告案例，含节点 JSON 与拆解，见[案例目录](02_案例库/README.md)）。**W11 邵氏英语单词一步成片模板**（2026-10-29 自在线画布采集入库，首个可复用模板画布案例，新增 C17，见[案例目录](02_案例库/README.md)）。**I06 Monet 画布搭建方法**（2026-10-29 入库的内部生产规范，用户已确认后续画布一律按此格式搭建，见[行业 Skill 目录](03_行业Skill/README.md)）。**R02 大招演出提示词格式**（2026-11-03 入库，9 张提示词截图文本级提取，新增 C18 五拍结构与五层特效栈，见[格式参考](07_格式参考/R02-大招演出提示词格式.md)）。**I09 故事转手绘动画**（2026-11-04 固定 GitHub commit 快照；提取故事节拍与逐场一致性方法，供可爱角色生活片做方案参考；未采用其画风或运行环境，见[行业 Skill 目录](03_行业Skill/README.md)）。**I10/I11 做菜分镜参考**（2026-11-04 固定 GitHub commit；分别补逐段分镜/提示词连续性、先做菜品动作参考板的机制；与做菜线规划卡组合使用，未复现来源生成流程，见[行业 Skill 目录](03_行业Skill/README.md)）。

Agent 协作入口：[AGENTS.md](AGENTS.md)，规定任务路由、每阶段确认参考、方向设计、新来源入库、证据边界与检查方式。

## 内容与使用边界

- 原始资料采用定向复制的文件级克隆，保存来源记录和 SHA-256；没有可供这五份文档使用的上游仓库 URL，未虚构远程仓库或执行整仓克隆。索引见 [source-manifest.json](source-manifest.json)。
- 仅包含方法文档、节点 JSON 与来源原文。图片、视频、音频、已制作角色、剧本、季纲、项目品牌素材、账号配置与凭据均未复制。原始快照中的参考媒体 URL 是来源证据，未下载为资产。**例外**：`08_作品/` 是 2026-10-29 用户指定的作品区，该目录下允许存放资产、画布与成片；其余方法层仍不含任何制作媒体。
- 十份案例是来源样本，里面的主体和故事属于原例；不构成本库的原创选题或默认人物。通用方法和模板使用可替换变量。
- 每个制作阶段先确认参考；确认一次后在约定范围内推进，主要参考/风格/目标改变时再确认。资料入库不自动启动制作。
- 本库有八个项目内 Skill 入口，位于 [.agents/skills](.agents/skills/README.md)：一个总入口、五个工艺适配入口，以及[英语故事画布](.agents/skills/english-story-canvas/SKILL.md)、[做菜线](.agents/skills/cooking-line/SKILL.md)两个生产插件。它们是本库新写的适配版；五份原始 Skill 作为参考原文保留，不冒充依赖齐全的官方安装包。
- 不复制较早的外部制作仓库，不安装全局 Skill，不改系统配置，不提交远端任务。实际平台操作需在目标环境核对 CLI 与模型能力。
