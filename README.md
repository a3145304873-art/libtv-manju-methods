## 内容与使用边界

- 原始资料采用定向复制的文件级克隆，保存来源记录和 SHA-256；没有可供这五份文档使用的上游仓库 URL，未虚构远程仓库或执行整仓克隆。索引见 [source-manifest.json](source-manifest.json)。
- 仅包含方法文档、节点 JSON 与来源原文。图片、视频、音频、已制作角色、剧本、季纲、项目品牌素材、账号配置与凭据均未复制。原始快照中的参考媒体 URL 是来源证据，未下载为资产。
- 十份案例是来源样本，里面的主体和故事属于原例；不构成本库的原创选题或默认人物。通用方法和模板使用可替换变量。
- 每个制作阶段先确认参考；确认一次后在约定范围内推进，主要参考/风格/目标改变时再确认。资料入库不自动启动制作。
- 本库有六个项目内 Skill 入口，位于 [.agents/skills](.agents/skills/README.md)：一个总入口和五个工艺适配入口。它们是本库新写的适配版；五份原始 Skill 作为参考原文保留，不冒充依赖齐全的官方安装包。
- 不复制较早的外部制作仓库，不安装全局 Skill，不改系统配置，不提交远端任务。实际平台操作需在目标环境核对 CLI 与模型能力。

已整理：来源归档、阶段路由、漫剧生产链、能力卡、提示词/节点契约、任务模板及检查工具。九份快照合计 671 节点、260 个视频节点和 109 个图片节点含非空 `params.prompt`（基线 628/254/95 + W10 的 43/6/14）；额外一例（W08）只有文档索引。统计不表示已采用镜头数。

尚未完成：所有原例媒体播放、采用版确认、全部方法复现、换主体迁移和成片质量验收。I04/I05 的部分外部依赖未随文档提供，详见行业目录。本库提供完整的方法与维护入口，原始技能依赖和成片效果仍按实际证据记录。
