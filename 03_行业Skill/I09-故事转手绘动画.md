## 观察到的流程

Skill 的目标是把中文故事或有序图片做成无声手绘视频。其可借鉴的流程骨架是：

1. 先确定故事事实和按序素材；遇到代词指向、时间跳跃、角色年龄等歧义先消解。
2. 先做角色表，再按节拍拆故事；默认以完整句为拍，长句在叙事转折处拆分。
3. 每个场景制作“字幕＋插画”的完整画面母版，逐项核对中文文字、角色身份和参考图一致性。
4. 先交付无声画面，配音、音乐另行后期处理；完成时按输出规格检查成片。

Skill 还提供固定的彩铅日记画风、形状/构图规则、风格资产和 Remotion 脚本。这些属于该仓库的手绘路线，**不迁移为心易做菜的画风、声音或工具规定**。

## 对可爱角色做饭日常的适用部分

这份 Skill 不是烹饪 Skill，但可补“故事怎么组织”的问题：先定一条简单日常意图，再拆成可读的动作节拍；先锁角色和场景连续性，再逐拍生成画面；把画面、字幕/文字和后期声音分开核对。结合本库已有秃秃拉片，适配为：

`生活触发/想吃什么 → 取食材 → 处理 → 烹煮 → 揭晓 → 享用或分享 → 一个日常收尾`

它补的是**叙事规划、角色一致性和逐场校核**，不能代替已有 cookline 的菜谱卡、状态账本、分镜闸门、手部/道具连续性与人工审美检查。对于心易，必须由 [跨项目角色规范](../08_作品/_共享角色/心易/README.md) 管理：心易不说人话、不写内心独白、不让旁白代言；声音只用固定“咔啵”；情绪通过身体动作表达。外部片中的拟人化台词和心声字幕不适用。
