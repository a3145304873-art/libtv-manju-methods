# 梳理 03｜爆款视频复刻 · 工艺逻辑

> 原文：[原文/03-爆款视频复刻.md](../04_原始资料/industry-skills/I03/source.md.txt)｜梳理日期 2026-10-21（二次调整：剔除问询交互与画布解析工具，只留拆解与改写逻辑）｜状态：纸面拆解，未实测。

## 方法主干

成片 → 故事板拆解（拉片）→ 逐镜改写替换内容 → 全局一致性梳理 + 按节奏合并 → 按片段生成。**五份文档中唯一"以已有成片为输入"的方法**，可作为参考视频结构化拆解与主体改写的方法候选。

## 拉片故事板字段表（拆对标片的标准字段）

镜号｜时间｜画面描述｜画面风格｜叙事内容｜景别｜摄像机角度｜摄像机运动｜焦距与景深｜光线｜背景音乐｜人声/音效｜图像生成提示词｜视频生成提示词｜关键帧。

- **口播纪律**：有人对镜头说话的镜头，必须在"人声/音效"字段完整记录台词，并在"画面描述"标注"人物有口播"。

## 逐镜改写规则

- **音频**：未提及 → 完全保留原片，不改写；口播镜头的视频提示词必写"人物面对镜头说话，口型与台词同步"+ 台词原文；替换人物时台词保留、口播动作迁移到新人物。
- **时长**：每镜严格等于原片该镜实际时长（原片 3.2s 就写 3.2s），不自动延长或补齐。
- **平面设计融合**：拉片中图像提示词里的字体排版/Logo/图形/色块/动态文字，必须完整融进视频生成提示词（字体风格/排版位置/配色/图形细节/动效方式），不单独出设计稿。
- **每镜输出固定格式**：画面描述 → 画面风格 → 景别 → 摄像机角度 → 运动 → 焦距景深 → 光线 → 人声/音效 → 视频提示词 → 替换说明（无改动注明"无改动"）。
- **视频提示词骨架**：景别与镜头类型，主体描述，动作，环境，光线，摄像机运动，焦距与景深，风格关键词，情绪基调，时长：Xs。全中文。

## 合并与节奏规则

- **全局一致性梳理（合并生成前必做）**：跨镜头检查人物外观（服装颜色/款式/配饰）、场景道具（颜色/形态/位置）、环境背景（色调/光线）的描述漂移；同一场景同一人物连续出现且非换装创意 → **以第一镜描述为基准统一后续所有描述，不得自行重新描述**；换装/变身/对比创意 → 保留差异。
- **合并节奏**：总时长 ≤15s 无论有无硬切全部合并为一条；>15s 按 15s 分组、组内能并则并（相邻硬切可拆，但优先凑满 15s）。
- **取整规则**：≤15s 严格复刻原片总长不裁剪；>15s 尾段 ≥4s 保留、<4s 舍弃（17s→15s；21s→15s+6s）。
- **合并提示词必须重写**：把各镜动作、场景按时间顺序串联成一条完整连续描述，不得只列镜号或保留各镜原始 prompt；画幅与清晰度写进每条。
- **片段数 = 生成数**：合并方案定了几个片段就生成几个，不得回退成原始镜头数散生成。
- **多片段音频**：每条片段提示词必写"保留音效、环境音、人声，不生成背景音乐"，BGM 全部片段生成后统一加，防各段自带音乐合成后断续。

## BGM 处理逻辑

- 单片段：BGM 风格要求直接写进视频提示词，一并生成。
- 多片段：生成完毕后单独出 BGM 提示词，四要素——风格（复刻原片或指定）/ 情绪曲线（开场→中段→结尾）/ 参考描述（BPM 范围、乐器构成、氛围关键词）/ 总时长。默认完全复刻原片音乐风格。

## 借鉴要点 / 不搬

- 借鉴：拉片字段表（对标样本结构化拆解直接可用）、时长三纪律（单镜=原片时长 / ≤15s 不裁 / 尾段 <4s 舍）、一致性预检、"片段数=生成数"约束、BGM 提示词四要素。
- 不搬：问询流程与画布解析工具调用。
