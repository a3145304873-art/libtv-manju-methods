# 梳理 05｜古典武侠电影全流程导演（hujinquanwuxia）· 工艺逻辑

> 原文：[原文/05-hujinquanwuxia.md](../04_原始资料/industry-skills/I05/source.md.txt)｜梳理日期 2026-10-21（二次调整：剔除阶段确认门/状态卡等 agent 交互与分辨率工具参数）｜状态：纸面拆解，未实测。⚠️ 原文引用 `references/*.md` 十余个外部文件未随文档提供，提示词细节层不完整。

## 核心原则

**"恰好够用"的生产深度**：不因有剧本就默认重做资产，不因没剧本就自动建完整资产库；资产、首帧、场景图全部按触发条件开启，默认关闭。五份文档中唯一以**剧本路由与分镜纪律**为主体的方法。

## 剧本路由（输入四级分流）

| 输入成熟度 | 处理逻辑 |
|---|---|
| A 完整剧本 | 锁定场次、人物关系、台词、动作、结局和不可改事实；不擅自删改；按场次/语义/台词/表演逐单元判断时长 |
| B 简单想法 | 补成最短可执行节拍：触发 → 判断 → 动作 → 结果 → 余味；补写内容明确标"自动补齐假设"；**Agent 补的不算用户剧本** |
| C 模糊题材 | 先给 2-3 个明显不同的一句话方向（人物/冲突/核心视觉/结尾），选定后再成节拍 |
| D 单镜 | 直接写单条提示词：镜头目的、画幅、时长、动作起止、风格、声音 |

所有路线先写**创作脊柱**句式：

> 谁，在什么空间，因为看见或听见什么，判断发生怎样的变化，于是做出什么动作，最后停在哪个有余味的画面。

## 风格锁（提示词层）

三段式文字锁，不写空风格名：**前置风格身份锚 → 正文可见证据 → 结尾防稀释锁**。要求每段风格有"可见证据"（构图/光线/调度上的具体呈现），而非只在开头写风格名。验证方式：用一条代表性测试片验证文字锁；严格路线先做三张定标图（空间远景 / 中景人物关系 / 动作关键帧）定基准再批量。可融合风格时限定"主风格 ≥80%，辅助 ≤20%"并列出允许借用的具体元素。

## 分镜逻辑

- **九宫格接触表**：严格 3×3、每格继承成片画幅，按阅读顺序表达连续九个节拍（不足九镜用建立/触发/反应/动作/结果节拍占位）；**只是计划审核图，不是生成素材**——图内不出编号/字幕/对白气泡（外部表格用 G01-G09 对照），**绝不把整张九宫格喂给视频生成**，要引用只能裁单格。
- **画幅影响调度**：16:9 横向对峙与山水调度；9:16 减少横向并排、改用前中后景与纵深路线；2.39:1 横向留白与群像；4:3 建筑框景与集中人物关系；1:1 中心关系与短动作。
- **时长纪律**：按内容语义逐单元判时长；模型只有固定档位时选"不短于需求"的最近档位，**禁止为凑档位把所有片段拉平成相同 5s/10s**。

## 资产逻辑（恰好够用，触发条件制）

- **1+3 角色资产板**：只给"跨多段、会被清楚辨认、需固定服装武器"的主要角色——左侧脸部正面特写 + 右侧全身正视/90° 侧视/背视。
- 一次性角色、远景群演、背影：只用**文字身份锚**（提示词中每条完整重复身份描述）。
- 道具/武器：只在推动剧情、参与交互、反复特写、跨镜必须一致时才建。
- **场景资产默认 0**（没有用户完整剧本时禁止生成）；**首帧默认 0**，仅多人精确站位、兵器接触起点、上镜结尾强继承、特殊构图、直生反复失败的高风险镜使用。
- 新建资产统一中性浅灰纯色底（#B8B8B8 左右，无渐变纹理文字水印）；已有资产不因底色/格式不同强制重做。

## 镜头动作与打斗逻辑

- **打斗前置五件**：叙事目标、文字空间图、轴线、动作节拍、拆镜——先规划后生成；**单条视频不承担完整连续打斗**。
- **动作四要素**：每个动作写触发、起点、终点、重量，并留"可接下一镜的结尾"。
- 两种风格的声音节奏参考：胡金铨=空间、停顿、短爆发、声音留白；邵氏=棚景调度、完整身体动作、短促变焦、复古锣鼓节拍。

## 逐镜提示词检查清单

1. 人数、身份、服装、武器、关键道具稳定；未用资产时文字身份锚每条完整重复。
2. 场景文字锚、左右关系、光源、画幅、动作轴线连续——**没有场景资产也不省略空间描述**。
3. 实际生成参数已记录；生成分辨率与导出分辨率分开记，后期超分明确标注、不冒充原生。
4. 动作有触发/起点/终点/重量，结尾可接下一镜。
5. 无多手、多剑、穿模、瞬移、漂浮、人物互换、背景无故重构。
6. 风格有可见证据而非只有风格名。

返修只动失败变量；错误来自上游资产或风格定标时，先修上游再更新受影响镜头。

## 借鉴要点 / 不搬

- 借鉴：输入四级路由、创作脊柱句式、风格锁三段式、九宫格"只审核不生成"定位、资产触发条件制与文字锚点档位、打斗拆镜纪律、动作四要素、逐镜检查清单、分辨率诚信。
- 不搬：武侠题材美学（references 缺失且题材专属）、阶段确认门与状态卡等交互设计。
