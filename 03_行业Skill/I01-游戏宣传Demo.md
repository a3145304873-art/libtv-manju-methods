## 适用范围

原创/自有游戏的宣传 Demo。两种剧本结构：① 三段式实机演示 45s（引导/剧情/战斗各 15s）；② 开放世界类 gameplay 短片 30-60s。

## 剧本与叙事结构逻辑

1. **三段式秒级 timeline**：Video A（0-3s 封面与按钮交互 → 3-10s 选人/技能展示 → 10-15s 第一人称入景）；Video B（NPC 对话 → 场景追踪到地标）；Video C（实机战斗 → 结算）。每段 15s 内部有完整起承转合，三段功能递进：认识系统 → 进入世界 → 验证核心玩法。
2. **玩法二叙事二选一**：
   - 结构 A 快节奏事件三段：氛围铺垫（广角俯视、远处警笛，"平静下的暗流"）→ 冲突失控（局部特写、追逐、社媒手持视角，节奏由平缓到高频）→ 悬念悬挂（特写眼神/车门关闭/倒后镜，音乐突歇只留引擎、呼吸、单调音效）。
   - 结构 B 单镜生活切片：5-12s 一镜到底，一件事从开始到结束。
3. **悬念收尾设计**：画面收在"未完成动作/反应特写"上，声音先抽空——用声音落差制造钩子。

## 镜头设计逻辑

- **单镜生活切片纪律**：只留 1 个主行为（加油/递热狗/扫码/点烟）+ 1 种运镜（慢推/侧移跟拍/固定/轻微手持）；禁复合动作、禁时空切换——"动作绝不复杂，镜头绝不乱切"。
- **多切镜 4-Cut 公式**：把一个事件写成一条 15s prompt 内部切四镜——Shot1 环境与威胁 / Shot2 动作细节特写（踩油门、拉枪栓）/ Shot3 反应与阻碍（受阻、路人慌乱、警灯）/ Shot4 悬念终局（逃脱或撞击定格）。每镜只承载 1 个信息点；景别在全景/车内/低机位/特写/社媒画面间交替。理由：单次 15s 生成正是模型产出内部切镜与自然转场的最优区间。
- **五类专有视角**：类 gameplay 第三人称（机位低、偏侧、角色身后、轻微延迟、隐去 UI）；车载/车旁（副驾肩后、后视镜、后保险杠极低机位）；社媒竖屏（手持直播、抖动失焦，可切 9:16 插入）；监控/bodycam（固定广角压缩噪点 / 强晃动鱼眼）；亲密逃亡双人（车窗、门框、百叶窗遮挡构图）。
- **空间连续性**：高动态切镜必须同街区、同时间、同光影、同运动方向，防跳跃穿帮。

## 提示词模板与句式

- **视频 prompt 结构**：`[Camera: 机位] <<<参考图占位>>> [Character/Action 主体动作] [Background 环境] [Audio: 声学标记]`——运动堆栈顺序固定为 相机 → 主体动作 → 空间环境 → 声音。标记约定：对白 `{…}`、音乐氛围 `(…)`、动作音效 `<…>`；尾部固定负向词 `no music, no subtitles, no logo, no branding`。
- **角色 3D 渲染模板（EN）**：
  > A 3D game character render of [character name], a [gender] with [hair/face features], wearing [outfit], open-world game style, 3D game model, third-person game gameplay character, Unreal Engine 5 render, high fidelity, realistic game engine shaders, wet skin texture, high contrast tropical lighting.
  结构要点：风格定语（3D game / third-person / UE render）+ 身份 + 外形 + 服装 + 材质词 + 光照词，全身与侧面特写横排同图。
- **四色调口诀**（现成色彩短语组）：霓虹夜晚 pink/purple neon + wet asphalt reflections + cyan highlights；热带黄昏 golden hour + teal sea + palm silhouettes；晨雾沼泽 olive green + dense fog + searchlight beam；白日 harsh sunlight + overexposed edges + hard shadows + heat shimmer。
- **UI 锁定指令（提示词层）**：先记录 HUD 各元素（血条/技能栏/对话框）的位置，在视频提示词中声明为"禁止形变区"——禁止位移、伪影、形变；对话 UI "绝对清晰、不颤抖、不模糊，文字与角色状态同步"。
- **连续性写法**：生成下一段时延续上一段的主体状态描述（车辆颜色、受损程度、光影），保证跨段平滑。
- **配方库组织法**：结构公式 + 可改词实例（单镜 4 例、多切镜 3 例、8 个高频镜头配方）——"公式固化、内容留变量"的组织方式值得沿用。

## 声音与节奏逻辑

- **音画分离**：视频提示词不写 BGM（负向词兜底），配乐后期统一，防重叠。
- **剪辑三段节奏**：开场 4-5s 平缓、淡入淡出；中段 0.8-1.5s 一剪、硬切+闪白；结尾拉长到 6-8s、淡出至黑。
- **三音轨设计**：SFX 与动作帧严格对齐（碰撞瞬间音量 +6dB 加低震）；对话 Ducking（BGM −12dB，对话前 0.3s 降、结束后 0.5s 回升）；结尾 10s BGM 抽空或低通，只留呼吸与警笛残音。

## 用户照片→角色（提示词层）

只提取"性别 + 大致形象气质"输出极简英文特征词（如 `A Hispanic male in his 20s, with sharp facial features and determined eyes`），不写发型/妆容/服装/配饰——细节交给图生图自适应，避免提示词硬规定与照片打架。定位句式："将现实形象抽象为该风格 3D 角色的底色"。
