## 命名

类型前缀：

| 前缀 | 含义 | 例 |
|---|---|---|
| `A` | 角色锚 | A0 心易三视图 |
| `S` | 场景空景 | S1 厨房台面·清晨 |
| `P` | 道具白底 | P2 鸡蛋（生/裂缝/蛋液） |
| `K` | 关键帧（一条一片，带集号） | K1-EP01 |
| `T` | 尾帧（自动截取，只作接线） | T1-EP01 |

## 出图规范

- 角色与道具白底图长边与短边比 ≤ 2.5（`_共享/规范/资产比例规范化-2026-10-20.md` 的口径，已在本库沿用）。
- 白底图只出物体，不出手、不出文字、不出品牌。
- 角色图必带：搪胶质感、磨砂表面、蛋壳接缝线、真实投影、豆豆眼、粉色腮红、头顶呆毛。
- 场景图必带：一个光源方向（右侧窗光）、背景杂物 ≤ 2 件、浅景深。
