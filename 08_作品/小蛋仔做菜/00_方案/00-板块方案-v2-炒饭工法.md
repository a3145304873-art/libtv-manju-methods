## 一、一句话

**一只 12 厘米的蛋仔，在人类厨房的台面上，用扬州炒饭那种工法做一道菜。一条一道，30 秒，12 个细拍，不配口播。**

做菜的动作是真的，锅气是真的，油光是真的；它够不着、搬不动、被油溅到——可爱是真的。

## 二、精致度标准（回答"不要过于粗糙"）

这四条是硬指标，验收时逐条打勾，不靠"看起来还行"：

1. **每一拍都有一个可读的接触点。** 手和食材、铲和锅、蛋液和油面——接触发生的那一帧必须看得见，不能糊、不能切在动作中间。
2. **每 3 拍至少 1 个微距。** 米粒、油泡、蛋液拉丝、蒸汽、火舌。微距是 W10 的"贵"所在：观众记住的是米粒上的那层油光，不是全景。
3. **材质分层。** 蛋仔＝搪胶（磨砂、接缝线、真实投影）；锅＝铸铁（哑光、油膜、磨损）；瓷＝釉面（冷白高光）；木＝纤维与刀痕。四种材质在同一画面里必须能分辨。
4. **光影只有一个方向。** 全片统一右侧窗光＋锅底火光；不出现第二光源，不出现广告式的轮廓光。背景保持干净、浅景深，杂物不超过 2 件。

反例（会被判"粗糙"）：一拍里塞两个动作、全景交代后直接跳成品、材质统一成"塑料感"、每拍都换机位、字幕当工序表用。

## 五、镜头语言（16:9 版）

三种机位，全片只用这三种：

1. **台面平视（主用）**：机位与台面同高，画面左侧是它、右侧是锅，锅占右侧 2/3，它站直只到锅沿。
2. **45° 俯拍（处理用）**：画面里只有它的手、食材、砧板/碗，它本人在画外；用于洗、切、搅。
3. **低角仰拍（名场面用）**：贴台面仰拍，锅与火占上方 2/3，它在下 1/3 抬头。

微距插入规则：微距不单独占一拍，而是**嵌在同一拍的镜头内推近**（同机位推近，不另起切点）。这样 12 拍里有 5 个能"细"，但切点仍是 12 个，观众不会晕。

换机位＝换拍组。同拍组内用尾帧续接，组与组之间硬切（I06）。

### 5.1 有厨师 vs 无厨师（分镜不能照搬的根本原因）

W10 是**没有厨师**的：食物就是全部，镜头可以任意微距、任意角度，不需要连续性，因为画面里没有第二个需要交代"站在哪、够不够得着"的主体。本片有厨师，厨师是蛋仔。差别是五条，写进每一拍：

| 项 | W10（无厨师） | 本片（蛋仔下厨） |
|---|---|---|
| 在场 | 食物就是全部 | 每拍至少一端有它；纯食物空镜 ≤ 3/12，且要留痕迹（手、影、被它搅动的热气） |
| 可及 | 火自己燃、饭自己翻，不追究物理 | 12 cm 对 20 倍大的锅：每个动作都要给"它怎么做到"的解法（板凳、锅盖垫脚、站锅耳、锅铲当杠杆）。**解法要像老师傅，不演狼狈** |
| 因果 | 靠剪辑节奏推进 | 食物变化必须由它的动作引起，接触点在画面里 |
| 视线 | 没有"谁在看"，切点自由 | 它有眼睛，看向哪里就是下一个切点（它抬头看锅 → 切锅里） |
| 反应 | 1 s 一切，靠密度 | 被溅到→后仰→眨眼要 1.5–2 s，一拍里给反应留一半 |

**已知的一处照搬错误**：EP01 原稿 P10 写"颠锅"——那是成年厨师的手腕，12 cm 的蛋仔举不起那口锅。已改成它**吊在锅柄末端、用体重把锅压翘**，画面同样是"饭腾空"，但因果和笑点归它所有。

## 六、字幕与声音

- 字幕：横屏右下角横排，距右 5%、距下 12%；1080p 下字号 52–58 px；白字＋极轻描边。
- 写法：独白、口语、2–6 字；「隔夜饭」「两个蛋」「翻！」「自己炒自己」。**不写配比、不写火候原理**。
- 声音：环境底（窗外/厨房空间）＋ 动作声（刀、油、蛋、饭粒、锅铲）＋ 轻音乐（钢琴/木吉他，BPM 75–95）。
- 没有口播。视频生成开 `generate_audio:true` 拿基础动作声；音乐与平衡在后期做。
- 声音纪律：全程无静音段、无突然峰值（参考片实测 −20 ~ −37 dB 稳定铺满）。

## 九、生产管线（W10 → Monet，管线 B）

### 9.1 映射

| W10 炒饭 | 本板块 |
|---|---|
| 90 s＝6 段×15 s，每段一张 4×3 十二宫格 | **30 s＝2 段×15 s，全条一张 3×4 十二宫格**（整图 4:3，单格 16:9） |
| 十二宫格 → `mixed2video` 直驱，段内 12 个 1 s 快切 | **十二宫格 → 每拍关键帧 → 每拍 3 s 视频（剪到 2.5 s）** |
| 六段 prompt 共用 `text_generate` 提炼的风格前置句 | 板块级固定风格句，全季复用 |
| 主视觉三模型抽卡 → 白底素材派生 | A0 角色沿用；A1 场景＋P1–P5 白底各抽 1–2 次 |
| 超分 4K | 不做；直接输出 1080p |
| 声音随片生成（含旁白） | 只留动作声，无旁白，音乐后期 |

### 9.2 为什么用 B 不用 A

W10 的"一张网格直驱一段 15 s"能出 90 s 只要 6 次生成，但：段内 12 个切点由模型自己决定，任何一拍坏了要整段重跑；Monet 侧也明确"多宫格不直接接视频，会干扰构图"（I06）。
本板块把网格降级为**分镜审核图＋关键帧的构图参考**，换成 12 段 3 s 的独立生成——贵，但每一拍可单独返修。**"细致"这件事，本质上是用可控换来的。**

### 9.3 生成节奏

- 每拍生成 3 s（Vidu 档位 3–16 整数秒，取下限），剪辑剪到 2.5 s，留 0.5 s 切点余量；12×3 s ＝ 36 s，剪掉 6 s 得 30 s。
- 拍组按机位分，组内尾帧链，组间硬切：
  - A 组（P1–P5，台面）：K1 → P1 → T1 → P2 → … → P5
  - B 组（P6，仰拍灶台）：K6 起，硬切，不接 A 的尾帧
  - C 组（P7–P12，锅前）：K7 → P7 → … → P12（P10 颠锅可单独用 K10 起，更稳）
- 上一拍重跑必须重截尾帧，否则旧状态（火大小、油量、脏污）会带进下一拍。

### 9.4 批次（组＝跑序，组内无依赖边）

| 组 | 内容 | 说明 |
|---|---|---|
| 00 | A0 角色、已上传参考 | 免重传 |
| 01 | A1 厨房晨景空景 | 先跑，一条复用 |
| 02 | P1–P5 白底道具 | 与 01 并行 |
| 03 | G01 十二宫格 | 引用 A0/A1/P，审核定稿后再往下 |
| 04 | K1、K6、K7 三张关键帧 | 引用 G01 对应格作构图参考 |
| 05 | V1–V12 十二段 3 s | 引用 K/尾帧作首帧 |
| 06 | 后期 | 剪辑、字幕、音乐、封面；不进画布 |

交付前跑 `工具/检查画布接线.py`；引用双接入（prompt token＋数据字段）缺一即失败。

### 9.5 风格前置语句（板块级，草案）

> 精致生活实拍质感，十六比九电影构图，低机位平视厨房台面；清晨右侧窗光斜入，暖白与奶油黄为主色，铸铁锅、白瓷、木台面、米粒油光，浅景深、真实轻微噪点；主体是一只十二厘米高的搪胶蛋仔，磨砂蛋壳、接缝线清晰、真实投影，动作慢半拍但落点准；画面干净、有生活痕迹、不摆拍、不广告打光、不出现第二光源；节奏克制，声音被放大；不出现人类五官、官方标识、可读品牌文字、生图文字。

## 十一、验收

- [ ] 12 拍各有一个可读接触点，切点不在动作中间。
- [ ] 每拍能答出"它站在哪儿"；纯食物空镜 ≤ 3 且都留了它的痕迹。

- [ ] 微距 ≥ 4 个；四种材质可分辨。
- [ ] 只有一个光源方向；背景杂物 ≤ 2 件。
- [ ] 它站直只到锅沿，至少一处可信参照。
- [ ] 字幕 ≤ 12 条，没有一条是工序说明书。
- [ ] 无口播、无静音段、无突然峰值。
- [ ] 尾帧状态（火、油、脏污、持物）接得上。
- [ ] 结尾是"尝＋推出去"，不是"做完了"定格。
