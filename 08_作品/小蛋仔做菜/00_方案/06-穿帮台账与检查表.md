## 二、场景与道具：搭工作流时就定死

**问题**：以前是"边生成边想这场景该有什么"，模型就自由发挥——凭空多出蒜头、砧板落地、板凳进锅。

**现在**：每个场景角落必须在菜谱卡里声明两件事，缺一项就编译不过。

```json
{
  "key": "stove",
  "name": "土灶",
  "desc": "石头砌的土灶……",
  "layout": "站位：土灶在画面右侧，锅坐灶眼上；砧板在灶台左平台；草窝在左下……",
  "props_here": ["土灶","黑铁锅","木柄锅铲","陶油壶","陶盘","草窝","干柴","松针","灶台左平台上的砧板"]
}
```

编译时会把 `props_here` 拼成一句「**本角落的器具：… ；只有这些，不要多出别的器具**」写进网格、首帧、视频三类提示词，同时负向加一条"出现该角落没有的器具"。

**校验器会拦住的**：

- 场景缺 `layout` 或 `props_here`
- 段里引用了不存在的场景 / 不存在的配角
- 3 个动作拍缺"起幅/动作/落幅"任何一截
- 第 4 拍不是空镜
- 段数不是 4

跑一次就知道，不用等出图。

## 四、验收怎么用这张表

出片后按 1–16 逐条过一遍，新发现的写进这张表，并标清楚它归哪一层：

- **能写进生成器常量的**（所有片子都要遵守）→ 放 `build_from_recipe.py`，改一次全系列生效
- **这道菜特有的**（站位、器具、动作细节）→ 写进菜谱卡
- **只能靠人看的**（表演、节奏、治愈感）→ 留空并注明"未判定"
