## 二、七段式结构（5 条片子都对得上）

| 段 | 内容 | 出现位置 | 为什么必要 |
|---|---|---|---|
| 1 · 点菜 | 左上角一张评论截图「可以做 XX 吗」 | 第 1 秒 | 选题来自观众；不用自我介绍 |
| 2 · 取 | 去自然里拿主料：采艾草 / 摘青菜 / 溪里捉虾 / 网兜抓鱼 / 菜园摘番茄 | 第 2–8 秒 | 建立"它生活在自然里"，不是"它有个厨房" |
| 3 · 理 | 木桌上的处理：洗、捣、切、揉 | 中段 | 手部特写 + 材质 |
| 4 · 配 | 加料：加面粉、倒红豆沙、铺芝士、放盐 | 中段 | 有"配比"的动作，显得会做饭 |
| 5 · 火 | 灶/窑/蒸笼：生火、进窑、上笼、封坛 | 中后段 | 火是唯一的强光源，也是情绪高点 |
| 6 · 揭 | 开笼 / 出窑 / 起锅，热气扑出来 | 后段 | 全片唯一"揭晓"时刻 |
| 7 · 分 | **把吃的分给小狗/兔子**（草窝里），或自己坐下来吃 | 结尾 8–15 秒 | 落点是关系与日子，不是食物 |

水煮鱼那条还多走了三步：**洗碗 → 写日记 → 睡觉**（字幕「宝宝们明天见」）。它把"做饭"扩成了"过完一天"。

## 三、四个可复用的设计决定

### 1. 场景是一条动线，不是一间房
四条片子的空间都是同一片"院子"的四个角落：

```
菜地/林子（取）── 溪流/水塘（洗）── 木桌（处理）── 土灶·石窑·蒸笼（火）── 草窝（分）
```

镜头在角落之间跳，但**色温、雾气、苔藓、木纹**始终一致，所以看起来是同一个世界。
没有一条片子是"站在一个厨房里不动"。

### 2. 比例是协调的，不是巨物反差
蘑菇比锅小，但**擀面杖、竹篮、石臼、小碟都是按它的身量配的**；锅和蒸笼大，那是"它家的大锅"，不是"人类的巨物"。
我们之前那套"锅径＝身高 2.5 倍、要看出它是小矮人"其实是**反差喜剧**的逻辑，不是治愈的逻辑。治愈要的是**安全的小世界**。

### 3. 字幕分两种，混着用
- **动作提示**：加面粉 / 揉成圆形 / 蒸熟了 / 切配料
- **心里话**：无聊等待 / 吃得好饱好香 / 写日记 / 宝宝们明天见 / 真香~

不是纯工序标签，也不是纯卖萌，是"一边干活一边嘀咕"。

### 4. 声音：环境音是主体
水、柴火、蒸笼、雨、鸟、锅铲；音乐极轻甚至没有。角色只"嘟"一声。

## 四、我们 v8 的问题（对照着看）

| 项 | 原片 | 我们 v8 | 要改成 |
|---|---|---|---|
| 空间 | 院子动线，5 个角落 | 一间小木屋厨房，固定台面 | **一条动线**，每段换角落 |
| 比例 | 协调（工具按它身量配） | 巨物（锅 2.5 倍身高，强调小） | **协调**，锅大但工具配身量 |
| 结尾 | 分给小狗 / 吃完洗碗写日记 | 尝一口、推盘 | 加**分享**，可延伸到洗碗 |
| 字幕 | 动作 + 心里话 | 8 条工序短词 | 混入心里话（"等一会儿""真香"） |
| 开场 | 评论卡 | 无（你说不用） | 尊重你的决定，不加 |
| 结构 | 取 → 理 → 配 → 火 → 揭 → 分 | 备料 → 起锅 → 下锅 → 收 | **补"取"和"分"两头** |

最大的缺口是**两头**：原片开头一定去自然里"取"，结尾一定"分"出去。我们两头都没有，所以像广告，不像日子。

## 五、据此的 v9 改法（待确认）

1. 场景换成**院子的四个角落**：菜地（取葱/取蛋）→ 木桌（切、打、搅）→ 土灶（炒）→ 草窝（分给小狗）。
   蛋从哪来？原片从不解释食材来源的合理性，直接"取"——我们可以让它从菜地边的鸡窝里取两只蛋。
2. 锅仍比它大，但**锅铲、碗、刀按它身量配**，去掉"必须看出它是小矮人"的表述。
3. 结尾从"尝一口"改成"**分一半给草窝里的小狗，自己吃另一半**"。
4. 字幕混入 2–3 条心里话。
5. 时长维持 60 s（青团子 58 s、青菜包 51 s，我们 60 s 合理）。
