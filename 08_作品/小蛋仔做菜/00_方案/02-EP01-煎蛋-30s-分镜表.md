## 二、九宫格分镜图（G01）prompt

> 生成规格：一张图，3 行 × 3 列，共 9 个竖屏 9:16 画面，整图比例 9:16；2K。
> 用法：审核构图与顺序；定稿后裁出对应格作为关键帧的构图参考（不作首帧）。

```
治愈系实拍质感，竖屏九比十六，低机位贴厨房台面的微距视角；清晨侧窗光从右上方斜入，暖白与奶油黄为主色，木质台面、白瓷、旧铁锅、浅景深、真实轻微噪点；主体是一只十二厘米高的搪胶蛋仔，磨砂蛋壳质感、接缝线清晰、有真实投影；画面干净、有生活痕迹、不摆拍、不广告打光。

请生成一张三行三列的分镜设计图，一张大图中包含九个按顺序排列的竖屏九比十六画面，从左到右、从上到下按时间顺序阅读，整体保持统一的光线、色调与材质。

第一格：厨房台面上，一枚鸡蛋立在蛋仔旁边，蛋顶到它的胸口，蛋壳高光里映出它的轮廓；它抬头看蛋，一只手刚抬起来要摸。
第二格：同一个台面，它抱着这枚鸡蛋往一只白瓷碗的碗沿跑，身体前倾，蛋比它的上半身还大。
第三格：它把鸡蛋举过头顶，蛋壳在碗沿上裂开，蛋液正浇在它头上，它睁着豆豆眼、眨了一下；蛋壳碎成两半。
第四格：灶台前，它把一只小板凳推到灶边，仰头看灶台；画面下方是它的背影，上方是巨大的灶台与旋钮。
第五格：它站在小板凳上，踮脚拧开旋钮，一簇蓝色火焰从灶眼窜起，火光映在它的蛋壳上。
第六格：它端着一只小碗把蛋液倒进黑铁锅，油花正从锅底炸开，它身体后仰、一只手抓着锅沿。

九个格子里都只能出现这一只蛋仔，不出现人类、不出现第二只蛋、不出现文字与标识；每一格只表现一个动作瞬间，格与格之间不要加任何标注或边框文字。
```

## 四、视频 prompt：一段完整样例（P5 下锅）

> 所有规范按 I06 的结构顺序：首帧锁定 → 引用说明 → 角色/尺度 → 动作（时间拍）→ 声音 → 负向。

```
【首帧锁定】{{K5}}：沿用首帧的机位与构图——低机位平视厨房台面，它在画面左侧站在小板凳上，黑铁锅的锅沿在右侧占画面三分之二；锁定锅的位置、火焰大小、它的朝向与站姿，不改变景别与透视。

【引用图片说明】{{A0}} 只用于锁定角色外观：十二厘米高的搪胶蛋仔，奶白蛋壳、磨砂质感、豆豆眼、粉色腮红、头顶一撮呆毛、短手短脚、毛巾改的小围裙；不引入其他角色。{{A1}} 只用于锁定厨房环境：木质台面、旧瓷砖、右侧窗的晨光。

【尺度】它站直只到锅沿，锅铲比它高，碗比它的手掌略大；画面里始终保留一个可信的尺度参照。

【动作】它双手端着一只小碗，把碗里的蛋液倒进热锅；蛋液接触油面的一瞬间，油花向外炸开；它被油星吓得往后一仰，一只手抓住锅沿稳住身体，另一只手仍举着碗。

【时间拍】0–1 秒举碗、身体前倾；1–2.5 秒蛋液落下、油花炸开；2.5–4 秒后仰、抓住锅沿、豆豆眼睁大。

【声音】油爆声密集，碗沿轻磕一声；无人声台词。

【负向】不出现人类手指或人脸，不出现第二只蛋仔，不出现文字与标识，镜头不旋转不漂移，锅与碗的位置不发生复制，油花不遮挡主体。
```

其余八拍沿用同一骨架，只换【首帧锁定】【时间拍】【动作】【声音】四段。

## 五、验收点（EP01 专项）

- [ ] P1 的体量对比一眼可读：蛋到它胸口，锅比它高。
- [ ] P3 的蛋液真的落在它身上，不是落在旁边。
- [ ] P5 的油花与后仰在同一拍完成，不是切开的两个动作。
- [ ] P7 的翻面成功，蛋翻过去后仍完整、不碎成块。
- [ ] P9 的"自己煎自己"能读懂，不需要额外解释。
- [ ] 9 拍加起来 30 s ±0.5 s，字幕 9 条以内。
