## 文件约定

```
02_画布/
├── build-EP01蛋炒饭-v2.py     ID 生成、节点工厂、prompt 常量、组装、自检、输出

└── _归档-v1-12拍/             改版本前的旧文件
```

- 一次交付多支画布必须换 ID 前缀（A/B/集数），否则节点 ID 全撞。
- `edges` 由 `reference_images` / `first_frame_image` 派生生成，不手写两套。
- 输出双份：本目录 + `Downloads`，带版本号。

## 接线纪律

- **引用双接入**：prompt 写了 `{{node-x}}`，必须同时挂进下游 `reference_images`（首帧则 `first_frame_image`）并存在 `x→下游` 的边，缺一是"无效的引用块"。
- **组＝依赖分层＝跑序**：组内不得有依赖边；组名按"第 N 步"编号。
- **禁止边**：`video→video`、`audio→video`、视频→尾帧的来源记录边。
- 上一段重跑必须重截尾帧。


有 ERROR 不得交付。画布无回收站，删除前先查产物；**只交 .monet 由用户自行导入**。
