## 一、这一集在等什么

**等红薯在灰里熟。** 没有刀、没有油、没有翻锅——只有一个"埋进去"和一个"等"。
选它做首集：动作最少、物理风险最低、火光与蒸汽最好看，最能检验"她能不能撑住 15 秒不切"。

## 二、场景与角色

### 2.1 场景 S1：灶与池同框（黄昏）

- 画面左侧：石头砌的小土灶，灶口朝右，灶膛里有红灰与柴；灶上坐一口粗陶小锅（这一集不用，只是"这是厨房"的交代）。
- 灶边石缝：插着一根小木棍（她的"手"）；灶前有一块干石板，用来放烤好的红薯。
- 右后方：石池，热水冒白气，水面浮一片橘子；池沿湿。
- 地面：湿石、散落的灰、两片落叶。
- 光：暮色冷蓝从后方来；灶口暖橙是唯一主光。**不打第三支灯。**

### 2.2 V3 的机位（不另建场景）

用同一个景，把机位挪到池边、回看灶口：画面左前是灶沿与插着木棍的石缝，右侧是池沿与她。中景，不特写——这一帧要能一眼看完"灶、池、她"三件事。

### 2.3 角色

心易＝棕色水豚毛绒玩偶，12 cm（尺度待定，见方向设计 §4.2），短手无指，头顶橘子（本体）。整条片她**不说话**，只有两次咔啵；情绪全在蹲、后仰、耳朵、身体上。

### 2.4 道具

| P1 | 红薯（生，带泥） | 比她的躯干略大，两只手抱得住 |

## 六、尾帧与接点设计

### 6.0 先定模式：全能参考，不挂首尾帧

三条视频都设 `_reference_way: "reference"`，`first_frame_image` / `last_frame_image` 都留空，图只进 `reference_images`。2.0-mini 在 reference 模式下首/尾帧槽本来就不生效（见 [燕云可复用管线 §6](../../燕云冲击帧/00_方案/18-可复用管线.md)）；硬要首尾帧得切 `frames` 模式并清空参考图，那是另一条管线。

所以下面说的"尾帧链"是**内容上的接**：V1 的真实最后一帧，作为 V2 的**参考图**喂进去——不是把 T1 塞进首帧槽。

三个接点，三种处理——**不是每处都该用尾帧链**。

| 接点 | 关系 | 做法 | 为什么 |
|---|---|---|---|
| V1 → V2 | 同一镜头、同一动作被切成两段生成 | **尾帧链**：V2 首帧 ＝ V1 真实最后一帧（T1） | 连续动作不能重画；重画就会跳 |
| V2 → V3 | 地点变了（灶前 → 池边）、时间省略十秒到一分钟 | **匹配剪辑**：同一颗红薯、同一个姿势、同一个蒸汽方向 | 硬切太生；加尾帧链会把 V3 锁死在灶前，反而错 |
| V3 → 下一条 | 系列片尾 | 固定机位 3 秒 ＋ 尾卡 | 这是"印章"，不需要接 |

### 6.1 V1 的尾帧（T1）：要"没结束"

尾帧不是"漂亮的收尾"，是**一次还没发生完的等待**。它要满足七条：

1. **机位没动**：与 V1 开头同机位、同焦段；最后 2 秒镜头完全停住（不推、不摇）。
2. **她在蹲姿**：3/4 侧身、两只短手撑在膝前、头朝灰堆；眼睛睁着，耳朵不动。
3. **灰堆没揭**：鼓一小包、缝里透一点橙红、一缕细烟；红薯还埋着。
4. **木棍在手里**（或横在膝前）——V2 第 4 秒要用它拨红薯，不能在尾帧里消失。
5. **火是稳的**：只剩炭火，没有火苗窜起；避免 V2 开头"火突然变大"。
6. **背景的池子还在**：右后白气继续冒，不要被她的身体完全挡住。
7. **干净**：不糊、不抖、没有运动模糊、没有模型加的字。

> 进 prompt 的写法：「最后两秒完全静止，只有烟与水汽在动；镜头停住，画面稳定不抖。」

### 6.2 T1 替换检查表（截完先对，再跑 V2）

- [ ] 是 V1 的**真实最后一帧**，不是重画的图。
- [ ] 机位与 V1 开头一致，没有漂移。
- [ ] 她是蹲姿、侧对镜头、没看镜头。
- [ ] 灰堆是鼓的、红薯还埋着、木棍在。
- [ ] 没有火苗窜起、没有第二个角色、没有文字。
- [ ] 画面不糊；**最后一帧若糊，往前退 0.2–0.5 秒**截（最后 2 秒是静止的，退一点不影响接）。

### 6.3 V2 尾帧 / V3 首帧：做一对"匹配帧"

V2 与 V3 之间不用尾帧链，用**匹配剪辑**：让两帧在四个点上对得上，观众自己会补上"她走到池边"的那十秒。

| 匹配点 | V2 最后一帧（约 12 s） | V3 第一帧（K3） |
|---|---|---|
| 手里的东西 | 半个红薯，切面朝镜头 | 同一个半个红薯，切面朝镜头 |
| 姿势 | 两只短手捧在胸前 | 同一个捧法，只是坐下、脚进水 |
| 蒸汽 | 从红薯往上、略偏右 | 同一方向、略偏右 |
| 暖光 | 红薯上的暖光在右侧 | 同一侧 |

- V2 最后 1 秒：把红薯举到胸前、切面朝镜头、身体微沉、头轻低——**不要吃完、不要放下**。
- V3 第 0 秒：同一个姿势；**0.5 秒后才咬第一口**。

### 6.4 兜底

- V2 尾帧没举起来 / V3 首帧对不上：后期加 **0.2 s 叠化或白闪 ＋ whoosh**，不要硬切。
- V1 尾帧漂了、糊了：重跑 V1，或退 0.2–0.5 秒截帧；**不要用"相似图"顶替**。
- **不要给 V3 加 T2 尾帧节点**：那会把 V3 锁在灶前，3 秒内再做一次"走到池边"，必崩。
