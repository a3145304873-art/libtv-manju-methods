## 为什么是这条线

心易换了新形象（棕色水豚毛绒）和新设定（只发"咔啵"、不说话、情绪稳定）之后，"做菜"这件事要重新设计——不是把旧做菜片的主角换张图。

结论：她做不了"利落的手上功夫"（短手无指），硬做会变成"够不着"的滑稽，而那条戏已经被 `小蛋仔做菜` 占了。她真正做得好的是**守**。
所以本线按菇子柒的结构走完"取→理→火→吃"，把"等"放在火段：**挖出来、洗干净、埋进去、等一下、好了、泡一下。**
