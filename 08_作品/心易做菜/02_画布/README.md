## 二、为什么是四段（对齐菇子柒／秃秃）

| 依据 | 做法 |
|---|---|
| 原片 51.5 秒、11 拍、约 4.7 秒/拍，**时长由动作定** | 60 秒、4 段、每段 3 拍；**秒数按动作分配**（4–7 秒），不平均分 |
| 原片一定从"取"开始、以"分"收尾 | 取（菜园挖土豆）→ 理（溪水洗、捧在怀里）→ 火（添柴吹火、上灶下锅）→ 吃（池边掰开、蘸盐、泡脚） |
| 原片的小世界是"工具按身量配、锅盆比它大" | 一坡四台：菜园／溪／灶／汤池；灶比她高、锅沿高过她头顶、柴堆可踩 |
| 原片角色不说话、只发一个音 | 心易只发咔啵（3 声），环境声打底，无音乐 |
| 原片白字压在主体上 | 后期白字**竖排**，2–3 字，压在主体旁，全片 7 条 |

备菜不是过场，是"从哪来"的因果。土豆从土里挖出来、滚下石阶，一颗土豆把四段串成一条下坡路。

## 三、为什么是全能参考，不是首尾帧

四条视频全部走**全能参考**（`_reference_way: "reference"`，`first_frame_image` / `last_frame_image` 都是 `null`），图只进 `reference_images`：

- **2.0-mini 在 reference 模式下，首/尾帧槽本来就不生效**（见 [燕云可复用管线 §6](../../燕云冲击帧/00_方案/18-可复用管线.md)）。想真用首尾帧，必须 `_reference_way: "frames"` 并清空参考图——那是另一条管线。
- **不要用上一段整帧当参考**：V2 已经有 K2 定开场构图，再挂一张“菜园站着”的 V1 尾帧，等于两个构图参考互相打架；即使 prompt 写“以 K 为准”，模型也可能被带跑。v2 试过 T1–T3，已撤（v3 回到 K-only）。
- 如果之后发现角色/光漂：**裁角色**再用——从上一段尾帧里裁出她（不带背景）当参考，而不是整帧；整帧的构图会抢 K 的活。
- **首尾帧会把人物锁在两帧之间**，动作容易变僵（见 [燕云视频验收](../../燕云冲击帧/00_方案/24-视频验收-有没有动作.md)）。
- 四段是**换台地**（菜园→溪→灶→汤池），段间本来就不该接尾帧；每段以自己那张 K 为开场参考。

## 五、跑法（一次只跑一组）

1. **01 场景 4 张**（可同跑）：看四台地是不是同一面坡、同一层雾、同一个光向。
2. **02 道具 4 件**：与 01 并行。
3. **03 四格**：看四格顺序（取/理/火/吃）、她的位置、土豆、火光；定稿后再往下。
4. **04 K1–K4**：每段只看"开场构图对不对"，尤其 K1（前景土豆叶、后景她与石阶）。
5. **05 V1（15 s）**：先看晨雾逆光、拔秧、土豆滚下坡三件事；闭眼就重跑（提示词已加"全程睁眼"）。
6. **06 V2 理**：洗、捧在怀里走；不要再出现削皮器/刀。
7. **07 V3 火**：添柴吹火（火已经着着）→ 踩柴堆上灶台、掀盖、土豆下锅、盖盖 → 锅盖冒汽 → **揭盖、白汽、用木棍戳起土豆**。**土豆不进火**。
8. **08 V4 吃**：池边、从锅里捞出的热土豆（浅黄不焦）、掰开蘸盐、泡脚；眼睛全程睁着。
9. 后期：白字竖排 7 条（[字幕草稿](EP01-等土豆熟-字幕.srt)）、3 声咔啵、尾卡「非教程 仅供娱乐」、环境声与极轻音乐。

## 六、硬约束

- **视频内无字、无气泡**；白字竖排与咔啵全部后期。
- **四段是硬切**（换台地），不接首尾帧；每段以自己那张 K 为构图。**不要用上一段整帧当参考**（两个构图会打架）；要补一致性就裁角色。
- **四条视频都走全能参考**：不挂首帧/尾帧槽；不要改回首帧槽（2.0-mini 在 reference 模式下首帧不生效）。
- **眼睛按跨项目规范**：白片＋深棕细圈、中心空白；无瞳孔/高光；**全程睁开，不眨眼、不眯眼、不闭眼、不笑成弯眼**；不拍眼睛大特写。情绪全走身体。
- **尺度 30 cm**（做菜线）：灶比她高，灶口到胸口；锅沿高过她头顶，柴堆可踩；木棍/碟子按她身量配。
- **土豆下锅，不进火**：火只加热锅；锅里有水；熟土豆是浅黄白汽，不是焦黑。
- **先只跑 V1**；不要一键全跑。
- **动线（blocking）必须接得上**：每拍起点接上一拍终点——人在哪、手里有什么、道具在哪、**道具几个**；道具不能同时出现在两处；离开台地后不要回拍该台地的空镜；段尾要能接下一段开场。V2 已踩：人都往灶台走了，第三拍又回溪边抱着湿土豆滴水，而且变成了三颗土豆。
- **手永远只有两只**：V2 在侧面/搓洗时冒出四条手臂。角色段写“只有两只短手和两只圆脚”，动作写“两只短手按住”，负向加“多余手臂/第三只手/多双手”。
- **近景别把灶台拍没**：V3 切近景时，高石灶被模型改成了平地火塘（石圈＋火）。提示词要写“中景、保留石头灶身与灶口火膛”，负向加“火塘/石圈/锅放地上”。
- **空镜要有因果**：第三拍尽量收在动作上（捡起、取出、泡脚），不要单纯拍景；空镜里最好有她或她手里的东西。
- **成片剪辑（2026-11-03）**：V1 从第 4 秒起（去掉开头四手的拨叶），V4 到第 8 秒止（去掉裸脚泡水结尾）；四段合并 **49.3 秒**，字幕时间轴已按这版重对。
- **视频提示词里不要写具体字幕字**：模型会把「一窝」这类字直接烧进画面（V1 已踩）。字幕只放 SRT，提示词只写“不生成任何字幕”。
- 段内 3 个镜头：2 动作＋1 收尾（空镜或“捡起/取出”这类收束动作）；**秒数按动作定，不平均分**。
