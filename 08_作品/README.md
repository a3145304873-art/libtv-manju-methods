# 08 作品区

> 2026-10-29 用户指定：**以后的资产和画布不再放在 `E:\漫剧项目\ai-drama\_共享\工作流研究\…` 下，统一存到本目录。**
> 目录结构沿用用户习惯的"方法库 / 作品区"分离：`00_方法论`–`07_格式参考` 是方法层，`08_作品` 是作品层。

## 为什么单独一层

方法层（00–07）的约定是**不含制作媒体**：不存角色图、场景图、成片、账号凭据（见 [AGENTS.md](../AGENTS.md) §1、[README](../README.md)）。检查脚本 `06_工具/检查方法库.py` 原本会对全库任何 `.png/.jpg/.mp4/.mp3` 直接报错。

作品区放进库根后，这一条必须留一个明确出口：脚本只对 `08_作品` 放行媒体，方法层仍然一个像素都不许有。边界写在代码里，不靠人记。

## 目录约定

```
08_作品/
├── _共享角色/       跨项目角色规范与资产（目前：心易）
└── <作品名>/
    ├── README.md      入口：定位、状态、待拍板、下一步
    ├── 00_方案/       方向、拉片、分镜表、参考确认；文档与证据抽帧
    ├── 01_资产/       角色/场景/道具的参考图、白底图、首帧
    ├── 02_画布/       build 脚本 + 导出的 .monet
    ├── 03_成片/       候选片段、剪辑版本、封面
    └── 04_素材/       上传中转、抽帧原始、临时文件
```

## 跨项目角色

- 同一角色跨多个项目使用时，规范与共享资产放 `_共享角色/<角色名>/`，不复制成多份互相打架的人设卡。
- 目前：[心易·跨项目角色规范](_共享角色/心易/README.md)（**全局无台词**，只发咔啵；白片＋深棕圈、无瞳孔）；[黄蛋·跨项目角色规范](_共享角色/黄蛋/README.md)（正常眼睛、可眨眼/表情；标准/毛绒两版）。
- 所有蛋仔作品使用心易前必须查阅共享规范；题材和媒介不会改变她不能说话的设定。后期气泡若被该作品采用，只是动作/表情的视觉转译。
- 心易锁眼只限心易；黄蛋不套用；两角色同框时材质版本要一致（毛绒心易→毛绒黄蛋）。
- 各项目仍在自己 `00_方案/` 里写本项目的能力边界/分镜；角色外形、眼睛、材质、声音以共享规范为准。

## 跨项目工具

- 跨作品的操作脚本放 `_共享工具/`，不放作品资产。
- 目前：[monet_pull.py](_共享工具/monet_pull.py)（只读拉画布与已生成结果）、[monet_push.py](_共享工具/monet_push.py)（导入成新画布，2026-11-02 验证）、[cookline](_共享工具/cookline/README.md)（做菜线：菜谱卡 → 校验 → 分镜闸门 → `.monet`，不派发；DSH 插件 [cookline-dsh](_共享工具/cookline-dsh/README.md) 已装）。说明见 [_共享工具/README.md](_共享工具/README.md)。

## 边界

- **只放本作品的资产**，不放其他项目、不放账号凭据（`.env`、`credentials.json`、`.libtv` 一律不许）。
- **例外**：跨项目角色统一放 `_共享角色/<角色名>/`；项目里只放引用/副本，不另写一套角色规范。
- **画布交付默认只交 `.monet`**，由用户自行导入；2026-11-02 授权后：首次导入用 `_共享工具/monet_push.py` 新建；**返修用 `_共享工具/monet_sync.py` 在原 canvasId 上覆盖（先建版本快照，保留已有输出）**；删除须点名 canvasId 并确认无产物。
- 成片候选按版本保留，不覆盖已采用版本。
- 方法层的通用规则、能力卡、来源证据仍然回到 00–07，不往作品区里写"方法"。
