# 心易 · 跨项目角色规范 v1

> 2026-11-02｜状态：**canonical（跨项目全局约束）**｜适用：所有使用“心易（棕色水豚）”的题材、项目与媒介
> 本规范优先于各项目里旧的心易人设卡；旧卡里“黑小圆瞳/单高光/可眨眼”的写法已作废。
> 资产：`心易-水豚-标准.png`、`心易-水豚-脸部.png`、`心易-水豚-眼睛参考.png`、`心易-水豚三视图.png`

## 一、一句话

一只巴掌大的棕色水豚毛绒玩偶，情绪稳定，不说人话；声音只有固定拟声“咔啵”。

## 二、外形锁

| 部位 | 锁 |
| --- | --- |
| 整体 | 圆身、无脖子、头身一体的毛绒玩偶；不是蛋仔、不是猫耳 |
| 毛色 | 暖棕短绒；绒毛方向可见，边缘有绒光 |
| 脸板 | 奶油色、面积大、几乎占满正面 |
| 口鼻块 | 额头中央一块奶油白、中间一道浅棕分线的口鼻块 |
| 耳朵 | 小而圆、棕色，长在头顶两侧 |
| **眼睛** | **白色圆形眼片＋外圈一条深棕细线；中心空白，没有黑色瞳孔、没有虹膜、没有高光点** |
| 腮红 | 橘色椭圆，两侧各一 |
| 嘴 | 一条短横线（一字嘴），不上扬、不下垂 |
| 肚 | 奶油白椭圆，像围兜 |
| 手 | 短圆、无手指；棕色 |
| 脚 | 棕色圆脚，脚踝一圈奶油色 |
| 背 | 小圆尾 |
| 头顶 | 一颗橘子＋两片绿叶 |
| 橘子 | 本体：不可摘、不可吃、不可换、不可掉落 |

## 三、眼睛：白片＋棕圈，无瞳孔

参考图看清楚：

- 眼片是**白色/奶油白圆片**；
- 外圈是**深棕色细描边**，不是黑瞳；
- 中心**空白**，没有黑点、没有虹膜、没有高光；
- 像贴/缝上去的**固定玩偶眼**，不是生物眼。

### Prompt 正写

```text
【心易眼睛·仅限心易】心易是毛绒玩具，眼睛是固定塑料/刺绣件，不是生物眼：
白色圆形眼片，中心没有黑色瞳孔；外圈一圈深棕色细描边；
眼片中心保持空白，没有高光点；
眼片形状、外圈深棕线、中心空白全程不变；
不出现瞳孔/黑瞳/眼珠/虹膜/高光点；
不眨眼、不眯眼、不抬眼皮、不皱眉、不闭眼；
情绪只靠歪头/身体/手势/咔啵。
镜头以中景/中近景为主，不要心易眼睛大特写。
```

### Prompt 负向（只写心易）

```text
心易的黑瞳、心易的眼珠、心易的虹膜、心易的瞳孔、心易的高光点、
心易的眼皮、心易的眼睑、心易的眉毛、心易的眨眼、心易的眯眼、
心易的半闭眼、心易的眼神变化、心易的眼球转动、心易的泪光、
心易的眼睛大特写、眼睛变形、卡通大眼、拟人化眼神
```

**不要写无主语的“不眨眼/不要眼皮”**，否则会误伤黄蛋或其他角色。  
其他角色（黄蛋等）眼睛正常：可以眨眼、看、做表情；在 prompt 里明确写“该角色不受此限制”。

## 四、材质

- 短毛绒/毛毡：纤维可见、压过留痕、哑光；
- 不做：搪胶、塑料、金属高光、蛋壳接缝线；
- 沾面粉变白、沾水结缕、沾灰变暗——这是质感戏，不是脏。

## 五、声音与角色关系

- 心易**不能说话**，实际声音只发“咔啵”；不写人话、内心独白或让旁白代她发言；
- 项目若采用后期气泡，气泡只是对她动作/表情的视觉转译，不代表她说了这句话；未选气泡形式时，不自行添加；
- 四调：疑问 `咔啵？`、收到 `咔啵！`、等一下 `咔——啵`、难过 `咔……啵……`；
- 满足调 `咔啵~` 只在需要“好吃/满足”的项目里加；
- 另一个角色负责说话；不要让心易念规则/长句；
- 夸赞可以由心易发“咔啵！”＋后期气泡（`真不错！`/`真棒！`）。

## 六、表演与镜头

- 情绪只走身体：歪头、点头、后仰、蹲、耳朵动、抬手、耷拉；
- 不走脸：不加眉毛/眼皮/瞳孔变化/挤眉弄眼；
- **不眨眼、不眯眼、不闭眼**；如果剧情必须闭眼，单独标为例外，不算默认；
- 中景/中近景为主，不要眼睛大特写；眼睛在画面里越小越稳。

## 八、跨项目规则

1. 任何题材、媒介或项目使用心易，**先读本规范**；
2. 不要把旧卡里的“黑小圆瞳/单高光/可眨眼”抄回去；
3. 每个项目的 K/V prompt 都带“心易眼睛·仅限心易”块；
4. 负向必须带主语“心易的…”；其他角色明确豁免；
5. 需要例外（闭眼/眯眼）时，在项目文档里单独写“例外镜头”，不要改默认规范；
6. 资产可复制到项目 `01_资产/角色/`，但规范以本文件为准；局部作品文档不得解除“心易不能说话”的全局设定。

## 九、验收

- [ ] 心易眼睛是白片＋深棕细圈，中心空白；
- [ ] 没有黑瞳/眼珠/虹膜/高光点；
- [ ] 没有眨眼/眼皮/眉毛/眯眼/闭眼；
- [ ] 没有眼神变化/眼球转动/眼睛大特写；
- [ ] 其他角色眼睛正常，没有被误锁；
- [ ] 心易只发“咔啵”，没有人话、内心独白或代言旁白；
- [ ] 情绪靠身体/气泡，不靠眼睛。
