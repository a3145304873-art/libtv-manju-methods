# 黄蛋 · 跨项目角色规范 v1

> 2026-11-02｜状态：**canonical（跨项目通用）**｜适用：所有使用“黄蛋（黄色蛋仔）”的项目
> 与 [心易规范](../心易/README.md) 配对使用：**心易锁眼，黄蛋不锁眼**。
> 资产：`黄蛋-标准-正面.png`（搪胶/3D）、`黄蛋-毛绒版.png`（短毛绒）、`黄蛋-标准vs毛绒.png`

## 一、一句话

一只 12 厘米的黄色蛋仔，会说话、会眨眼、会做表情；和心易同框时负责“说”，心易负责“咔啵”。

## 二、外形锁

| 部位 | 锁 |
| --- | --- |
| 整体 | 黄色蛋形/椭圆身体；不是圆球、不是水豚、不是猫 |
| 脸板 | 奶油色椭圆大脸板，占正面大部分 |
| 眼睛 | **白色眼白＋棕色虹膜＋黑色瞳孔＋单个白色高光**；正常眼睛，可眨眼、可看、可做表情 |
| 嘴 | 张嘴笑，红色舌头；**没有牙齿** |
| 天线 | 头顶黄色细天线＋黄色圆球；**本体，不可拆、不可摘** |
| 手臂 | 短圆、无手指；黄色 |
| 袜子/鞋 | 白色短袜＋黑色横条纹；白色毛绒靴 |
| 蛋壳 | 没有裂壳、没有蛋液、没有蛋黄 |

## 三、眼睛：黄蛋是“正常眼睛”

黄蛋和心易相反：

- 心易：白片＋棕圈，**无瞳孔、不眨眼**；
- 黄蛋：白眼球＋**棕虹膜＋黑瞳孔＋白高光**，**可以眨眼、看、惊讶、开心**。

**不要把心易的锁眼负向套到黄蛋身上。**  
不要写“黄蛋不眨眼/不要眼皮/不要瞳孔”；这些只属于心易。

## 四、两种材质（选一种，不要同镜混用）

| 版本 | 资产 | 材质 | 用在哪 |
| --- | --- | --- | --- |
| 标准 | `黄蛋-标准-正面.png` | 搪胶/3D，光滑、轻微高光 | 普通项目、单人、和蛋小粉/其他搪胶角色同框 |
| 毛绒 | `黄蛋-毛绒版.png` | 短毛绒/毛毡，哑光、纤维可见 | 和毛绒心易同框、治愈/毛绒世界观 |

- 同一项目/同一镜头只用一种；
- 和**毛绒心易**同框 → 用毛绒黄蛋；
- 和蛋小粉/普通蛋仔同框 → 用标准黄蛋；
- 不要用滤镜把标准版“假装”毛绒；需要毛绒就换资产。

## 五、Prompt 正写

### 标准版

```text
16:9 纯白底角色设定图，只生成一只黄蛋：
黄色蛋形身体、奶油色椭圆大脸板、白色眼白＋棕色虹膜＋黑色瞳孔＋单个白色高光、
张嘴笑（红色舌头、无牙齿）、头顶黄色天线＋黄色圆球、短圆手臂无手指、
白色短袜（黑色横条纹）＋白色毛绒靴；搪胶/3D 卡通质感，轻微高光。
眼睛正常，可以眨眼、看、做表情。
```

### 毛绒版

```text
16:9 纯白底角色设定图，只生成一只毛绒黄蛋：
黄色短毛绒身体、奶油色毛毡脸板、白色眼白＋棕色虹膜＋黑色瞳孔＋单个白色高光、
张嘴笑（红色舌头、无牙齿）、头顶黄色布球＋布天线、短圆绒手臂无手指、
白色布短袜（黑色横条纹）＋白色毛绒靴；短毛绒/毛毡、哑光、纤维可见。
眼睛正常，可以眨眼、看、做表情。
```

### 负向

```text
人类、手指、牙齿、蛋壳裂开、蛋液、蛋黄、猫耳、水豚、橘子、粉蛋、蓝色/绿色蛋、
文字、字幕、logo、水印、比例失真、塑料高光过强（毛绒版）、过曝
```

**不要**在负向里写“眨眼/眼皮/瞳孔/高光点”——那是心易的限制，不是黄蛋的。

## 六、角色关系与声音

- 黄蛋：**说话的人**；可以说完整句子、问句、反应句；
- 心易：只发“咔啵”，不说话；台词/翻译走后期气泡；
- 黄蛋**不要替心易说“咔啵”**，也不要说“心易问……”；直接回答气泡/问题；
- 夸赞归谁由项目定；本项目（蛋仔记单词）定为**心易夸**，黄蛋不说“真不错/真棒”；
- 黄蛋可以惊讶、开心、疑惑；眼睛和嘴都可以演。

## 七、尺度

- 默认 **12 cm**，与心易同高；项目可调，但同项目内保持一致；
- 黄蛋略矮/略圆都可以，不要变成高瘦人形。

## 八、跨项目规则

1. 任何项目使用黄蛋，**先读本规范**；
2. 不要套用心易的锁眼负向；
3. 不要换色（黄蛋不是粉蛋/蓝蛋/黑蛋）；需要其他蛋仔另建共享卡；
4. 标准/毛绒选一种，同项目不混；
5. 和心易同框时，黄蛋说话、心易咔啵；黄蛋不抢“咔啵”；
6. 如果项目要“无表情/死鱼眼”的黄蛋，标为例外，不改默认。

## 十、验收

- [ ] 黄色蛋形、奶油脸板、天线＋球、短手、白袜白鞋；
- [ ] 眼睛是白眼球＋棕虹膜＋黑瞳孔＋白高光；
- [ ] 可以眨眼/看/做表情，没有被锁成死鱼眼；
- [ ] 没有牙齿、没有裂壳/蛋液/蛋黄；
- [ ] 材质版本和同框角色一致（毛绒心易→毛绒黄蛋）；
- [ ] 说人话，不替心易说“咔啵”；
- [ ] 没有把心易的锁眼负向套过来。
