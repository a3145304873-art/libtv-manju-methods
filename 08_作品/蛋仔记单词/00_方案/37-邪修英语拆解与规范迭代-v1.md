# 邪修英语拆解与蛋仔英语规范迭代 v1

> 日期：2026-11-03｜状态：方法已接入 `english-story` schema 2；内容方向仍可继续试做，不代表某一种节目形态已定稿。

## 结论先行

> **创作目标校正（2026-11-03 用户明确）：** 蛋仔英语的目标是“玩梗学单词”：用自然谐音、词形/词族联想或语义场景，把英文词与准确词义连起来，让观众在笑点里记住。表达不做课堂讲解；词典、音标和义项核对是防错底线。B站课程的词包/复习可作系列补充，不能替代单集的记忆梗。

本轮研究带来两类可迁移方法：

1. B站热门“邪修背词”样本展示了**主题分组＋稳定词卡＋发音/联想＋例句＋回顾**的系列课程组织方式。它的长课结构不等于 15 秒漫剧结构；可借鉴的是把词按语义/场景编成系列包，并在后续内容里回忆旧词。
2. 外部 GitHub Skill 星数很少，不能称为市场验证。可迁移的是**比较多个助记候选、发音和词义分开核对、真实词义桥、编码后 QA**；它的黑板风格、TTS/动画/渲染栈不搬进 Monet。

因此新故事从“先定谐音再写剧情”改为：核对目标词，比较不同记忆梗，再选剧情表达。自然谐音优先；也可用词形、双关、多义、词族或语义场景，但每个候选都要说明它怎样把词形/读音连到准确词义。若某种视觉笑点不能帮助回想目标词，就不作为本集主梗。如果音形不支持，不为完成表格硬造谐音。

补充的邵氏武侠英语样片属于**表现型参考**，不决定梗机制。风格标签（复古武侠、电影化动作、夸张反转）用于演出记忆梗；词卡给出准确拼写、IPA 和词义。

查看方法：两支全片按约每分钟抽帧浏览；开头约 120 秒做本地语音转写，另观察片尾回顾。B站字幕未能取回；没有逐秒完整拉片，也没有独立听写准确率、延迟回忆或对照组数据。播放量不证明观众学会。

观察到的稳定做法：

- 以语义主题组织词群（家庭成员、蔬菜瓜果），降低每个词孤立出现的感觉；
- 单词拼写、中文义、音标/发音提示、记忆联想、图示、例词/搭配有相对固定的版面；
- 一集结束有回顾/词表，形成即时检索；
- 视觉系统简洁重复，注意力集中在词和助记解释。

需要过滤的部分：样本里出现的字母拆分/联想是创作者的助记法，不能自动当作标准音节、词源或可靠发音教学。新稿必须以词典 IPA 为准，并把联想明确标成记忆钩子；听起来像不代表读音真的如此。

样本属于 28–30 分钟课程，表达相对静态，不是蛋仔双角色短剧。迁移建议是把主题词群和复习放在**系列/词包层**，把角色剧情留在单集；不要将几十个词或整段复习塞进一条短片。
