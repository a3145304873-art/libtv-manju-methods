# 旁白教学·制作方法 v1

> 2026-11-02 用户问：角色不发声、靠旁白的英语教学怎么做。
> 结论：**旁白＝唯一人声；蛋仔只做动作/表情，不开口、不配音、不对口型**。视频先出“无声表演”，旁白单独生成/录制，后期合。
> 适用于 `-like`、`-ful/-less` 等词族结构；和现在的“角色对话版”是两条线。

## 一、和对话版的区别

| | 对话版（现在） | 旁白版 |
| --- | --- | --- |
| 人声 | 心易问、黄蛋答 | **只有一个旁白** |
| 角色 | 说话、对口型 | **不发声、嘴巴闭合、只做动作** |
| 音频 | 视频模型生成对白 | 视频静音/环境声；旁白后期贴 |
| 优点 | 角色有性格、互动感 | 发音可控、口型不穿帮、制作简单 |
| 缺点 | 口型/音色不稳 | 角色像“哑剧演员”，靠表演和旁白撑 |

## 二、结构（先 3 词 / 15s）

```
旁白开场（2s）：like 是“像”。一个词加 like，就是“像它一样”。
词 1（4s）：旁白问 + 答 + 角色动作
词 2（4s）：旁白问 + 答 + 角色动作
词 3（4s）：旁白问 + 答 + 角色动作
收尾（1s）：你记住了多少？
```

- 6 词版：20s；每词 2.8–3s；开场 2s、收尾 1s。
- 旁白语速：约 5–6 字/秒；英文单词放慢、清楚；中文解释跟上。
- 不留角色对白气口；每词之间 0.2–0.3s 就切。

## 三、3 词旁白稿（`-like` 示例）

**旁白**：like 是“像”。一个词加 like，就是“像它一样”。

**旁白**：rocklike 是什么？  
**旁白**：rock 是石头——rocklike 就是像石头一样，坚固的！  
（黄蛋在石桌旁拍桌、摆“坚固”姿势；只做动作，不开口。）

**旁白**：snakelike 是什么？  
**旁白**：snake 是蛇——snakelike 就是像蛇一样，蜿蜒的！  
（黄蛋整臂做蛇形波浪；小蛇从花丛滑出；不开口。）

**旁白**：doglike 是什么？  
**旁白**：dog 是狗——doglike 就是像狗一样，忠诚的！  
（黄蛋拿狗绳、金毛摇尾；不开口。）

**旁白**：你记住了多少？  
（三张卡摆桌上：rocklike／snakelike／doglike；黄蛋点头。）

> 旁白可以自问自答；也可以只问不答、留 0.3s 给角色动作，再答。不要变成两个角色对话。

## 四、角色表演规则

- **不发声**：不配音、不“bo”、不拟声；角色声带完全静音。
- **不对口型**：嘴巴闭合/微笑/惊讶，不做说话开合；避免嘴部大特写。
- **只做动作**：拍、指、抱、扭、举、瘫、摇尾、点头；用身体和道具表达词义。
- **看镜头/看对象**：提问时看镜头或看动物；回答时看对象/做动作；不要“对着空气说话”。
- **镜头**：中景/中近景/侧 45°，少用正脸大特写；动作幅度大一点，弥补没有台词。

## 五、视频生成怎么写

每个视频节点：

- `generate_audio: false`（优先）；若平台仍给环境声，后期静音/压低。
- prompt 明确：
  - “角色**不发声、不说话、不口型、无对白**；只有动作、表情、环境声。”
  - “嘴巴闭合；不要说话开合；不要配音。”
  - “旁白/人声由后期添加，视频内无任何人声。”
- 不要写角色台词；不要把旁白写进角色 prompt。
- 环境声可以保留（石头落灰、蛇滑草、狗喘气），但**不能有角色说话声**；后期统一混。
- 如果需要“啊/嗯”等非语言声，也先不要；用户要求角色不发声。

## 六、旁白音频怎么做

### 方案 A：外部 TTS/录音（推荐）

- 一个旁白音色，全片统一；不要心易/黄蛋各配一个。
- 英文单词：慢、清楚、重音对；中文解释：自然、快半拍。
- 旁白稿按“词 1/词 2/词 3”分段生成，方便对齐；每段前后留 0.2s 静音。
- 工具：剪映“朗读”、Azure/Edge TTS、豆包 TTS、或真人录。
- 导出 48kHz WAV；不要带 BGM。

### 方案 B：Monet `gen-audio`（先试一条）

- 节点：`gen-audio`，`model_id: seed-audio-1.0`。
- 放在**后期组**，**不能接 video**（禁止 audio→video）；只作为声音母版。
- 现有案例只验证过非语言声音；**中文旁白能否稳定生成未验证**，先做一条 3s 测试，能出再批量。
- `reference_audios` 保持 `[]`；prompt 不放音频 token。
- 如果 TTS 出来像“念稿/机器”，换外部 TTS 或真人。

## 七、画布怎么接

1. 角色/场景/首帧：和现在一样（K 帧、A01–A04）。
2. 视频节点：`generate_audio:false`；prompt 写“角色不发声、不口型”。
3. 旁白：外部音频（推荐）或 `gen-audio` 节点；放在**后期组**，不接视频。
4. 成片：视频轨 + 旁白轨 + BGM/SFX 轨；旁白为主，BGM 压到 -18～-22dB。
5. 若用 `gen-audio`：它的输出只进后期，不进 `.monet` 的视频边。

## 八、后期合片

- 先铺旁白，再按旁白切视频；不要先剪视频再硬塞旁白。
- 每词：旁白问 → 0.2s → 角色动作 → 旁白答 → 0.2s → 切。
- 词卡：视频内出现（角色举卡/桌上摆卡）；如果卡面文字不稳，改用“角色指卡+旁白说词”，不要后期贴字。
- 结尾三卡复习：旁白逐个点，角色点头/指卡。
- 字幕可选；如果加，英文单词和中文解释分开，不要遮挡卡面。

## 九、验收清单

- [ ] 全片只有旁白一个人声；角色没有任何说话声/拟声。
- [ ] 角色嘴巴闭合，没有对口型；没有嘴部大特写穿帮。
- [ ] 每个词：旁白词义正确；角色动作对得上；卡面单词正确。
- [ ] 旁白英文发音清楚；中文解释不赶。
- [ ] 词与词之间没有长静音；总时长 15s/3 词或 20s/6 词。
- [ ] 结尾三卡复习 + “你记住了多少？”。
- [ ] BGM 不盖旁白；环境声不出现角色说话。
