# 黄蛋毛绒版·同水豚质感 v1

> 2026-11-02 用户问：黄蛋能不能也做成水豚那种质感。
> 可以：保留黄蛋身份，只换**短毛绒/毛毡玩偶材质**；不要改比例/五官。
> 画布：`02_画布/EP02-like-capybara-caption-plush-v1.monet`（16 节点 / 32 边 / 7 组；0 ERROR / 0 WARNING）

## 一、保留什么

- 黄色蛋形身体；
- 奶油色椭圆大脸板；
- 棕色大圆眼；
- 头顶黄色天线＋黄色圆球（角色本体，不拆）；
- 短圆手臂、无手指；
- 白色袜子（黑条纹）＋白色毛绒靴；
- 没有牙齿。

## 二、换什么

- 表面改成**短毛绒/毛毡玩偶**：细短绒毛、可见纤维、柔和缝线、哑光；
- 脸板：奶油色毛毡/布；
- 眼睛：亮面塑料/刺绣（保留一点高光）；
- 天线球：布球；
- 袜子/鞋：白布；
- 边缘有轻微绒毛轮廓；柔光棚拍，轻微投影。

**不要**：光滑塑料/搪胶、真实鸡蛋、蛋壳裂开、蛋黄/蛋液、牙齿、人类手指、猫耳/水豚耳朵、橘子、文字/logo。
