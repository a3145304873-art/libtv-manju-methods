# 芽芽 · 人设完整版 v1（候选 A）

> 2026-11-04｜状态：**proposed / 未确认**｜先人设，后设定图。
> 本文件只做人设设计，不出图、不改模板、不替换黄蛋共享卡。选定后才建 `_共享角色/<名字>/README.md`。
> 名字“芽芽”暂定，可换；人设不依赖名字。

## 〇、一句话

**一片总想替果子做决定的叶子。**
一只从心易橘子旁边长出来的叶子鸟，自称是她的“翻译”；他最大的本事，是听了一半就说“懂了”。

## 一、人设七问

| 问题 | 芽芽的答案 |
|---|---|
| 观众为什么看他？ | 他替观众先错一次。观众不敢问、不敢说错的那些词，他先冲上去说。 |
| 他想要什么？ | 被需要、被心易需要、被当成“懂的那个人”。 |
| 他怕什么？ | 被落下、被看穿“其实没懂”、没人听他说话。 |
| 他的矛盾是什么？ | 最会说的角色，最不懂；最不说的角色，最懂。 |
| 他每集怎么制造故事？ | 听一半→“懂了！”→立刻行动→世界打脸→“……” |
| 他和心易是什么关系？ | 他自称翻译，她从没任命；他解读她的动作，经常解读错；她不纠正，只用自己的身体把答案摆出来。 |
| 这些怎么变成看得见的东西？ | 头顶叶芽是“真相指示器”：先立起来，再慢慢卷下去。 |

## 二、身份卡

| 项 | 设定 |
|---|---|
| 名字 | 芽芽（暂定） |
| 物种 | 蛋型叶鸟：蛋形身体＋小三角喙＋短圆翅套＋大叶形尾＋头顶卷叶芽 |
| 体型 | 比心易高一头，13cm 左右；同一个蛋形模具，只换零件和涂装 |
| 年龄感 | 刚长出来不久，但不是婴儿；会说话、会行动，只是对世界太新 |
| 身份 | 自称“心易的翻译”；没有谁任命过他 |
| 住处 | 心易的橘子旁边；不摘橘子、不吃橘子、不碰橘子 |
| 日常 | 听词、猜意思、抢答、帮倒忙、被现实纠正、再试一次 |
| 一句话来历 | 心易头顶的橘子旁边，长出了一只叶子鸟；他第一眼看到的是心易，于是认定自己是她的翻译。 |

## 三、性格三层

### 表层：嘴快、自信、爱帮忙

- 听到一个新词，先给结论，再找证据；
- 喜欢抢在别人前面回答；
- 看到心易动一下，就立刻解释“她的意思是……”；
- 帮人帮得特别积极，经常帮倒忙。

### 里层：怕被落下、怕自己其实没懂

- 他说话快，是因为怕安静下来就轮不到自己；
- 他说“懂了”，是因为怕别人发现他不懂；
- 他被纠正后会不好意思，但不会恼羞成怒；
- 他最怕的不是错，是错的时候没人理他。

### 底线：不嘲笑心易、不撒谎、不抢橘子

- 他从不拿心易不说话开玩笑；
- 他相信自己说的，不是故意骗人；
- 心易的橘子是禁区，他只能坐在旁边；
- 他可以被现实打脸，但不会被打倒。

## 四、欲望 / 恐惧 / 矛盾

| 项 | 内容 |
|---|---|
| 表层欲望 | 做心易的翻译，做那个“先懂”的人 |
| 深层欲望 | 被需要、被留下、有一个属于自己的位置 |
| 表层恐惧 | 说错、出丑、被笑话 |
| 深层恐惧 | 被落下、被忽略、安静下来就没人记得他 |
| 核心矛盾 | 他太想懂，所以总在最该听的时候开口 |
| 可爱之处 | 他错得很认真，而且错完还愿意再来一次 |

## 五、喜剧引擎：三个“懂”

每一集不需要三个都出现，但情绪弧要完整：

| 拍 | 台词 | 动作 | 观众看到 |
|---|---|---|---|
| 1 | **“懂了！”** | 叶芽“唰”地立直，喙张开，身体前倾，立刻行动 | 他又要先错了 |
| 2 | **“懂了？”** | 世界打脸；叶芽慢慢卷下去，叶尾夹紧 | 他自己也开始怀疑 |
| 3 | **“……懂了。”** | 叶芽放松，喙闭上，看向心易 | 这次可能是真的 |

### 变体

- **真懂**：第 3 拍真的懂了，心易“咔啵！”；一季里不要太多，留给关键集；
- **装懂**：第 3 拍还在装，叶芽没立起来；观众知道，心易也知道；
- **心易先懂**：心易用动作把答案摆出来，芽芽才懂；不是他聪明，是他终于看了；
- **一起错**：两个人一起误判，最后一起收场；不总是芽芽一个人出丑。

### 每集必须有的具体动作

不是“他误解了”，而是一个可拍的动作：
- 听错一个词，立刻把道具用错；
- 把心易的一个动作当成“同意”，马上执行；
- 把英文词的字面意思当真，做出一个荒唐但认真的行为；
- 说到一半停住，因为发现所有人都在看他。

## 六、和心易的关系

### 核心动态

- **他自称翻译，她从没任命。**
- 他不替她说话；他解读她的**动作**，而且经常解读错。
- 她从不用话纠正他；她用自己的身体把答案摆出来：指、挡、坐、拉、看、把东西推到他面前。
- 她的“咔啵”是留白；他往里面填答案。观众知道那是他填的，不是她说的。

### 一条硬规则：不许替心易发言

- 芽芽**不能说**“心易说……”“心易的意思是……然后替她补完整句”；
- 他只能说“我猜心易的意思是……”“她刚才看了我一眼，一定是……”；
- 旁白可以拆穿：“心易只是打了个哈欠。”
- 心易的“咔啵”不能被任何角色翻译成人类语言；观众自己看懂她的动作。

这条规则同时保护心易的全局设定和芽芽的喜剧位置：**他不是她的代言人，他是一个猜错的人。**

### 长期弧

- 从“替她说”到“听她说”；
- 从“怕错”到“敢错”；
- 从“心易忍着他”到“心易需要他”；
- 心易不改变“不说话”的设定，但她的动作可以从“被动回应”变成“主动引导”。

### 不能做的事

- 不拿心易的沉默开玩笑；
- 不替心易说人话、不写她的内心独白；
- 不把心易写成“负责纠正他的老师”；
- 不把芽芽写成“每次都被惩罚的笨蛋”；
- 不固定“芽芽闯祸、心易旁观”的单一公式。

## 七、语言系统

### 说话方式

- 短句、快、先结论后证据；
- 兴奋时更快，心虚时突然变慢；
- 不确定时重复对方最后两三个字：“……没有肉丝？”；
- 说英文词时先自信、后迟疑、最后正确；
- 不讲课、不解释语法、不说“同学们”、不拿教鞭。

### 固定台词

| 台词 | 用法 | 限制 |
|---|---|---|
| **“懂了！”** | 听一半就抢答 | 每集最多 1–2 次，不能变成口头禅轰炸 |
| **“懂了？”** | 世界打脸后的自我怀疑 | 轻，不嚎 |
| **“……懂了。”** | 真正理解 | 轻，慢，不煽情 |
| **“诶？”** | 听错/没听清 | 短，不拖 |
| **“我猜心易的意思是……”** | 解读她的动作 | 必须被画面或旁白拆穿，不能成真 |
| **“你看，她‘咔啵’了。”** | 把她的拟声当回答 | 他说的是“她咔啵了”，不是替她发“咔啵” |

### 不能说的话

- 不解释词义、不讲构词法、不做课堂总结；
- 不说“心易说……”“心易觉得……”；
- 不发出“咔啵”这个声音；
- 不说“真不错/真棒”（夸赞归心易，按项目模板）；
- 不嘲笑心易、不拿她的沉默做梗。

### 旁白的关系

- 旁白是独立的“真相声线”，不是芽芽的内心；
- 旁白可以冷幽默：“芽芽懂了。可惜懂错了。”；
- 旁白负责解释词义，芽芽负责把词用错一次、再用对一次；
- 旁白不替心易说话。

## 八、生活角色与故事位

| 角色位 | 用法 |
|---|---|
| 自称翻译 | 解读心易的动作，经常解读错；观众看他猜 |
| 新词第一反应者 | 听到词就行动，制造字面误会 |
| 帮倒忙的人 | 想帮忙，结果把事情弄得更糟；不是恶意 |
| 试错者 | 替观众先把词用错一次，再被现实纠正 |
| 偶尔的赢家 | 一季里少数几次真的懂了；观众会记住 |

### 不固定的东西

- 不总是他闯祸；有时心易闯祸，他误读；
- 不总是他错；有时他对了，但没人信；
- 不总是他说话；他也有听完再说的集数，那集要留给他真正听懂。

## 九、成长弧

### 单集

“懂了！”→ 懂错 → “懂了？”→ “……懂了。”

### 一季

- 前段：他抢答、猜错、被拆穿；
- 中段：他开始先看心易的动作，再开口；
- 后段：他有一次真的听懂了她，不靠台词；
- 终点：他还是会抢答，但他学会了听完。

### 观众

- 从“看他出丑”到“替他着急”；
- 从“这个词我也不懂”到“这次我听完了”；
- 从“心易到底什么意思”到“我好像看懂她了”。

## 十、视觉翻译

| 人设 | 视觉 | 怎么演 |
|---|---|---|
| 急着说 | 小三角喙先开、身体前倾、翅套抬起 | 话比脑子快 |
| 听一半 | 头歪向声源、叶芽先立后卷 | 只听到前半句 |
| 自信 | 叶芽笔直、叶尾翘起 | “懂了！” |
| 被拆穿 | 叶芽慢慢卷下去、叶尾夹紧、喙闭上 | “懂了？” |
| 真的懂 | 叶芽放松、喙闭合、看向心易 | “……懂了。” |
| 怕被落下 | 靠近心易、翅套抓住她的身体/道具 | 不是撒娇，是确认她还在 |
| 想帮忙 | 翅套抱太多东西、叶尾扫到道具 | 帮倒忙的物理来源 |

### 眼睛的意味

- 心易：白片＋棕圈，中心空白——**不评判**；
- 芽芽：黑片＋琥珀圈＋一个白高光——**在寻找**，找答案、找认可、找心易的反应；
- 一个“空”，一个“满”；一个接纳，一个索求。

### 嘴的意味

- 心易：一条横线，不动——**不说话**；
- 芽芽：小三角喙，会开合——**话比脑子快**；
- 嘴就是他的角色。

### 颜色与材质

- 心易暖棕＝稳定、落地；芽芽叶绿＝生长、变化；
- 共用奶油白＝同一个玩具系列；
- 共用琥珀橘＝同一个“橘子家族”；
- 同为短毛绒/毛毡、哑光——同一个世界，不是两种材质。

### 体块与构图

- 芽芽高一头，能 leaning over 心易；心易低坐，稳；
- 他前倾，她后靠；他动，她静；
- 双人构图天然有戏：一个在说，一个在听；一个在错，一个在等。

## 十一、人设禁区

- **不教师腔**：不讲课、不解释语法、不说“同学们”；
- **不替心易说话**：不写“心易说/心易觉得”，不翻译她的“咔啵”；
- **不油腻、不自大**：他的自信是热情，不是看不起别人；
- **不撒谎**：他真的相信自己懂了；
- **不是纯小丑**：他会不好意思，会难过，会再来一次；
- **不每集都他闯祸**：心易也可以闯祸，他也可以只是误读；
- **不抢橘子**：心易的橘子是本体，不能摘、不能吃、不能换；
- **不发“咔啵”**：这个声音只属于心易；
- **不抢夸赞**：夸赞归心易（按项目模板）；
- **不把心易写成工具人**：她有自己的目标，不是专门等他犯错。

## 十二、观众记忆点

- **一句台词**：“懂了！”
- **一个动作**：头顶叶芽先立起来，再慢慢卷下去；
- **一个关系**：自称是心易的翻译，其实一直在猜；
- **一个反差**：最会说的角色最不懂，最不说的角色最懂；
- **一句承诺**：说错也有人听你说完；
- **栏目名建议**：《芽芽懂了》（可做蛋仔记单词的子栏目名，不改项目名）。

## 十三、第一集验证

- [ ] 观众能不能在 3 秒内看懂“他听一半就开始懂”？
- [ ] “懂了！”和“……懂了。”能不能成为记忆点？
- [ ] 叶芽的“先立后卷”能不能不靠台词说明他错了？
- [ ] 心易的“咔啵”有没有被误读成台词？
- [ ] 旁白有没有变成课堂？
- [ ] 20 秒内有没有一次真正的“听完整”？
- [ ] 观众是笑他，还是替他着急？后者才对。

## 十四、B / C 的人设骨架

### B. 阿栗｜蛋型松鼠

- **一句话**：一只把词当坚果囤的松鼠，囤得越多，越拿不出来。
- **欲望**：把每个词都存住，不再丢东西；**恐惧**：用完就没了、被借走、被忘记。
- **矛盾**：他收集词，却不会用词；他怕丢，所以藏得太深。
- **引擎**：把词藏进叶尾/颊袋→要用时拿错→掉出一堆错词。
- **和心易**：他给心易的“咔啵”贴标签、归档，贴错；她不是他的档案。
- **记忆点**：叶尾一抖，掉出一个错词。
- **风险**：容易写成“背单词”而不是“用单词”。

### C. 哨哨｜蛋型狐獴

- **一句话**：一只永远在站岗的狐獴，负责先发现，也负责先误会。
- **欲望**：被需要、被当成“有用的人”；**恐惧**：漏掉信号、来不及提醒。
- **矛盾**：他先报警，后确认；他怕漏，所以总是误报。
- **引擎**：在生活里“发现”一个词→拉警报→结果是虚惊→真信号来了，他又没看见。
- **和心易**：他把心易当基地，向她报告；她只“咔啵”，他照样报告。
- **记忆点**：眼罩一紧，警报拉响，结果是虚惊。
- **风险**：“哨兵”梗容易重复；性格对称强，但成长弧比 A 窄。
