# 15s 短卡·morose 故事设计 v1（心易表演位／芽芽说话位）

> 2026-11-04｜状态：**proposed / 未确认 / 结构已被 v2 取代**｜用途：按用户“心易不能说话，只能演绎剧情”，设计第一支 15s 一词一梗短卡。
> **2026-11-04 后续**：用户反馈“没有惊喜，一开始就说了没肉丝”；结构改为**先演后揭**，见 [54](54-15s短卡-morose-先演后揭-v2.md)。本文件 0–2s 报梗的节拍作废旧版，其余“心易只演/芽芽不代说”原则保留。
> 依据：[40 邪修格式](40-邪修英语赛道对照与格式选择-v1.md)、[41 morose 15s 样片](41-15s短卡-morose-样片-v1.md)、[46 兜帽蛋仔设计](46-二号角色-玄凤兜帽蛋仔-设计-v1.md)、[52 无星表情](52-二号角色-表情无星v2-验收-v1.md)。
> 角色：心易＝水豚，只“咔啵”；芽芽＝玄凤兜帽蛋仔，说话位；卡尾后期。

## 一、核心原则（这支片子的底线）

1. **心易不说话**：只发“咔啵”四调；不写人话、不写内心独白、不让芽芽代说“她说……”。
2. **动作就是剧情**：把芽芽的台词全部静音，观众仍能看懂——心易想要什么、发生了什么、她什么反应。芽芽的词只是给这件事“贴标签”。
3. **芽芽不替心易发言**：他只说词/谐音/真义，或对老板/镜头说话；不转述心易的想法。
4. **一个词、一个梗、一个后果**：15s 不塞第二个词；梗必须真的造成画面里的后果。
5. **词义准确**：谐音“没肉丝”是记忆钩子；真义“郁闷的”必须词典核对；卡面给拼写/义。

## 二、系列故事引擎

> **心易想要一件小事 → 芽芽抛词/抛梗 → 心易把词演成真 → 芽芽给真义 → 心易用咔啵反应 → 卡。**

- 心易的愿望必须 **2 秒内可读**（指、够、护、递），不靠台词。
- 芽芽的台词 **≤3 句短句**：抛梗句、真义句（可加一句“记住了吗”）。
- 梗要参与因果：芽芽的谐音/误说/误操作，真的改变了心易的处境；不能只是事后解释。
- 结尾用“咔啵”的情绪收，不用旁白讲道理。

## 三、第一支：morose = 没肉丝 → 郁闷的

### 故事一句话

心易想点青椒肉丝饭；芽芽练“morose”练成“没肉丝”，又抢着替她点单，结果饭盒里真的没有肉丝；心易郁闷，芽芽这才把词说对。

### 15s 节拍

| 时间 | 心易（不说话） | 芽芽（说话） | 画面/道具/声音 |
|---|---|---|---|
| 0–2s | 指柜台上的肉丝小碟，眼睛亮；**“咔啵！”**（兴奋） | 5A 得意：“morose——没肉丝。” | 中景，小饭馆柜台；肉丝小碟在柜台上；桌上一只**关着的餐盒**＋勺子 |
| 2–4s | 等餐，歪头看芽芽 | 芽芽冲窗口：“老板，没肉丝！”（他以为在帮点单） | 窗口递出**关着的餐盒**；芽芽接过放桌 |
| 4–7s | 两只短手捧盖掀开，盖放桌面；夹勺拨两下，只有青椒；耳朵耷下；**“咔啵？”**（疑惑） | 芽芽看到她的脸，5B 被抓包（小汗滴） | 推近盒内；勺碰盒；无肉丝 |
| 7–11s | 看芽芽，等解释 | 5B 转认真：“没肉丝，所以郁闷——morose，郁闷的。” | 中景双人；芽芽看心易/镜头 |
| 11–12s | 低头，**“咔……啵……”**（难过） | 芽芽看她 | 近景心易；定格 |
| 12–15s | — | （卡） | 单卡：morose／没肉丝 → 郁闷的 |

### 因果链（必须成立）

1. 心易指肉丝 → 观众知道她想要肉丝。
2. 芽芽的“morose——没肉丝”是他在练词，不是翻译；观众听到“没肉丝”。
3. 芽芽抢着点单“老板，没肉丝！”→ 窗口真的按“没肉丝”出餐。
4. 心易打开：只有青椒 → 她的愿望落空 → 郁闷。
5. 芽芽这才把“没肉丝→郁闷”说成真义；词和画面对上。

### 心易的表演（无台词）

- **愿望**：指肉丝小碟，眼睛亮；“咔啵！”上扬。
- **等待**：双手放桌，歪头看芽芽；不抢戏。
- **发现**：捧盖、掀开、盖放桌、夹勺拨两下；耳朵从立到耷；肩膀垮。
- **疑惑**：“咔啵？”（升调）看芽芽。
- **难过**：“咔……啵……”（低、慢、弱）低头。
- 只两只短手；不出现多余手臂/手指；勺子是细长直柄，不是木勺。

### 芽芽的表演（说话位）

- 0–2s：5A 得意/懂王；说“morose——没肉丝”时一本正经，像在炫词。
- 2–4s：还是 5A，冲窗口喊“老板，没肉丝！”；他以为自己在帮忙。
- 4–7s：看到心易耷拉，切 5B 被抓包；小汗滴；不敢看她。
- 7–11s：从 5B 转认真；说真义；不嬉皮笑脸。
- 11–12s：看她，收住；不说“别难过”之类的大话。
- 不写“她说……”，不替心易解释内心；他的错和解释都是他自己的。

### 静音测试

把芽芽的台词全部静音，只看画面：

指肉丝 → 等 → 接盒 → 开盒只有青椒 → 拨找 → 耳朵耷 → 看芽芽 → 低头。

**能看懂“她想要肉丝、没吃到、郁闷”。** 芽芽的词只是把这件事叫 morose。测试不过就改动作，不靠加台词补救。

## 四、画面与资产

| 项 | 要求 |
|---|---|
| 场景 | 小饭馆柜台/出餐口；暖光；柜台上有**肉丝小碟**（给心易指） |
| 餐盒 | 一只，**首帧关着**；窗口递出；到桌才开；盒内只有青椒，**无肉丝** |
| 勺子 | 首帧在桌面；心易两只短手夹住；用完放回 |
| 心易 | 水豚标准＋R02E 锁眼；只咔啵；短手短脚；耳朵/身体演 |
| 芽芽 | 4A 经典灰兜帽蛋仔（无星）；5A/5B 表情参考；短圆蛋仔手；帽上小喙装饰 |
| 卡 | 后期静帧 3s：morose／没肉丝 → 郁闷的；视频内无字 |
| 声音 | 芽芽人声；心易咔啵；环境声（盒盖/勺子）；BGM -18～-22dB；无旁白 |

## 五、15s 画布跑序（下一步）

1. K_A 首帧：柜台/肉丝小碟/关盒/勺子/心易指/芽芽 5A。
2. V1 0–7s：抛梗→误点单→接盒→开盒→拨找→耷拉；结尾稳定 1s。
3. 截 V1 尾帧 → T_A。
4. V2 7–12s：首帧 T_A；芽芽 5B 被抓包→认真给真义；心易“咔……啵……”。
5. 卡 12–15s：后期静帧。
6. 跑完做静音测试；不过就改动作，不加旁白。

## 六、验收

- [ ] 心易全程只“咔啵”，没有人话/内心独白/代说。
- [ ] 芽芽没有“她说……”；台词≤3 句短句。
- [ ] 静音能看懂：想要肉丝→没吃到→郁闷。
- [ ] 梗参与因果：芽芽的“没肉丝”真的导致饭盒没肉丝。
- [ ] 盒内无肉丝；盒首帧关着；盖放桌面；勺子细长直柄。
- [ ] 心易只有两只短手；耳朵/身体演情绪。
- [ ] 芽芽 5A→5B→认真；蛋仔手；帽上小喙不动。
- [ ] 词义准确；卡面拼写/义正确；视频内无字。
