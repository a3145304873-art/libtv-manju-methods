## 二、逐项验收

| 项 | 结果 | 判断 |
|---|---|---|
| 四格是同一只角色 | 同奶油身体、同暖灰玄凤帽、同黄羽冠/蜜桃腮斑/粉钩喙、同脸板/单眉/星高光 | **过**；没有漂成四只不同角色 |
| 四格表情可区分 | 得意：半眯＋歪嘴；被抓包：瞪眼＋波浪嘴＋汗滴；惊讶：圆眼＋小圆嘴；无语：半眯＋平线嘴 | **过** |
| 单边挑眉 | 四格都在观众左眼上方，位置一致 | **过** |
| 星形高光 | 四格都在观众右眼，位置一致 | **过** |
| 帽上小脸/冠羽 | 侧看/瞪大/圆睁/半眯；翘/耷/竖/平，跟着表情变 | **过**；二重脸成立 |
| 1×4 版式 | 横向四格、细浅灰分隔线、无文字/标签 | **过** |
| 毛绒/蛋仔身体 | 短绒/毛毡；蛋形半身；不是鸟体/翅膀手 | **过** |
| 无狗/猫帽、M、文字 | 过 | 过 |
| 128px 整张 | 四格能看出不同，但每张脸很小；256/512px 才清楚 | **半过**；表情表是设定稿，不是缩略图 |
| 四格一致性 | 头身比例/半身大小有轻微差异；3 号略大、4 号略小 | 可接受；不是换角色 |

## 三、小问题（不阻断）

- **128px 太小**：一张 1×4 表，128px 下每张脸只有约 30px；表情表看大图，小尺寸用 5A/5B 单张。
- **半身比例轻微差异**：3 号略大、4 号略小；不影响“同一只角色”的判断。
- **4 号“无语”很淡**：平线嘴＋半眯眼，风格对，但远看容易以为没表情；若要更明显，可把眉压低/嘴角下压一点。
- **2 号汗滴偏小**：256px 可见，128px 弱。
- **3 号小圆嘴带一点红**：像小舌/口腔，可爱；若严格“无舌”，可改深色口腔。

## 四、结论

- **一张图 1×4 表情表成功**：四格同一只角色，四个表情能区分，单眉/星高光/帽上小脸都保持。
- 这张表适合当**角色设定稿/表情总表**；15s 视频里用 **5A/5B 单张**（或从表里裁格）更稳，尤其小尺寸。
- 角色当前是 **4A 经典灰**；若定 4B 暖杏，需要再出一张 4B 版表情表（或后期调色，不推荐直接调）。
- 表情系统可以定稿：默认 5A、反应 5B、惊讶/无语备用。
