## 一、三种逻辑，为什么选解读

| 逻辑 | 芽芽在做什么 | 问题/优点 |
|---|---|---|
| **翻译** | 把心易的咔啵/意思翻成人话 | 心易没有说话，翻译什么？容易变成代她发言；观众没有惊喜 |
| **解说/旁白** | 他知道词，直接讲给观众 | 像教学/旁白；心易变道具；没有角色弧 |
| **解读** | 他读心易的行为/现场，可能读错；观众看得见真相；词是正确解读 | **推荐**：保住心易主角位；有误会/翻车/惊喜；词是最后一块拼图 |

- 解读不是“替她说话”：芽芽说的是**他自己的猜测**（“我猜/我读/根据我的观察”），不是“她说”。
- 解读可以错：他自信读错 → 照错的做 → 出后果 → 心易用行动纠正 → 他读对，给词。
- 词是“正确解读”的标签，不是翻译她的语言；这正好贴“心易只能演”。

## 二、解读位引擎

> **心易想要（只演）→ 芽芽误读（自信）→ 照错的做 → 小后果 → 心易用行动纠正 → 芽芽读对，给词 → 心易咔啵 → 卡。**

- 心易的愿望/反应必须 2 秒可读；她全程只咔啵。
- 芽芽的误读要“近义但不对”：不是随便胡闹，而是听起来合理的错读。
- 词在最后出现；前面只说他的误读，不报词、不报“没肉丝”。
- 芽芽的误读/纠正都是他自己的；不写“她说……”。

## 三、morose 15s 节拍

| 时间 | 心易（不说话） | 芽芽（说话） | 画面/因果 | 声音 |
|---|---|---|---|---|
| 0–3s | 指柜台上的肉丝小碟，眼睛亮；**咔啵！** | 5A 得意：“根据我的观察——她今天想吃清淡的。” | 肉丝小碟、关盒、勺；心易指碟 | 环境声 |
| 3–5s | 等餐，歪头看芽芽 | 芽芽指肉丝小碟对窗口：“那个不要。” | 窗口的手把肉丝碟撤走/不出肉丝；盒关着 | 无 vendor 台词 |
| 5–8s | 接盒、捧盖掀开、盖放桌；夹勺拨两下，只有青椒；耳朵耷下；**咔啵？** | 看到她的脸，5B 被抓包（小汗滴） | 推近盒内；无肉丝；勺碰盒 | 盒盖/勺 |
| 8–11s | 看芽芽，等解释 | **“等等……我读错了。不是清淡，是——morose。没肉丝，郁闷的。”** | 双人中景；5B 转认真 | 芽芽台词 |
| 11–12s | 低头，**咔……啵……** | 看她 | 近景心易 | 咔啵 |
| 12–15s | — | （卡） | morose／没肉丝 → 郁闷的 | BGM 收 |

- 15s 紧；8–11s 的“读错→读对→真义”如果装不下，放 16–18s，不硬压。
- 前 8 秒不出现“没肉丝”，也不出现“肉丝”这个词；只有画面里的肉丝小碟和“那个不要”。
- 8–11s 是词第一次出现，也是“肉丝”第一次被说出来；观众把刚才的怪事和词对上。

## 四、惊喜在哪（三层）

1. **她明明指了肉丝，芽芽却读成“想吃清淡的”**——他读错了。
2. **他照错的读法做，把肉丝拒了**——饭盒真的没肉丝；心易不知道。
3. **第 8 秒他读对：“morose——没肉丝”**——观众把“他刚才的误读”“饭盒没肉丝”“这个词的音”三件事扣上。

不是“先告诉你谐音再演”，是“先让你看见他读错，再让他读对”。

## 五、心易的表演（无台词）

- **想要**：指肉丝小碟，眼睛亮；“咔啵！”上扬。
- **等待**：双手放桌，歪头看芽芽；不知道窗口发生了什么。
- **发现**：捧盖、掀开、盖放桌、夹勺拨两下；耳朵从立到耷；肩膀垮。
- **疑惑**：“咔啵？”（升调）看芽芽。
- **难过**：“咔……啵……”（低、慢、弱）低头。
- 只两只短手；无多余手臂/手指；勺子细长直柄。

## 六、芽芽的表演（解读位）

- 0–3s：5A 得意；用“根据我的观察”开头，像个小侦探/行为解读师；**读错**成“想吃清淡的”。
- 3–5s：照错的读法做——指肉丝小碟说“那个不要”；自信，不觉得有问题。
- 5–8s：看到心易耷拉，切 5B 被抓包；小汗滴；知道自己读错了。
- 8–11s：从 5B 转认真；**“我读错了。不是清淡，是——morose。没肉丝，郁闷的。”** 词是“正确解读”，不是翻译。
- 11–12s：看她，收住；不说“别难过”之类的大话。
- 不写“她说……”，不替心易解释内心；他的误读/纠正都是他自己的。

## 七、静音测试

把芽芽全部台词静音，只看画面：

心易指肉丝小碟 → 等 → 芽芽指小碟对窗口说“那个不要” → 接盒 → 开盒只有青椒 → 拨找 → 耳朵耷 → 看芽芽 → 低头。

**能看懂“她想要肉丝、芽芽把肉丝拒了、她没吃到、郁闷”。** 词只是最后给这件事命名。

## 八、和“邪修词卡”的关系

- 纯邪修词卡是“一词一梗，先抛梗再演”，词卡效率高，但心易容易变道具。
- 解读位是**故事/角色型**：词在结尾当“读对了”的答案；市场依据是宠物沟通师/Blue's Clues 这类“解读沉默角色”的强品类（见 39），不是纯词卡。
- 这是用角色/故事换纯词卡的即时效率；如果用户要纯词卡，另做 `parrot15` profile，不混。

## 九、下一步

1. 确认解读位逻辑；因果用“误读成清淡→拒肉丝”（推荐）。
2. 确认 15s 还是 16–18s；15s 紧就放 16–18s。
3. 建 15s 画布：K_A（柜台/肉丝碟/关盒/勺/心易指/芽芽 5A）→ V1 0–8s（误读/拒肉丝/开盒/耷拉）→ T_A → V2 8–12s（5B 被抓包→读对/真义/咔啵）→ 卡 12–15s。
4. 跑完做静音测试；不过就改动作，不加旁白。

## 十、验收

- [ ] 前 8 秒没有“没肉丝”，也没有“肉丝”这个词；只有画面里的肉丝小碟。
- [ ] 芽芽的误读是“我猜/我读”，不是“她说”；不代心易发言。
- [ ] 误读是“近义但不对”（清淡 vs 郁闷），不是随便胡闹。
- [ ] 误读真的造成后果（肉丝被拒、饭盒没肉丝）。
- [ ] 第 8 秒词第一次出现时，观众已经把事件看完整。
- [ ] 静音能看懂：想要肉丝→被拒→没吃到→郁闷。
- [ ] 心易全程只咔啵；没有人话/内心独白/代说。
- [ ] 芽芽没有“她说……”；台词≤3 句短句（误读、读对、真义）。
- [ ] 词义准确；卡面拼写/义正确；视频内无字。
