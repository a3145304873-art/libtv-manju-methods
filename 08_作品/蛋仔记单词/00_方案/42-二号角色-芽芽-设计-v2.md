## 二、三个方向

| 方向 | 参考风格贴合 | 芽芽身份 | 说话可读性 | 复杂度 | 判断 |
|---|---|---|---|---|---|
| **2A 蛋形＋叶鸟连帽** | 高 | 高（叶鸟帽） | 高（脸板嘴说话） | 中 | **推荐** |
| 2B 蛋形鸟体（无帽） | 中 | 最高（鸟体） | 最高（喙说话） | 低 | 备选 |
| 2C 直接用狗/猫帽 | 最高 | 低（丢叶鸟） | 高（脸板嘴） | 低 | 不推荐 |

- **2A**：保留参考图的“蛋形＋连帽衫”语言；芽芽是“奶油白蛋仔穿雾青绿叶子鸟连帽”。帽前额的小三角喙是装饰，**说话用脸板的嘴**。
- **2B**：没有连帽，鸟喙就是嘴；更像 38 的“蛋型动物塑”，但离参考图远。
- **2C**：最像参考图，但芽芽的叶鸟/学舌身份没了，名字也要换。

## 三、2A 外形锁

| 部位 | 锁 |
|---|---|
| 整体 | 蛋形身体，头身一体，无脖子，头约占全身一半；13cm 玩具比例；站姿，短手短脚 |
| 材质 | 短毛绒/毛毡，毛茸茸、哑光、纤维可见，边缘有细绒光；参考图只借形体，不借光滑 3D；不是搪胶/塑料/写实鸟 |
| 身体 | 奶油白/米白毛绒蛋形身体；胸口一枚毛毡/刺绣小叶子徽章（金色/奶油色）；**不要 M 标志** |
| 连帽 | 雾青绿毛毡叶子鸟连帽衫，覆盖头顶和后脑；帽前额一个小三角琥珀喙（闭合，装饰，不是说话嘴）；帽顶一株毛毡卷叶芽，芽尖一颗小琥珀球；帽后下方一片大叶形毛毡尾羽（深青绿，中央浅色缝线叶脉） |
| 脸板 | 奶油色大圆脸板，占正面大部分；边缘一圈浅绿细边 |
| 眼睛 | 大圆眼：白眼球＋琥珀棕虹膜＋黑瞳孔＋一个白高光；毛绒玩偶的固定眼片/刺绣眼工艺，可眨、可做表情；**不是心易的白片无瞳**；不是写实眼/光滑塑料反光 |
| 嘴 | 张嘴笑，红色毛毡舌，无牙；**说话时用脸板的嘴开合，帽子上的喙不动** |
| 手臂 | 两只短圆毛绒手臂，奶油白，末端雾青绿毛毡手套；无手指 |
| 腿/鞋 | 两条短腿，奶油白/浅黄短袜＋白色毛毡小靴，靴口雾青绿边；无脚趾 |
| 头顶 | 连帽的毛毡卷叶芽＋芽尖小琥珀球；不是心易的橘子 |
| 声音 | 明亮、偏快、清楚；有点“懂王”的得意；说英文词清楚 |
| 标志道具 | 一根小木指针，尖端一片小叶子；场景道具，不是身体一部分 |

**和 v1 的关键差别**：v1 是“短毛绒叶鸟，喙就是嘴”；v2 是“奶油白蛋仔穿叶鸟连帽，脸板的嘴说话，帽上的喙是装饰”。这是参考图的“动物连帽衫”语言决定的。

## 五、不复制的东西（IP 边界）

- **不复制**参考图的狗耳/猫耳连帽、帽上狗/猫脸、金色“M”标志、具体配色、角色身份。
- 胸口改**小叶子徽章**（金色/奶油色），或者不加；不要出现“M”形。
- 参考图是用户提供的风格参考，不是本项目角色资产；不把它们直接当芽芽的设定图使用。

## 六、材质：用户更正为全毛绒（参考图只借形体）

参考图是哑光 3D 乙烯基/搪胶；用户要求芽芽也毛茸茸，实际采用**全毛绒**，参考图只借形体。以下 A/B/C 保留作历史对照：

| 方案 | 做法 | 优点 | 风险 |
|---|---|---|---|
| A（曾选，已改） | 芽芽用参考图的 3D 材质；心易保持毛绒 | 最贴参考图；毛绒 vs 3D 的对比有“玩具收藏”感 | 材质不统一；用户已改为全毛绒 |
| B | 3D 身体＋毛绒连帽 | 材质桥接；帽子和心易同质感 | 设计更复杂；生成容易混材质 |
| C | 全毛绒芽芽 | 和心易统一；更像毛绒世界 | 离参考图远；参考图只借比例 |

- 黄蛋共享卡的“同镜材质一致”是针对黄蛋的；芽芽是新角色，需要项目单独定。
- 实际用 C 全毛绒；参考图只借形体。

## 七、性格、功能、声音（沿用 v1）

- **短卡（抛梗解说位）**：说词＋谐音，一本正经；最后给真义。用**脸板的嘴**说话；帽子上的喙不动。
- **故事（解读位）**：读错心易的行为→照错的做→小后果→心易纠正→读对给词。
- **性格**：嘴快、爱学舌、爱拽英文；自信到有点欠；爱面子，被纠正时僵住/眨眼，下次还犯；对心易忠诚。
- **声音**：明亮、偏快、清楚；少年感/机灵，不低音、不油腻；英文词咬清楚。
- **关系**：一个不说，一个爱说；芽芽不替心易说“咔啵”、不说“心易问……”。
