# 锁眼仅心易·黄蛋豁免 v1

> 2026-11-02 用户指出：黄蛋是会眨眼/做表情的，全局“不眨眼/不要眼皮”会误伤黄蛋。
> 本版把眼睛限制**只锁心易**，并在心易角色/参考图出现的位置写清楚；黄蛋明确豁免。
> 画布：`02_画布/EP02-like-capybara-tail-v4-eyes-scoped.monet`（17 节点 / 25 边 / 7 组；0 ERROR / 0 WARNING）

## 一、为什么要分角色

上一版负向写的是：

```text
眼皮、眼睑、眉毛、眨眼、眯眼、瞳孔放大/缩小...
```

没有主语，模型可能把**黄蛋**也锁成死鱼眼。  
黄蛋是蛋仔，眼睛本来就会眨、会看、会做表情；不能一起锁。

## 二、现在的写法

### 1. 在心易角色/参考图处写

```text
【心易眼睛·仅限心易】心易是毛绒玩具，眼睛是固定塑料/刺绣件，不是生物眼：
白色圆形眼白、黑色小圆瞳、单个高光；
眼白形状、瞳孔大小/位置、开合度全程完全不变；
不眨眼、不眯眼、不抬眼皮、不皱眉、不转瞳孔、不放大缩小、不出现泪光；
情绪只靠歪头/身体/手势/咔啵。
**黄蛋不受此限制：黄蛋的眼睛可以正常眨眼、看、做表情，不要套用。**
镜头以中景/中近景为主，不要心易眼睛大特写。
```

### 2. 负向也只写“心易的”

```text
心易的眼皮、心易的眼睑、心易的眉毛、心易的眨眼、心易的眯眼、
心易的半闭眼、心易的瞳孔放大/缩小、心易的瞳孔移动、心易的眼神变化、
心易的眼球转动、心易的泪光、睫毛、眼影、虹膜变色、眼睛变形、
卡通大眼、拟人化眼神、心易的眼睛大特写；
不要限制黄蛋的眼睛，不要给黄蛋加眼罩/无眼/死鱼眼
```

**不再**写无主语的“不眨眼/不要眼皮”，避免误伤黄蛋。

## 三、两角色口径

| 角色 | 眼睛 |
| --- | --- |
| 心易（水豚） | 固定玩偶眼：白圆眼白、黑小圆瞳、单高光；不眨眼/眼皮/瞳孔变化 |
| 黄蛋（毛绒蛋） | 正常眼睛：可以眨眼、看、做表情、惊讶/开心；不要锁 |

- 心易情绪：歪头、点头、抬手、耷拉、咔啵、后期气泡；
- 黄蛋情绪：眼睛＋嘴＋身体都可以用。

## 五、跑 V1 看什么

1. 心易：0s/1s/2s/3s 眼睛是否完全一样（眼白/瞳孔/开合度）；
2. 黄蛋：是否还能正常眨眼/看/做表情；
3. 如果心易还漂：拆短或后期锁眼，**不要回头锁黄蛋**；
4. 如果黄蛋被锁成死鱼眼：说明负向还在误伤，重跑/再收紧主语。

## 六、兜底

- 心易还漂：V1 拆 5s＋5s，或后期 R02F 贴眼；
- 黄蛋被锁：确认负向没有无主语“眨眼/眼皮”，prompt 里保留“黄蛋不受此限制”；
- 两边都要：只能分角色写，不能全局一刀切。
