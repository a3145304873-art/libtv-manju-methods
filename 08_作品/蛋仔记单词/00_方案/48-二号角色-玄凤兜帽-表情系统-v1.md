## 一、签名特征（角色的“脸纹”）

1. **单边挑眉**：只有一只眼睛上方一道细短深灰棕色毛毡眉，挑起；不是两条、不是人类粗眉。
2. **星形高光**：一只眼睛的高光是四角星形，另一只是圆点高光；不对称。
3. **歪嘴/波浪嘴**：得意＝单边嘴角上扬的歪嘴笑；被抓包＝小波浪线嘴。
4. **帽上小脸**：帽上两颗小圆点眼＋小喙有自己的表情（侧看/瞪大/冠羽翘或耷），常和主脸唱反调——这是“二重脸”特色。

## 二、两套表情

| | 5A 得意/懂王 | 5B 被抓包/心虚 |
|---|---|---|
| 眼睛 | 观众左眼半眯（上眼皮略降），右眼睁大；右眼星形高光 | 两眼睁大，瞳孔看观众左侧（侧眼）；右眼星形高光 |
| 眉毛 | 单眉挑起 | 单眉挑更高 |
| 嘴 | 歪嘴笑：左嘴角上扬、右嘴角平/略下压，微张露一点红舌 | 波浪线嘴：闭口、不露舌 |
| 附加 | 帽上小眼侧看、冠羽翘/歪 | 小汗滴（右太阳穴）、帽上小眼瞪大、冠羽耷拉 |
| 手 | 短圆蛋仔手，正常站姿 | 双手抬到胸前，掌心朝外，“等一下/不是我” |
| 用途 | 抛梗、解释、得意 | 被心易纠正、翻车、心虚 |

## 五、验收

- [ ] 128px 能区分“得意” vs “被抓包”：不是同一张笑脸换色。
- [ ] 单边挑眉成立；不是两条粗眉。
- [ ] 星形高光/圆点高光的不对称成立（能看出更好，不能也不阻断）。
- [ ] 歪嘴笑/波浪嘴成立；无牙、红舌只在 5A。
- [ ] 帽上小脸有表情（侧看/瞪大/冠羽翘或耷）。
- [ ] 手/身体/帽子仍是 4A 蛋仔；不是鸟体/翅膀手。
- [ ] 毛绒、无狗/猫帽、无 M、无文字。
