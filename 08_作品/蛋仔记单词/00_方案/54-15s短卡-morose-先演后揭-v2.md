# 15s 短卡·morose 先演后揭 v2

> 2026-11-04｜状态：**proposed / 未确认**｜用途：按用户反馈“没有惊喜，一开始就说了没肉丝”，把 [53 故事设计](53-15s短卡-morose-心易表演位-故事设计-v1.md) 从“开头报梗”改成**先演后揭**。
> **2026-11-04 后续**：用户进一步要求“解读逻辑，不是翻译逻辑”；因果改为“芽芽误读成清淡→拒肉丝→读对给词”，见 [55 解读位 v3](55-15s短卡-morose-解读位-v3.md)。本文件的“走神摇头”因果作为备选保留。
> 外部依据：[04 市面谐音故事检索](04-市面谐音故事检索-v1.md) 的 E01 morose 31s（期待→缺料→闷闷不乐，词在最后）、C03 四段式（场景→谐音→反转→互动）、A08/A12 邵氏武侠（先演一段，再词卡）。
> 核心不变：心易不说话，只演；芽芽说话，但不替她发言。

## 一、上一版错在哪

- 53 版 0–2 秒芽芽就说“morose——没肉丝”，观众立刻知道梗，后面只是等验证；**没有惊喜**。
- 外部故事型的共同点：**先让观众看懂事件，再给词**。morose 31s 是“期待→只有青椒→闷闷不乐”，词卡在最后；四段式是“场景→谐音→反转”；邵氏是“先演冲突，再上词卡”。
- 所以不是“梗不好”，是**梗的位置错了**：梗应该在结尾当“啊，原来是这个词”，不是开头当“我来解释这个词”。

## 二、新结构：先演后揭

> **心易想要（不报词）→ 芽芽走神/误操作 → 心易发现缺料、郁闷 → 芽芽才报词 → 真义 → 卡。**

- 前 8 秒**不出现“没肉丝”三个字**；连“肉丝”这个词也不说，靠画面里的肉丝小碟和心易指它。
- 芽芽的误操作是**动作**（走神摇头），不是把梗念出来。
- 第 8 秒芽芽才说“morose——没肉丝”；观众把刚才看到的“没肉丝”和这个词对上，惊喜在“音”。
- 词第一次出现时，观众已经看过完整事件；词是标签，不是预告。

## 三、新节拍（15s 目标）

| 时间 | 心易（不说话） | 芽芽（说话） | 画面/因果 | 声音 |
|---|---|---|---|---|
| 0–3s | 指柜台上的肉丝小碟，眼睛亮；**咔啵！** | “这个，谢谢！”（不报菜名、不报词） | 肉丝小碟在柜台；桌上一只**关着的餐盒**＋勺子 | 环境声 |
| 3–5s | 等餐，歪头看芽芽 | 走神、嘴在默念；窗口的手指向肉丝小碟问“要不要？”；芽芽**摇头“不要”**（不是“没肉丝”） | 窗口的手/小碟；芽芽摇头；心易没注意 | 无 vendor 台词；可留一声“嗯？” |
| 5–8s | 接盒、捧盖掀开、盖放桌；夹勺拨两下，只有青椒；耳朵耷下；**咔啵？** | 看到她的脸，5B 被抓包 | 推近盒内；无肉丝；勺碰盒 | 盒盖/勺 |
| 8–11s | 看芽芽，等解释 | **“morose——没肉丝。”**（词第一次出现）→“morose，郁闷的。” | 双人中景；5B 转认真 | 芽芽台词 |
| 11–12s | 低头，**咔……啵……** | 看她 | 近景心易 | 咔啵 |
| 12–15s | — | （卡） | morose／没肉丝 → 郁闷的 | BGM 收 |

- 15s 紧；如果 5–8s 发现拍太赶，放 16–18s，不硬压。
- 芽芽摇头那下要清楚：先看窗口的手/小碟，再摇头；观众要能看见“他把肉丝拒了”。
- 心易全程不知道芽芽摇头；她只是在等、开盒、发现、郁闷。

## 四、惊喜在哪

1. **第一层**：心易明明指了肉丝，饭盒里却没有——为什么？
2. **第二层**：芽芽刚才走神摇头，把肉丝拒了——他为什么走神？
3. **第三层**：第 8 秒他说“morose——没肉丝”，观众才把“他刚才在默念的词”和“饭盒没肉丝”对上——词是最后一块拼图。

不是“先告诉你谐音，再演给你看”，而是“先让你看见怪事，再告诉你它叫什么”。

## 五、心易的表演（无台词）

- **想要**：指肉丝小碟，眼睛亮；“咔啵！”上扬。
- **等待**：双手放桌，歪头看芽芽；不知道窗口发生了什么。
- **发现**：捧盖、掀开、盖放桌、夹勺拨两下；耳朵从立到耷；肩膀垮。
- **疑惑**：“咔啵？”（升调）看芽芽。
- **难过**：“咔……啵……”（低、慢、弱）低头。
- 只两只短手；无多余手臂/手指；勺子细长直柄。

## 六、芽芽的表演（说话位）

- 0–3s：正常点单“这个，谢谢！”；5A 得意但**不报词**。
- 3–5s：走神默念（嘴动、没声）；窗口问“要不要？”时**摇头**；他以为自己在回答别的事。
- 5–8s：看到心易耷拉，5B 被抓包；小汗滴。
- 8–11s：5B 转认真；第一次说出“morose——没肉丝”；再说“morose，郁闷的。”
- 11–12s：看她，收住；不说“别难过”之类的大话。
- 不写“她说……”，不替心易解释内心；他的走神/摇头/报词都是他自己的。

## 七、静音测试

把芽芽全部台词静音，只看画面：

心易指肉丝小碟 → 等 → 窗口的手指小碟 → 芽芽摇头 → 接盒 → 开盒只有青椒 → 拨找 → 耳朵耷 → 看芽芽 → 低头。

**能看懂“她想要肉丝、没吃到、郁闷”，也能看出“芽芽摇头把肉丝拒了”。** 词只是最后给这件事命名。

## 八、备选因果（如果“摇头”不够好笑）

- **B. 芽芽顺手把肉丝吃了/拿走**：他一边走神一边把碟里的肉丝当零食吃掉，饭盒自然没肉丝；心易开盒发现。更直给、更好笑，但“为什么没肉丝”在第一层就揭了，惊喜主要落在词上。
- 推荐先用 **A. 走神摇头**：因果更误会、词和“走神”能扣上；B 作为备选。

## 九、下一步

1. 确认因果：A 走神摇头（推荐）／B 顺手吃掉肉丝。
2. 确认 15s 还是 16–18s；15s 紧就放 16–18s，不硬压。
3. 建 15s 画布：K_A（柜台/肉丝碟/关盒/勺/心易指/芽芽走神）→ V1 0–8s（点单/摇头/开盒/耷拉）→ T_A → V2 8–12s（5B 被抓包→报词→真义/咔啵）→ 卡 12–15s。
4. 跑完做静音测试；不过就改动作，不加旁白。

## 十、验收

- [ ] 前 8 秒没有“没肉丝”，也没有“肉丝”这个词；只有画面里的肉丝小碟。
- [ ] 芽芽的误操作是动作（摇头/吃掉），不是把梗念出来。
- [ ] 第 8 秒词第一次出现时，观众已经把事件看完整。
- [ ] 静音能看懂：想要肉丝→没吃到→郁闷；也能看出芽芽的误操作。
- [ ] 心易全程只咔啵；没有人话/内心独白/代说。
- [ ] 芽芽没有“她说……”；台词≤3 句短句（点单、报词、真义）。
- [ ] 词义准确；卡面拼写/义正确；视频内无字。
