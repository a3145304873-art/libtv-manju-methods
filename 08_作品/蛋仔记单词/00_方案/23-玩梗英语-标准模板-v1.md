# 玩梗英语·标准模板 v1

> **自 2026-11-02 起，所有“玩梗记单词”都按这一套执行。**
> 依据：morose v6 定稿逻辑（旁白解释＋黄蛋反应＋心易结尾咔啵＋单卡尾）。

## 一、一句话标准

**1 个词 / 20s；黄蛋只说反应；旁白讲解释；心易只在结尾“咔啵？”；V1→T_A→V2；最后一张词卡静帧 3s。**

## 二、固定时长

| 段 | 时长 | 内容 |
| --- | --- | --- |
| V1 | 8s | 玩梗钩子/字面误会；黄蛋反应短句 |
| V2 | 9s | 从 T_A 继续；黄蛋问一句；旁白给真义 |
| 尾 | 3s | 单卡静帧；旁白收“你记住了吗？”；不加强行咔啵 |

总 **20s**。不塞第二个词；不临时加长。

### 场景由故事决定

- **不默认小院**；场景要由梗的来源决定。
- morose/没肉丝 → 小饭馆/快餐店（现炒打包）；pest → 草丛/院子；ambition → 擂台/报名处；bail → 车站/门口。
- 场景要提供：角色身份、道具、T_A 桥、视觉差异。
- 先定场景，再定心易 B 故事。
- 详见 [场景选择](25-玩梗场景选择-店里-morose-v1.md)。

## 三、角色分工（硬规则）

- **黄蛋**：只说**反应短句**。例：“青椒肉丝饭！”“怎么没有肉丝？”“肉丝呢？”“真的没有……”“没肉丝……所以我很 morose？”“你记住了吗？”
  - **不许**讲解释、讲词义、讲 like/构词规则。
- **旁白**：讲全部解释。例：“morose，郁闷的。没肉丝，所以郁闷。”
  - 一个声音；后期配音；不写成黄蛋台词。
- **心易**：不说话。只在结尾“咔啵？”（升调）当“记住了吗”。
  - 不在每个词/每句话都咔啵。
- 视频内**无文字、无气泡、无字幕**；词卡是后期静帧。

- **咔啵台词只写拟声**：不要写“（收到）/（心虚）/（等一下）/（补救）/（抱歉）”，动作写在括号外；模型会把括号里的字念出来。

### 心易不是背景板

- 心易至少要有 **2 个主动作/情绪点**，不能只有结尾“咔啵？”。
- 她可以是**起因/闯祸者**：端饭、打包、藏东西、拿错；**不要做补救**，不拿吃的回来解决问题。
- 心虚/躲/探头就是戏；让黄蛋自己郁闷。
- 用 4 种“咔啵”语调演：平、强调、疑问、难过；不说话。
- B 故事模板：① 起因 ② 被发现/想溜 ③ 补救 ④ 收尾。
- 如果复用旧 V1/V2，用 1–3 个 1.5–2s 插入镜头补，不重跑主片段。
- 详细拍法见 [心易 B 故事](24-心易B故事-玩梗-v1.md)。

## 三点五、时长弹性

- 基准 20s：V1 8s＋V2 9s＋卡 3s。
- 如果旁白装不下，**V2 可延长到 13s，总 24s**；先保证旁白完整，不硬压。
- 旁白仍在 V2 视频内生成，不是后期。

## 四、V1→V2 必须 T_A 接尾帧

```
K_A → V1（8s）→ 截 V1 最后一帧 → 替换 T_A → V2（9s，首帧＝T_A）
```

- V1 结尾必须停在**稳定姿势**（如黄蛋趴桌/低头），保持 1s。
- V2 首帧＝T_A；**不换机位、不重摆、不换光**。
- T_A 没替换前，不要跑 V2。
- 这是解决“两个片段割裂”的固定做法。

## 五、形象与眼睛

- 心易：棕色水豚；**R02E 无瞳孔锁眼**：白色圆形眼片，中心没有黑色瞳孔/眼珠/虹膜；外圈一圈深棕色细描边；眼片中心保持空白，没有高光点；眼片形状、外圈深棕线、中心空白全程不变；不眨眼、不眯眼、不抬眼皮、不皱眉；情绪只靠歪头/身体/手势/咔啵。
- 黄蛋：**R01P 毛绒版**：保留黄身/奶油脸/棕眼/天线球/白袜白鞋；短毛绒/毛毡质感；**不限制黄蛋的眼睛**。
- 小院 A02；道具按词换 A05。
- 旧粉蛋/猫耳/光滑塑料黄蛋一律不用。

## 五点三、单词必须出现

- 黄蛋至少说一次单词：如“所以我很 morose？”。
- 旁白讲词义：morose，郁闷的；没肉丝，所以郁闷。
- 尾卡拼写：morose / 没肉丝 → 郁闷的。
- 只出 V1+V2 的 17s 不算成片，必须带旁白/尾卡。

## 五点四、食物道具

- 递出时**关盒**；V1 不打开、不露食物。
- 到桌后才打开；打开才揭示“没肉丝”。
- 餐盒/食物只放**桌面**，不放凳子/椅子；桌面要明确。
- 关盒/开盒可以是两个资产（A05C 关盒，A05 打开后的盒内）。

## 五点五、生成资产保留

- 已生成的 R01P/A05/R02/R02E/KC/T_A 等，后续画布**直接引用**；不要清空 outputs、不要改“待生成”。
- 复用优先用 `input-image` 指向已生成 URL；或保留 `gen-image` 的 done 输出。
- 只有新场景/新道具/新首帧/新视频才新建节点。
- 换版本先复制旧画布，再改 prompt/场景，不覆盖已生成资产。

## 六、单卡尾

- 1 个词 → **1 张卡**（不是三张）。
- 卡面：红色单词＋黑色“谐音 → 词义”。
  - 例：`morose` / `没肉丝 → 郁闷的`
- 米白卡、浅灰边、黑色手写感字、红色关键词；木桌/小院虚化、午后暖光。
- 后期静帧 3s；不生成视频、不贴气泡。
- 多词特辑才用多卡；单词条目默认单卡。

## 七、画布结构（13/21/7）

- R00 比例、R01 黄蛋、R02 水豚、R02E 眼睛；
- R01P 黄蛋毛绒版；
- A02 小院、A05 本条道具；
- K_A 首帧、T_A 尾帧占位；
- V1 8s、V2 9s；
- KC 单卡尾（后期静帧）；
- S0 说明。

跑序：R02/R02E → R01P → A05 → K_A → V1 → 截尾帧替换 T_A → V2（视频内含旁白）→ 后期只加单卡。

## 八、换词模板

只换四样：**词、谐音、A05 道具、V1/V2 台词/旁白**；角色、结构、T_A、单卡尾、锁眼都不动。

例：

- `pest = 拍死它 → 害虫`：A05 小虫；黄蛋“pest？拍死它！”；旁白“pest，害虫。”
- `ambition = 俺必胜 → 野心`：A05 奖杯/擂台；黄蛋“ambition？俺必胜！”；旁白“ambition，野心。”
- `bail = 拜了您嘞 → 保释/离开`：A05 行李箱/门；黄蛋“bail？拜了您嘞！”；旁白“bail，保释/离开。”

### 心易眼睛负向（只写心易的）

```text
心易的黑瞳、心易的眼珠、心易的虹膜、心易的瞳孔、心易的高光点、
心易的眼皮/眼睑/眉毛/眨眼/眯眼/半闭眼/眼神变化/眼睛大特写
```

- 不写泛化的“动漫高光/写实瞳孔”，避免误伤黄蛋。
- 详见 [心易眼睛·无瞳孔锁死](26-心易眼睛-无瞳孔锁死-v1.md)。

## 九、验收清单

- [ ] 1 个词 / 20s（8＋9＋3）。
- [ ] 黄蛋只说反应短句；没有解释/词义。
- [ ] 旁白讲全部解释；不是黄蛋声。
- [ ] 心易不说话；只有结尾“咔啵？”。
- [ ] V1 尾帧替换 T_A；V2 首帧＝T_A；没有换机位/重摆/换光。
- [ ] 心易眼睛按 R02E；黄蛋毛绒版。
- [ ] 视频内无文字/气泡/字幕。
- [ ] 单卡尾：红词＋“谐音→词义”，静帧 3s。
- [ ] 落点回到真实词义；梗只是记忆钩子。

## 十、不要做

- 不要黄蛋讲 like/构词/词义长句；
- 不要心易说人话；
- 不要三卡尾套单词条目（单词用单卡）；
- 不要后期贴气泡/字幕；
- 不要跳过 T_A 直接跑 V2。
