# 二号角色·玄凤鹦鹉 设计 v1

> 2026-11-04｜状态：**proposed / 未确认**｜用途：二号位从“叶鸟”改为**玄凤鹦鹉（cockatiel）**，用大尺度物种特征解决“看不出是哪个动物”；同时保留毛绒蛋形与说话位功能。
> 依据：[43 出图验收·物种可读性](../00_方案/43-二号角色-2A2B-出图验收-v1.md)、[42 v2](42-二号角色-芽芽-设计-v2.md)、[38 候选](38-新角色候选-蛋型动物塑-v1.md)。
> 参考图仍用 [ref-01/02](../04_素材/参考/二号位-风格参考/README.md)，但**只借蛋形/脸板/大眼/短手脚/小靴/毛绒质感**，不借狗/猫帽。暂名“芽芽”，可改“小凤/奇奇”。

## 一、为什么是玄凤鹦鹉

- **物种可读性**：玄凤有四个一眼可读的大特征——**高羽冠、圆腮斑、小钩喙、长尾羽**；比叶芽/叶尾这种植物线索更明确。
- **功能匹配**：玄凤会学舌、吹口哨，天然对应“二号位说话/学词”的设定；比狗/猫更贴“学英语”。
- **和心易区分**：心易暖棕＋橘子＋白片无瞳；玄凤灰/奶油＋黄冠＋蜜桃腮斑＋正常大眼；同框不混。
- **保留蛋仔玩具感**：蛋形身体、大脸板、大眼、短手短脚、小靴、毛绒——参考图的形体语言继续用。

## 二、两种色系

| | 3A 经典灰 | 3B 奶油白面 |
|---|---|---|
| 身体 | 中灰（暖灰，不偏蓝） | 奶油白/米白 |
| 脸板 | 淡黄色 | 奶油白/浅奶油 |
| 羽冠 | 黄色（3–5 根尖羽） | 淡黄色（保留物种线索） |
| 腮斑 | 蜜桃色/珊瑚色圆斑 | 浅蜜桃色圆斑（可更淡） |
| 翼斑/尾羽 | 灰色带白边 | 灰色带白边 |
| 和心易对比 | 灰 vs 暖棕，最清楚 | 奶油 vs 暖棕，较柔和 |

- 3A 最像“玄凤”，优先验证物种可读性。
- 3B 更贴项目现有的奶油/毛绒调，但羽冠/钩喙/长尾必须保留，否则会退回“蛋＋叶子”。

## 三、外形锁

| 部位 | 锁 |
|---|---|
| 整体 | 蛋形身体，头身一体，无脖子，头约占全身一半；13cm 玩具比例；站姿，短手短脚 |
| 材质 | 短毛绒/毛毡，毛茸茸、哑光、纤维可见，边缘有细绒光；不是光滑搪胶/塑料/3D 乙烯基 |
| **羽冠** | **头顶一撮高耸的羽冠：3–5 根尖羽，向后弯；黄色（3A）/淡黄色（3B）；是羽毛冠，不是叶子/植物芽/橘子/天线球** |
| 脸板 | 淡黄色（3A）/奶油白（3B）大圆脸板，占正面大部分；边缘一圈同色细边 |
| 眼睛 | 大圆眼：白眼球＋琥珀棕虹膜＋黑瞳孔＋一个白高光；毛绒玩偶的固定眼片/刺绣眼；可眨眼；**不是心易的白片无瞳**；不是写实眼/光滑塑料反光 |
| **腮斑** | **两侧脸颊各一块圆形蜜桃色/珊瑚色腮斑**；3A 明显，3B 淡一些；不是心易的橘色腮红位置 |
| **喙** | **脸板中央一个小钩喙：灰粉色，喙尖向下弯，像玄凤鹦鹉；喙微张，像在说话；无牙无舌；不是鸭嘴/鸡喙/大鹦鹉喙** |
| 身体 | 灰色（3A）/奶油白（3B）毛绒蛋形身体 |
| 翅膀/手臂 | 两只短圆翅膀手臂，身体同色，带一道**白色翼斑**；末端 2–3 片毛毡羽尖；无手指 |
| **尾** | **身后 3 根长尾羽，灰色带白边/黄边，毛毡；不是叶子尾、不是扇形鸡尾** |
| 腿/鞋 | 两条短腿，白/灰毛毡小靴，靴口同色边；无脚趾 |
| 胸口 | 一枚小叶子徽章（金色/奶油色），作为“芽芽”的小配饰；**不要 M 标志**；不要让它变成主特征 |
| 声音 | 明亮、偏快、清楚；会学舌/吹口哨的感觉；有点“懂王”的得意 |
| 标志道具 | 一根小木指针，尖端一片小叶子；场景道具，不是身体一部分 |

## 六、验收

- [ ] 128px 剪影：**羽冠、钩喙、长尾**至少三项能认；不是“蛋＋叶子”。
- [ ] 羽冠是羽毛冠（3–5 根尖羽），不是叶子/植物芽/橘子/天线球。
- [ ] 腮斑是脸板两侧圆斑；3A 明显，3B 淡；不是心易的橘色腮红。
- [ ] 喙是小钩喙，喙尖向下弯；微张像说话；不是鸭嘴/鸡喙/大鹦鹉喙。
- [ ] 尾是 3 根长尾羽，不是叶子尾/扇形鸡尾。
- [ ] 翅膀手臂有白色翼斑＋2–3 片羽尖；无手指。
- [ ] 毛茸茸短绒/毛毡；不是光滑搪胶/塑料/3D 乙烯基。
- [ ] 无狗/猫帽、无 M 标志、无文字、无第二只角色。
- [ ] 和心易同框：暖棕 vs 灰/奶油；橘子 vs 黄冠；白片无瞳 vs 大眼；能一眼分开。
- [ ] 说话嘴可读：喙微张/有开口线；不是“鼻子”。
