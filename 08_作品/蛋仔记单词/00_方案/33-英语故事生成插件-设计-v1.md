# 英语故事生成插件 · 设计 v1

> 2026-11-03｜状态：**proposed，先定边界再写代码**
> 目标：把“谐音故事”和“词族故事”两套英语故事，做成一个可复用插件；人只选词/选稿，生成、校验、建画布尽量自动化。
> 参考：W11 邵氏英语单词一步成片（15s／6 镜／智能体定义＋单词单变量）；我们只借“单变量＋逐秒表＋智能体”，不借“台词解释单词”。

## 一、先确认“两个故事”指哪两个

本设计默认：

| 类型 | 结构 | 例 |
| --- | --- | --- |
| **谐音故事** | 1 个词／15s／6 镜／12s 画面＋3s 卡 | morose、pest、bail、umbrella |
| **词族故事** | 1 个词根／3 个派生词／23s／3 段＋尾卡 | -like：rocklike／snakelike／doglike |

如果你说的“两个”是别的（比如“蛋仔记单词”＋“心易做菜”），先改这个定义；插件按类型分模式。

## 二、插件形态

推荐：**DSH Skill ＋ 本地 Python CLI ＋ 模板**，不是纯提示词。

```
08_作品/_共享工具/english-story/
├── README.md                 使用说明（两种模式）
├── english_story.py          CLI 入口
├── story.schema.json         故事 JSON 结构
├── prompts/
│   ├── harmonic.md           谐音故事智能体定义
│   └── wordfamily.md         词族故事智能体定义
├── build_harmonic.py         15s 画布 builder
├── build_wordfamily.py       23s 画布 builder
├── validate_story.py         时间/道具/角色/卡面/字幕校验
├── make_card.py              本地生成三行卡（不靠模型写字）
├── stories/                  每个故事的 story.json + SRT
└── out/                       生成的 .monet 与预览
```

- **LLM 只做创意**：出 3 版故事候选；
- **代码做硬约束**：时长、镜数、道具首帧、角色台词、卡面、接线、文件命名；
- **人只做选择**：选词、选稿、点头导入；
- 不把“让模型直接写 .monet JSON”当主路径，容易漂。

## 三、CLI 设计

```powershell
# 1) 谐音：一个词，出 3 版候选
py -3 english_story.py harmonic --word pest --zh "拍死它" --meaning "害虫" --scene "小院" --candidates 3

# 2) 词族：一个词根 + 3 个派生
py -3 english_story.py family --root like --words rocklike,snakelike,doglike --scene "小院"

# 3) 选稿后生成 story.json / SRT / 卡
py -3 english_story.py pack --story stories/pest-15s.json

# 4) 建画布并校验
py -3 english_story.py build --story stories/pest-15s.json
py -3 english_story.py validate --story stories/pest-15s.json

# 5) 导入/同步 Monet（可选，需确认）
py -3 english_story.py import --story stories/pest-15s.json
```

## 四、story.json（核心字段）

```json
{
  "type": "harmonic",
  "word": "pest",
  "ipa": "/pest/",
  "zh": "拍死它",
  "meaning": "害虫",
  "scene": "小院石桌",
  "props": ["苍蝇拍", "水果盘"],
  "duration": 15,
  "shots": [
    {"start": 0, "end": 3, "shot": "中景", "action": "...", "dialogue": "第二十一下——拍死它！"},
    {"start": 3, "end": 5, "shot": "中近景", "action": "...", "dialogue": "我怀疑人生。"}
  ],
  "card": {"word": "pest", "zh": "拍死它", "meaning": "害虫"},
  "subtitles": [{"start": 0.8, "end": 2.0, "text": "第二十一下——"}],
  "score": {"natural": 24, "semantic": 25, "visual": 22, "character": 25}
}
```

- `shots` 必须覆盖 0–12s；卡尾固定 12–15s；
- 词族模式用 `segments`（V1/V2/V3）替代 `shots`，总长 23s；
- `score` 低于 80 不允许 build。

## 五、硬校验（代码，不靠模型自觉）

### 谐音 15s

- 1 个词；15s；6 镜；3＋2＋2＋2＋2＋4；
- 0–12s 画面，12–15s 卡尾；
- 道具 ≤3，第一帧全在；
- 黄蛋说话、心易只“咔啵”；
- 卡尾只三行，**无小字**；
- 视频 prompt 不含字幕/文字；SRT 单独；
- 谐音必须标“义接类型”：对象／后果／作用；只音近不借义的拒绝。

### 词族 23s

- 1 个词根＋3 个派生；
- V1 10s／V2 6s／V3 7s；T_A/T_B；
- 心易锁眼（白片＋棕圈、无瞳孔、不眨眼）；黄蛋正常；
- 3 段尾帧链；结尾三卡或单卡；
- 视频无字；字幕后期。

### 画布层

- 节点/边/组/引用 token 全部走现有 `检查画布接线.py`；
- 卡面文字用 `make_card.py` 本地出 PNG，不靠视频模型写字；
- 导入只新建或同步指定 canvasId，不覆盖现有。

## 六、两种模式的模板

### 谐音 15s

```
K_A（首帧，道具齐） → V1 12s → 卡 3s（后期）
```

- 不需要 T_A/V2；
- 适合单梗。
- 参考 W11 的 6 镜，但卡尾是我们自己的三行卡。

### 词族 23s

```
K_A → V1 10s → T_A → V2 6s → T_B → V3 7s → 尾卡
```

- 复用现有 `build-capybara-tail-*`；
- 适合一词根多派生。

## 七、和 Monet 的关系

- **现在能自动做的**：读画布、拉结果、导入、覆盖同步（`monet_pull.py`／`monet_push.py`／`monet_sync.py`）；
- **还没验证的**：Monet 文本生成节点的输出能否直接喂给视频 prompt；W11 是 LibTV 的智能体节点，不是 Monet；
- 所以 P1 先做 **DSH Skill＋CLI**：LLM 出故事、代码建画布；等 Monet 文本节点验证后，再加“画布内一步成片”模式。

## 八、分阶段

| 阶段 | 产物 | 验收 |
| --- | --- | --- |
| P0 | 本设计、schema、prompts | 用户确认“两个类型/形态” |
| P1 | 谐音 15s 最小闭环：pest 跑通 story→build→validate→卡 | `.monet` 0 ERROR/0 WARNING；story.json 可复现 |
| P2 | 词族 23s：用 -like 跑通 | 3 段/T_A/T_B/尾卡齐 |
| P3 | Monet 导入/同步接入 | 指定 canvasId 回读一致 |
| P4（可选） | 画布内文本生成节点 | 文本输出→视频 prompt 验证通过再上 |
