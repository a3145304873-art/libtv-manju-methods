## 一、设计公式

**蛋型动物塑**：同一个蛋形身体模板，只换表面件（耳/喙/尾/头顶/颜色/眼睛），不换骨架。

| 共享（同一个模具） | 可变（换零件和涂装） |
|---|---|
| 蛋形身体、头身一体、无脖子 | 头顶件：橘子＋两叶 / 卷叶芽 |
| 短圆四肢、无手指脚趾 | 耳/喙：小圆耳 / 小三角喙 |
| 短毛绒/毛毡、哑光 | 尾：小圆尾 / 大叶尾 |
| 纽扣眼工艺 | 眼睛：白片无瞳 / 黑片＋琥珀圈＋高光 |
| 12–14cm 尺度 | 颜色：暖棕＋奶油＋橘 / 雾青绿＋奶油＋琥珀 |
| — | 姿态：低坐 / 前倾站立 |
| — | 声音：咔啵 / 说人话 |

**和心易的对称轴**：果子/叶子；白片眼/黑片眼；静/动；听/说；无尾/大叶尾。

## 二、三版候选

### A. 芽芽｜蛋型叶鸟

> 一只 13cm 的雾青绿毛绒叶鸟，嘴快、爱学舌，负责把词“说出口”。

| 部位 | 锁 |
|---|---|
| 整体 | 圆蛋形身体，头身一体，没有脖子，头约占全身一半 |
| 颜色 | 雾青绿（偏蓝的叶绿，不是草绿）＋奶油白脸板/肚皮＋琥珀橘喙/脚/眼圈 |
| 头顶 | 一株卷叶芽：短茎＋一片卷曲嫩叶，浅叶绿，缝死，本体，不可摘 |
| 尾 | 一片大叶形尾羽，深青绿，中央一道浅色缝线叶脉；不是扇形羽毛 |
| 翅 | 两只短圆翅套，像连指手套，无手指，翅内侧奶油白 |
| 脚 | 两只琥珀橘短圆脚，无鞋无袜 |
| 眼睛 | 黑色圆形眼片＋琥珀色细圈＋一个白色小高光；可眨、可眯、可惊讶 |
| 嘴 | 小三角毛毡喙，琥珀橘色，会开合；无牙无舌 |
| 材质 | 短毛绒/毛毡，哑光、纤维可见；喙和脚也是毛毡 |

## 三、通用出图规则

- 一次只出一只，不要把三版放进同一张图；也不要让心易入镜，避免眼睛规则混线。
- 主设定图先出「正面偏 3/4 全身」；三视图等选定后再出，避免一次多视图导致形体漂移。
- 眼睛特写可选，用来确认「黑片＋琥珀圈＋白高光」是否稳定；不要把心易的「白片无瞳」负向套到新角色身上。
- 纯白底、无地面阴影、无场景、无道具；不要把角色放进小院或饭馆。
- 出图后先看六点：剪影、眼睛、蛋型、材质、和心易的色差、道具潜力。

### 眼睛特写 prompt（可选，把 `<名字>` 和括号内容换掉）

```text
16:9 纯白底眼部特写，只生成一只<名字>的一对眼睛，不生成整只角色：
黑色圆形眼片，外圈一圈琥珀色细描边，眼片上缘一个白色小高光；
眼片是毛绒玩偶的固定纽扣/刺绣件，边缘有细绒，不是写实动物眼、不是人眼、不是卡通大眼；
眼睛周围是<奶油白脸板/深色眼罩>；<角色头顶的叶芽/耳朵>在画面上边缘露出一小部分；
短毛绒/毛毡质感，哑光；纯白背景，无文字。
```

**负向**

```text
人眼、写实鸟眼、眼白、虹膜、睫毛、眉毛、瞳孔反光过多、第二只角色、心易、文字、字幕、logo、水印、塑料高光、过曝
```

### 出图后检查

- [ ] 缩小到 128px，剪影还能认出是谁吗？
- [ ] 眼睛是黑片＋琥珀圈＋一个白高光，不是写实眼/人眼/卡通大眼？
- [ ] 有没有偷偷长出脖子、长腿、手指、写实羽毛？
- [ ] 材质和心易一样是短毛绒/毛毡，不是搪胶/塑料？
- [ ] 和心易同框时，暖棕 vs 雾青绿/雾蓝灰/沙色，哪版对比最好？
- [ ] 谁的头饰不会和心易的橘子打架？
- [ ] 道具潜力：A 的翅套能夹住小道具吗？B 的手能拿饭盒吗？C 的站姿能够到高处吗？
