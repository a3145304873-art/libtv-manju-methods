# 15s 短卡·morose 样片 v1（心易表演位／二号位抛梗）

> 2026-11-04｜状态：**proposed / 未拍**｜格式依据：[40 邪修赛道对照](40-邪修英语赛道对照与格式选择-v1.md)；角色依据：[心易规范](../../_共享角色/心易/README.md)、[黄蛋规范](../../_共享角色/黄蛋/README.md)。
> 本文件只写样片脚本与拍摄约束，不建画布、不导入、不生成。cast 未定；样片可用黄蛋毛绒版占位二号位，台词按“二号位”写，换角不改节拍。

## 一、这条样片验证什么

1. **15s 内能否看懂**：二号位抛梗 → 心易字面演 → 二号位给真义 → 卡。
2. **心易能否只靠动作演清“没肉丝”**，不靠台词、不靠旁白。
3. **二号位是否像角色**，不像“站进画面的旁白”。
4. **词是否落地**：观众先看到“没肉丝”，再听到 morose，最后卡面给拼写/义。

不验证：长故事、连续剧、多词复习、cast 终选。

## 二、角色分工（硬规则）

- **心易**：当事人／表演位。想要青椒肉丝饭；打开盒只有青椒；耳朵耷下。全程只发“咔啵”，只发“咔……啵……”（难过）。不说人话、不内心独白、不让人代说。
- **二号位**：抛梗解说位。爱拽英文、一本正经；负责说词＋谐音、给真义。**不是旁白**，在画面里；不转述心易的话（不写“她说……”）。
- **旁白**：取消。二号位替代。
- **黄蛋（如用）**：可说话、可眨眼、可做表情；不套心易锁眼；不替心易说“咔啵”、不说“心易问……”。

## 三、15s 时间轴

| 时间 | 画面 | 动作 | 声音 |
|---|---|---|---|
| 0–2s | 中景，小饭馆桌边；心易左，二号位右；桌上一个**关着的**餐盒＋一把勺子 | 二号位指餐盒，抛梗；心易伸手去拿 | 二号位：“morose——没肉丝。” |
| 2–4s | 同机位，缓慢推近 | 心易打开盒盖，**把盖放到桌面**；盒内只有青椒 | 盒盖轻响；环境声 |
| 4–6s | 推近到盒内 | 心易用勺子拨两下，确实没有肉丝；放下勺子 | 勺子碰盒 |
| 6–7s | 中近景 | 心易停住；耳朵耷下、身体垮下；定格 1s | 环境声收 |
| 7–11s | 中景，二号位靠近 | 二号位一本正经给真义；心易歪头看他 | 二号位：“没肉丝，所以郁闷——morose，郁闷的。” |
| 11–12s | 近景，心易 | 耳朵耷下，低头 | 心易：“咔……啵……” |
| 12–15s | 卡（后期静帧） | morose／没肉丝 → 郁闷的 | BGM 收；无视频内文字 |

- 视频段 0–12s；卡 12–15s（后期静帧，不是视频）。
- V1＝0–7s；V2＝7–12s，首帧＝V1 最后一帧（T_A）。
- V1 结尾必须停在稳定姿势 1s；不换机位、不重摆、不换光。

## 四、道具与首帧

| 项 | 要求 |
|---|---|
| 餐盒 | 只一个；**首帧关着**；放在桌面，不放凳子/椅子；打开后盖放桌面 |
| 盒内 | 只有青椒，**没有肉丝**；不出现第二盒、不加肉 |
| 勺子 | 首帧就在桌面；心易用**两只短手**拿；用完放下 |
| 桌面 | 明确、干净；不出现外卖袋、筷子堆等干扰物 |
| 心易手 | 只有两只短手；不出现多余手臂、第三只手、多双手 |
| 二号位 | 首帧在桌边；不 walking around；V2 只前倾，不换位 |

## 六、V1 prompt（0–7s）

```text
9:16 竖屏，小饭馆桌边中景，暖光；从 K_A 开始，机位不变，缓慢推近桌面。
0–2s：二号位指向餐盒，开口说话（说“morose——没肉丝”）；心易两只短手伸向餐盒。
2–4s：心易用两只短手捧住盒盖，掀开，把盖平放到桌面；盒内只有青椒，没有肉丝。
4–6s：心易用两只短手夹住勺子，拨两下青椒，确实没有肉丝；把勺子放回桌面。
6–7s：心易停住，耳朵和肩膀耷下，保持稳定 1s。
只表现以上动作；不换机位、不重摆、不换光；无文字、无字幕；心易不说话，只做动作。
```

## 七、V2 prompt（7–12s，首帧＝T_A）

```text
9:16 竖屏，小饭馆桌边中景，暖光；首帧＝V1 最后一帧（心易耷拉、盒盖打开、勺子在桌面）。
7–11s：二号位向心易前倾，一本正经地说“没肉丝，所以郁闷——morose，郁闷的。”心易转头看他。
11–12s：心易耳朵耷下、低头，只发“咔……啵……”（难过）；不说话、不加词。
机位、光线、桌面位置与 V1 一致；无文字、无字幕；不换人、不加道具。
```

## 八、声音

- 二号位：现场声/TTS 均可；语速正常，抛梗句干脆，真义句放慢。
- 心易：只“咔……啵……”（低、慢、弱）；后期贴更稳；视频模型若给心易加人话，改静音＋后期。
- 旁白：无。
- BGM：-18～-22dB；不盖二号位与咔啵。
- 环境声：盒盖、勺子轻响；不盖人声。

## 九、词义与卡面

- 词：**morose** /məˈroʊs/，形容词；本集义项：**郁闷的、闷闷不乐的**（bad-tempered and unwilling to speak）。
- 谐音“没肉丝”只是**记忆钩子**，不是词源、不是标准发音；卡面必须给真义。
- 卡面：`morose`（红色关键词）／`没肉丝 → 郁闷的`（黑色手写感）；米白卡、浅灰边；不贴气泡。
- 卡是后期静帧 3s，不生成视频、不贴视频内文字。
