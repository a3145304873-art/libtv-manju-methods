# 二号角色·玄凤兜帽蛋仔 设计 v1

> 2026-11-04｜状态：**proposed / 未确认**｜用途：按用户反馈“3A/3B 太丑、要更像蛋仔的手”，把二号位改成**蛋仔身体＋玄凤连帽**，不再做鸟体。
> 依据：[45 3A/3B 验收与用户反馈](45-二号角色-玄凤3A3B-出图验收-v1.md)、[44 玄凤设计](44-二号角色-玄凤鹦鹉-设计-v1.md)、[参考图](../04_素材/参考/二号位-风格参考/README.md)。
> 暂名“芽芽”，可改“小凤/奇奇”。

## 一、为什么改成兜帽

- 3A/3B 把蛋仔语言换掉了：翅膀手、鸟喙当嘴、尖羽冠、淡脸板；用户反馈“太丑”，并明确要**原来更像蛋仔的短圆手**。
- 保留蛋仔的可爱资产：**蛋形身体、大脸板、大圆眼、张嘴笑、短圆手臂＋白色手套/肉垫、白靴、毛绒**。
- 玄凤只做**连帽**：高羽冠、蜜桃腮斑、小钩喙（装饰）；像参考图里狗帽/猫帽的语言，但帽子是玄凤。
- 说话仍用**脸板的嘴**（张嘴笑、红舌无牙）；帽上的小钩喙闭合、装饰，不用于说话。这样不会出现“两张嘴”。

## 二、外形锁

| 部位 | 锁 |
|---|---|
| 整体 | 蛋形身体，头身一体，无脖子，头约占全身一半；13cm 玩具比例；站姿 |
| 材质 | 短毛绒/毛毡，毛茸茸、哑光、纤维可见，边缘有细绒光；不是光滑搪胶/塑料/3D 乙烯基 |
| 身体 | 奶油白/米白蛋形毛绒身体（像参考图的蛋仔身体） |
| 脸板 | 奶油色大圆脸板，占正面大部分；边缘一圈浅色细边 |
| 眼睛 | 大圆眼：白眼球＋琥珀棕虹膜＋黑瞳孔＋一个白高光；毛绒玩偶的固定眼片/刺绣眼；可眨眼；不是心易的白片无瞳 |
| 嘴 | **张嘴笑，红色舌头，无牙；说话用脸板的嘴**；不是鸟喙当嘴 |
| 连帽 | 玄凤鹦鹉连帽衫，覆盖头顶和后脑；帽顶高羽冠（3–5 根尖羽，向后弯）；帽前额小钩喙（灰粉色，闭合、装饰，不用于说话）；帽两侧蜜桃色圆腮斑；帽前额两只小圆点眼睛（装饰） |
| **手** | **两只短圆蛋仔手臂，奶油白；上臂一块同色/蜜桃色小肉垫，末端白色手套/肉垫；无手指；不是翅膀、不是羽毛、不要扇贝边** |
| 腿/鞋 | 两条短腿，白色毛绒小靴，靴口同色/暖灰边；无脚趾 |
| 胸口 | 一枚小叶子徽章（金色/奶油色），不要 M 标志 |
| 声音 | 明亮、偏快、清楚；会学舌/吹口哨的感觉；有点“懂王”的得意 |
| 标志道具 | 一根小木指针，尖端一片小叶子；场景道具，不是身体一部分 |

## 三、两个色系

| | 4A 经典灰兜帽 | 4B 暖杏色兜帽 |
|---|---|---|
| 身体 | 奶油白/米白 | 奶油白/米白 |
| 连帽 | 暖灰（不偏蓝） | 暖杏/浅驼（cinnamon 感） |
| 羽冠 | 黄色 | 黄色 |
| 腮斑 | 蜜桃色 | 蜜桃色 |
| 钩喙 | 灰粉色 | 灰粉色 |
| 手套/肉垫 | 白手套＋暖灰/蜜桃小肉垫 | 白手套＋暖杏/蜜桃小肉垫 |
| 靴边 | 暖灰 | 暖杏 |
| 和心易 | 暖棕 vs 奶油/灰，最清楚 | 暖棕 vs 奶油/杏，较柔和 |

## 六、验收

- [ ] **手是蛋仔手**：短圆、无手指、白色手套/肉垫、上臂小肉垫；不是翅膀/羽毛/扇贝边。
- [ ] 身体是蛋仔蛋形，不是鸟体；无鸟翅/鸟尾。
- [ ] 脸是蛋仔脸：大脸板、大眼、张嘴笑红舌无牙；说话用这张嘴。
- [ ] 连帽是玄凤：高羽冠、腮斑、小钩喙；帽上小喙闭合装饰，不抢说话嘴。
- [ ] 128px：先看手和身体像不像蛋仔，再看帽子像不像玄凤。
- [ ] 毛茸茸短绒/毛毡；不是光滑搪胶/塑料/3D 乙烯基。
- [ ] 无狗/猫帽、M 标志、文字、第二只角色。
- [ ] 和心易同框：暖棕 vs 奶油/灰或杏；橘子 vs 黄冠；白片无瞳 vs 大眼；能一眼分开。
