# 锁眼硬约束 v1

> 2026-11-02 用户反馈：23s 版仍有眼神变化（眼皮/瞳孔/眯眼）。
> 本版在 23s 尾帧链画布上加了**眼睛硬约束**：
> 画布：`02_画布/EP02-like-capybara-tail-v3-eyelock.monet`（17 节点 / 25 边 / 7 组；0 ERROR / 0 WARNING）

## 一、硬约束怎么写

每段 K/V prompt 都加：

```text
【眼睛硬约束】心易是毛绒玩具，眼睛是固定塑料/刺绣件，不是生物眼：
白色圆形眼白、黑色小圆瞳、单个高光；
眼白形状、瞳孔大小/位置、开合度全程完全不变；
不眨眼、不眯眼、不抬眼皮、不皱眉、不转瞳孔、不放大缩小、不出现泪光；
情绪只靠歪头/身体/手势/咔啵。
镜头以中景/中近景为主，不要眼睛大特写。
```

负向加：

```text
眼皮、眼睑、眉毛、眨眼、眯眼、半闭眼、瞳孔放大/缩小、瞳孔移动、
眼神变化、眼球转动、泪光、睫毛、眼影、虹膜变色、眼睛变形、
卡通大眼、拟人化眼神、眼睛大特写
```

## 二、为什么之前会变

- 模型把“眼睛”当成表演工具：惊讶就放大瞳孔，难过就垂眼皮，思考就转眼珠；
- 只写“眼睛按参考图”不够，模型仍会为了情绪改眼睛；
- 10s 长镜头、正脸/大特写更容易漂。

所以这次不是“参考一下”，而是：
1. **定义成固定玩偶眼**（塑料/刺绣件，不会动）；
2. **明确禁止眨眼/眼皮/瞳孔变化**；
3. **限制镜头**：中景/中近景，不要眼睛大特写；
4. **情绪转到身体**：歪头、点头、抬手、耷拉、咔啵。

## 三、还能再加的硬手段

### A. 先跑 3s 测试

- 不要直接跑 10s；先跑 V1 的前 3s（或整段 10s 后只看前 3s）；
- 看眼睛是否从第一帧到第三秒都没变；
- 变了就重跑/换 seed，不要硬剪。

### B. 拆短

- 10s V1 仍然偏长；如果 10s 里眼睛还是漂：
  - 拆成 **开头 5s + rock 5s** 两段；每段眼睛更稳；
  - 代价：多一个接缝，可用尾帧链接。
- V2 6s、V3 7s 相对短，问题通常小于 V1。

### C. 后期锁眼（兜底）

- 用 R02F 的眼睛区域做贴片，跟踪每帧眼睛位置后覆盖；
- 能做，但 3D 转头时贴片容易抖/穿帮；优先还是生成时锁住；
- 如果生成怎么都漂，我可以再写一个跟踪贴眼脚本，先小范围试。

### D. 镜头避让

- 不要正脸大特写；用侧 45°/中景；
- 眼睛在画面里越小，变化越不明显；
- 但这不是“锁住”，只是“看不清”；优先 A/B。
