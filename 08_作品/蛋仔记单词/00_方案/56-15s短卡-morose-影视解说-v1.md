> **2026-11-04 后续**：用户反馈“只有关键的时候说”更好；连续解说改为关键句版，见 [57 关键句](57-15s短卡-morose-关键句-v1.md)。本文件保留作“解说腔”备选。
> 依据：[55 解读位 v3](55-15s短卡-morose-解读位-v3.md)（备选）、[54 先演后揭](54-15s短卡-morose-先演后揭-v2.md)、[52 无星表情](52-二号角色-表情无星v2-验收-v1.md)、[35 无厘头结构](35-无厘头小插曲结构-v1.md)。
> 核心不变：心易不说话，只演；芽芽说话，但不替她发言。

## 一、芽芽是什么位：现场影视解说员

- 不是翻译：心易没有说话，翻译什么？
- 不是侦探/误读：那会变成“他猜错→纠正”的剧情，重心跑到芽芽身上。
- **是影视解说员**：心易演，他在旁边把这场小事当电影解说；最后一句把词说出来。
- 他解说**画面里发生的事**，不转述心易的内心；不说“她说……”，只说“我们看到／然而／没有肉丝，失落的”。
- 喜剧来源：**大片解说腔 × 一顿午饭的小事**。越郑重，越好笑；心易越淡定，越反差。

## 二、解说的三句话

1. **开场**：“心易今天想吃点好的。”（不报菜名、不报词）
2. **转折**：“然而，饭盒里最重要的东西不见了。”（观众已经看到空位）
3. **落点**：“没有肉丝，失落的——morose 就是失落的。”（词第一次出现）

> 注意拼写：**morose**，不是 morse。中文落点用“失落的／郁闷的”；卡面给准确拼写和义。

## 三、15s 节拍

| 时间 | 心易（不说话） | 芽芽（影视解说） | 画面/声音 |
|---|---|---|---|
| 0–2s | 指柜台上的肉丝小碟，眼睛亮；**咔啵！** | “心易今天想吃点好的。” | 肉丝小碟、关盒、勺；环境声 |
| 2–5s | 接盒、捧盖掀开、盖放桌；夹勺拨两下，只有青椒；耳朵耷下；**咔啵？** | “然而，饭盒里最重要的东西不见了。” | 推近盒内空位；盒盖/勺 |
| 5–9s | 低头、肩膀垮下 | **“没有肉丝，失落的——morose 就是失落的。”** | 双人中景；芽芽 5A→认真 |
| 9–10s | 抬头看芽芽（你怎么在解说我） | 5B 被抓包（小汗滴） | 近景；好笑的一拍 |
| 10–11s | **咔……啵……** | 看她 | 近景心易 |
| 11–12s | — | “你记住了吗？” | 芽芽看镜头 |
| 12–15s | — | （卡） | morose／没肉丝 → 失落的 |

- 前 5 秒不出现“没肉丝”，也不出现“肉丝”；只有画面里的肉丝小碟和“最重要的东西不见了”。
- 5–9s 是词第一次出现；观众已经把“她想要→盒子空了→她失落”看完。
- 9–10s 的“心易看他”是可选一拍：她抓到他拿自己的倒霉做解说；芽芽 5B 心虚。15s 紧可删；保留则角色更好笑。

## 四、惊喜在哪

1. 她指了肉丝，芽芽却说“想吃点好的”——观众不知道具体是什么。
2. 盒子打开，最重要的东西不见了——观众看到空位，知道出事了。
3. 芽芽才说“没有肉丝，失落的——morose 就是失落的”——词是最后一块拼图。

不是“先报谐音再演”，是“先演完，再解说”。词是解说员的结论，不是预告。

## 五、心易的表演（无台词）

- **想要**：指肉丝小碟，眼睛亮；“咔啵！”上扬。
- **发现**：捧盖、掀开、盖放桌、夹勺拨两下；耳朵从立到耷；肩膀垮。
- **疑惑**：“咔啵？”（升调）。
- **被抓拍**：抬头看芽芽（他发现你在解说我？）。
- **难过**：“咔……啵……”（低、慢、弱）低头。
- 只两只短手；无多余手臂/手指；勺子细长直柄。

## 六、芽芽的表演（解说位）

- 0–2s：5A 得意/懂王；像电影解说开场，郑重其事。
- 2–5s：“然而”一转，语气压低；不抢心易的发现。
- 5–9s：认真给词；不嬉皮笑脸；词是结论。
- 9–10s：被心易看，5B 被抓包；小汗滴；一秒收。
- 11–12s：“你记住了吗？”看镜头；收尾。
- 不写“她说……”，不替心易解释内心；解说只描述画面和感受。

## 七、静音测试

把芽芽全部台词静音，只看画面：

心易指肉丝小碟 → 接盒 → 开盒只有青椒 → 拨找 → 耳朵耷 → 看芽芽 → 低头。

**能看懂“她想要、没吃到、失落”。** 芽芽的解说只是把这件事叫 morose；静音也成立。

## 八、和“解读位/误读”的区别

| | 解读位/误读 v3 | 影视解说 v1（本文件） |
|---|---|---|
| 芽芽在做什么 | 读她的行为，可能读错，造成后果 | 在旁边解说这场小事，最后给词 |
| 重心 | 芽芽的误读/纠正 | 心易的表演＋解说的反差 |
| 喜剧 | 误读翻车 | 大片解说腔 × 一顿午饭 |
| 15s 难度 | 较高（误读/后果/纠正三拍） | 较低（演完→解说三句） |
| 适合 | 想要角色冲突 | **想要“心易表演位＋芽芽特色”** |

- 解读位保留作备选（[55](55-15s短卡-morose-解读位-v3.md)）；影视解说作为当前主方向。
- 纯邪修词卡是另一条线；影视解说是故事/角色型，市场依据是影视解说/动物解说这类“解说腔”品类，不是纯词卡。

## 十、验收

- [ ] 芽芽是解说员：说画面/感受，不说“她说”，不代心易发言。
- [ ] 前 5 秒没有“没肉丝”，也没有“肉丝”；只有画面里的肉丝小碟。
- [ ] 5–9s 词第一次出现；观众已经把事件看完整。
- [ ] 9–10s 的“心易看他/5B”可选；保留则角色更好笑。
- [ ] 静音能看懂：想要→没吃到→失落。
- [ ] 心易全程只咔啵；没有人话/内心独白/代说。
- [ ] 芽芽台词≤3 句短句（开场/转折/落点）＋可选“记住了吗”。
- [ ] 词义准确；morose 拼写正确；卡面给拼写/义；视频内无字。
