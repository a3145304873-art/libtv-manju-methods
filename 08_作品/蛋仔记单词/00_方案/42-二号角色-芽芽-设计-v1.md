## 一、选型：为什么是 A 芽芽

| 候选 | 说话可读性 | 与心易对比 | 功能匹配 | 判断 |
|---|---|---|---|---|
| **芽芽（叶鸟）** | 三角喙开合，最像说话 | 雾青绿 vs 暖棕；黑纽扣眼 vs 白片无瞳；叶芽/叶尾 vs 橘子 | 爱学舌、把词说出口，直接对应抛梗解说 | **选 A** |
| 阿栗（松鼠） | 小圆嘴，说话不明显 | 雾蓝灰 vs 暖棕；大叶尾 | 囤词，适合“词库”型，不适合抛梗 | 备选 |
| 哨哨（狐獴） | 小圆嘴，说话不明显 | 沙色 vs 暖棕；眼罩 | “先发现先误会”适合故事解读位 | 故事备选 |

- 15s 短卡最重要的是“谁在说话”一眼看清；喙开合比小圆嘴更清楚。
- “学舌”是语言学习的天然隐喻：他重复词，观众跟着记。
- 冷绿 vs 暖棕、黑纽扣眼 vs 白片无瞳，两个角色同框不混。
- 如果以后做 20–30s 故事，芽芽也能当“解读位”：他读错、心易纠正、他再读对；同一个角色，两种用法。

## 二、一句话

一只 13cm 的雾青绿毛绒叶鸟，嘴快、爱学舌、爱拽英文；心易不说话，他负责把词说出口——常常说得太自信。

## 三、外形锁

| 部位 | 锁 |
|---|---|
| 整体 | 圆蛋形身体，头身一体，没有脖子，头约占全身一半；13cm |
| 颜色 | 雾青绿（偏蓝的叶绿，不是草绿）＋奶油白脸板/肚皮＋琥珀橘喙/脚/眼圈 |
| 头顶 | 一株卷叶芽：短茎＋一片卷曲嫩叶，浅叶绿，缝死，本体，不可摘；不是花、不是帽子、不是橘子 |
| 眼睛 | 黑色圆形眼片＋一圈琥珀色细描边＋一个白色小高光；可眨、可眯、可惊讶；**不是心易的白片无瞳** |
| 嘴 | 小三角毛毡喙，琥珀橘色，可开合说话；无牙、无舌、不出现口腔内部 |
| 翅 | 两只短圆翅套，像连指手套，无手指；翅内侧奶油白；能夹住小指针 |
| 尾 | 一片大叶形尾羽，深青绿，中央一道浅色缝线叶脉；不是扇形羽毛、不是松鼠尾 |
| 脚 | 两只琥珀橘短圆脚，无鞋无袜；腿很短 |
| 材质 | 短毛绒/毛毡，哑光、纤维可见；不是搪胶、不是塑料、不是写实鸟 |
| 声音 | 明亮、偏快、清楚；有点“懂王”的得意；说英文词清楚 |
| 标志道具 | 一根小木指针，尖端一片小叶子；场景道具，不是身体一部分 |

## 四、与心易的对比

| | 心易 | 芽芽 |
|---|---|---|
| 毛色 | 暖棕＋奶油 | 雾青绿＋奶油 |
| 头顶 | 橘子＋两片绿叶 | 卷叶芽 |
| 眼睛 | 白片＋深棕细圈，**无瞳孔、不眨眼** | 黑片＋琥珀细圈＋白高光，**正常眼、可眨眼** |
| 嘴 | 一字嘴，不为说话开合 | 三角喙，开合说话 |
| 尾 | 小圆尾 | 大叶尾 |
| 功能 | 表演位：有愿望、用动作演 | 说话位：抛梗、解释、读错/读对 |
| 声音 | 只“咔啵” | 说人话、说英文词 |

## 五、性格与功能

### 短卡（抛梗解说位）

- 说词＋谐音，一本正经；最后给真义。
- 语速快、爱用“这个词我熟”“翻译过来就是——”；自信到有点欠。
- 心易演的时候，他在旁边看；演完他收词。

### 故事（解读位）

- 把心易的行为读错，照错的做，出小后果；心易用行动纠正；他再读对，给词。
- 缺点：爱面子，被纠正时僵住/眨眼；下次还犯。不是恶毒、不是反派。
- 对心易：忠诚，替她说话；但常替她说过头。心易一个眼神/动作就能让他闭嘴。

## 六、关系与表演

- **一个不说，一个爱说**：心易演，芽芽解说。
- 芽芽说话时看心易/镜头；心易只咔啵；两人不同时说。
- 芽芽的喙只在他说话时开合；心易的嘴只为一字嘴/咔啵，不做说话口型。
- 同框时两人同高（13cm）；芽芽不要高瘦人形、不要长腿。
- 芽芽可以说完整句子；心易不能；芽芽不替心易说“咔啵”、不说“心易问……”。

## 七、声音（先定方向，不锁声线）

- 明亮、偏快、清楚；少年感/机灵，不低音、不油腻。
- 中文解释正常语速；英文词咬清楚，不夸张卷舌。
- 可以有一点“学舌”的重复感：同一句尾音重复一次，但不结巴。
- TTS/配音后定；先不锁具体音色。

## 八、标志道具

- 一根小木指针，尖端一片小叶子；只在场景里用，不是身体一部分。
- 用途：指餐盒/词卡/道具；短卡里可指一下，不遮挡脸。
- 可选：小本子（不写字）；不要眼镜（遮眼，且和黑片眼冲突）。
