## 1 从截图能确认什么

| 项 | 能确认 | 不能确认（待你补） |
|---|---|---|
| 人物 | 白发、白袍 + 黑腰封、护腕、冰霜气劲绕双臂 | 角色名、门派、身高体态设定、是否有第二武器 |
| 武器 | **剑**，外观「藏音·龙跃霄汉」；属性：颜色**冰泉**、剑刃**擎冰**、剑颚**炼虹**、剑柄**擎冰**、明光**曜日** | 剑长、是否有剑鞘、蓄力/大招时的特效形态 |
| 画面 | 游戏内实拍感，色调偏写实；水面/码头木桩/远山 | 你要的是 16:9 投放还是 9:16 竖版 |

**关键发现**：这套武器自带一组**冷暖对冲**——剑身是冰泉冷色，明光却是"曜日"暖光，剑颚是"炼虹"（虹彩过渡）。这就是三条片子的配色依据，**不需要再引入红色**（红眼那种与人设冲突的做法直接放弃）。

## 2 三帧的关系：人 → 眼 → 剑

不是三条互不相干的片子，是一个**递进系列**：先给"人站在那儿"（全身），再逼到"他在看什么"（眼），最后落到"他手里是什么"（剑）。三条各自成立，三连发就是一次完整的人物亮相。

| | ① 雪落无声 | ② 一线 | ③ 龙跃 |
|---|---|---|---|
| 景别 | 全身立势 · 35mm | 刃口与眼 · 85mm | 剑身与手 · 50mm 微距 |
| 画面主体 | 人（剪影）+ 雪地留白 | 一只眼 + 一道刃光 | 剑身 + 握住的手 |
| 情绪 | 静、压、不肯让 | 逼、冷、盯住 | 亮、锐、一触即发 |
| 强调色 | 曜金（剑尖一点） | 曜金（刃口一线） | 炼虹（护手一道）+ 曜日（剑尖） |
| 冲击点 | 剑尖触地，冰霜炸开 8 帧 | 反光沿刃口扫过 6 帧 | 碎冰沿剑身炸开 10 帧 |
| 一句话 | 他站在雪里，剑垂着 | 他抬眼，刃压在下半幅 | 剑先亮，人才到 |

## 4 提示词

### 4.1 图（先出定格，三张都按同一套风格锁写）

**① 全身立势**
```
写实国风，单帧定格。白发剑客立于雪原，白袍黑腰封，双臂有冰霜气劲；人整体压成暗块，
只有白发边缘、肩线与剑刃吃一道逆光。右手垂剑，剑尖指地，剑身是冰泉般的冷白，护手有一道极淡的虹彩。
左侧三分之一是空白雪地，立着四五根旧木桩；远山只用一道灰。构图：人物在右三分，脚在画面下缘，
主斜线从剑尖到左上留白，约 30°。高反差，冷灰为主，全片只有剑尖一点暖光。
禁止：红、彩色渐变、发光眼、多手多剑、文字与水印。
```

**② 刃口与眼**
```
写实国风，极特写静帧。画面下半幅被一道剑刃斜切，刃口是一线冷白高光，刃身上有极淡的冰纹；
上半幅只露一只眼和半张脸，眼睛在右三分，睫毛清晰，瞳孔里有一点冷白神光与一点暖金光。
脸在暗部，只有眼窝受光；颊侧有 3–5 点干涸的墨/尘。
构图：刃线约 −18°，眼在黄金分割右上方。黑白灰 + 一点暖金。禁止：彩色、发光眼、卡通描边、文字。
```

**③ 剑身与手**
```
写实国风，微距静帧。一把冰晶长剑从右下斜贯到左上出画，剑身半透，内部有龙形的霜纹走势；
护手是一道极细的虹彩（青到品红过渡），剑颚处结着霜；右下角是一只握柄的手（只见手背与两指），
白袍袖口被裁掉一半。黑底，剑身自发光：冷光为主，剑尖 1/10 处转暖金。
构图：剑轴 −52°，剑身占满对角线；霜粒 10–20 点悬浮。
禁止：彩色背景、塑料感、卡通描边、文字与水印。
```

### 4.2 视频（seedance-2.0-mini，4s 一条，剪头成 3s）

模型最短 4s，所以三条都按 4s 写；头部 1s 是静帧蓄势，剪掉不影响尾部水墨定格。
完整版提示词（带引用 token、首帧锁定、负向）在画布节点里，这里给不带 token 的读法：

**①** `4 秒，30fps，16:9。雪原静帧：人物不动，只有白发与衣袂被右后方的风推着轻摆，雪粒横飞。
1.4–1.6 秒剑尖触地，霜从触点向外爬开并炸起一圈雪雾；1.6–1.7 秒炸白 1–2 帧；
之后整幅转成黑白水墨定格，只有墨点飘落。固定机位，1.02 倍极缓推。禁止：人物走动、镜头摇晃、色彩变化、自动加字。`

**②** `4 秒，30fps，16:9。极特写静帧：刃口一线高光，眼不动；0.8–1.1 秒眨一次眼（约 3 帧）；
1.1–1.5 秒一道暖金反光沿刃口从右向左扫过（刃身不动）；1.5–1.7 秒炸白；
之后整幅转水墨，眼与刃口位置不变。固定机位，禁止推拉摇移、禁止加字。`

**③** `4 秒，30fps，16:9。微距静帧：冰晶剑身自发光，内部霜纹极缓流动；1.0–1.2 秒手腕轻转，
剑身冰晶亮一下；1.2–1.7 秒碎冰沿剑身向两端炸开；1.7–1.8 秒炸白；之后整幅转水墨。固定机位，禁止走位、禁止加字。`

> 共同纪律：**白闪、闪切、渐暗、文字、循环点，全部在剪辑里做**——模型做不出 1 帧的闪。

和上面 §3 的帧表有一处**必须知道的差别**：画布让视频自己在尾部转成水墨（尾声「炸白→水墨定格」由 seedance 直出），
所以 §3 里那些精确到帧的切点，落到画布后是「近似执行」；真正的 1 帧白闪留在剪辑补。
这不是能力不足，是取舍：把白闪和入墨挪到后期做两段拼接，仓库里试过——被评"完全不流畅"，才改回生成内直出。
剩下唯一的不确定是炸白的**帧数**，这个别猜：出片后跑 `02_画布/量白闪.py` 数一下，1 帧不动、2–3 帧接受、≥4 帧或没有才在原段里替换 1 帧白（不切段）。
另外 seedance 最短 4s：画布出 4s，掐头静帧成 3s 版——V1 剪 1.0s、V2 剪 0.6s、V3 剪 0.9s；V2 剪过 0.8s 会把眨眼吃掉。

## 6 验收（针对这套资产）

- [ ] 白发在画面里**是白的**（不是灰块），并且有边缘光
- [ ] 剑身能看出**冰晶半透**与内部霜纹，不只是白色发光条
- [ ] 护手的虹彩**只出现一处**，面积不超过画面 2%
- [ ] 暖金只出现在剑尖/刃口/瞳孔，出现在别处就是跑色
- [ ] 三条片的黑白灰关系一致（能拼成一组）
- [ ] 白闪 ≤1 次、≤2 帧；静帧段帧差 <3
- [ ] 无抖音号/水印/平台烧字；截图上的 TORSY 水印不得入画
- [ ] 9:16 版重构图（不能直接裁，斗笠与剑尖会被切）

## 7 缺口

1. **角色名与设定**：截图只够定"白发 + 白袍黑带 + 冰霜"，正脸结构、身高、配饰仍需立绘或三视图；
2. **武器形态**：蓄力/出鞘/大招时剑身是否变形（决定③能不能做"冰晶炸开"）；
3. **用途与画幅**：16:9 投放 / 9:16 抖音，决定重构图方案；
4. **是否要字**：这套画面建议无字，若品牌要求必须带字，位置留在左上留白；
5. 截图带 **TORSY-TORSY** 水印，只能当参考，不能进成片。
