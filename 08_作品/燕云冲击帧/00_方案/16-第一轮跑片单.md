## 第 1 步 · 01 组（4 张图）

跑 A0 / A1 / A2 / A5，**每组只留 1 张**。

**A2 是地基，只看三条**：

## 第 2 步 · 03 K1 + 04 E1（2 张图）

同时跑，各留 1 张。

**K1（起势）判据**：

- [ ] **剑尖出画右下**（画面里看不到端点）——这是最关键的一条
- [ ] 头顶被上缘切掉、右肩被右缘切掉
- [ ] 脸在右三分、眼半闭
- [ ] 只有一块白（左上）

**E1（尾帧）判据**：

- [ ] 和 K1 比，**只有手腕变了**（肩、头、身体几乎没动）
- [ ] 剑尖朝镜头、近大远小
- [ ] 没有变成"整个人刺出去"

> 这两张是整条片的地基。它们对了，视频才会"只动一点"。

---

## 第 3 步 · 05 V1（1 段视频，5s）

**判据（按顺序看）**：

1. [ ] **动作发生了**：剑尖确实往前送了一段
2. [ ] **动作不大**：没有挥砍、没有前冲、没有抬脚
3. [ ] **末帧 ≈ E1**：剑尖朝镜头、手腕翻到位
4. [ ] **没有变水墨/黑白**（一变说明它自己加戏了）

**三种失败与改法**：

| 现象 | 原因 | 改法 |
|---|---|---|
| 完全没动 | 首尾帧差太小（一掌在 5s 里太轻） | ① duration 改 4s；② 或 E1 的"一掌"改"一掌半" |
| 挥砍三下 | 提示词被"剑"带偏 | 负向再压：`挥砍、连续动作、身体前冲` |
| 变成水墨了 | 模型自己理解成"冲击帧" | 负向加 `水墨、黑白、画面变灰`，并把"实色"写进首句 |

## 第 4 步 · 06 I1（1 张图）

**判据**：

- [ ] 姿势和 E1 一致（姿势一变，后面白做）
- [ ] 脸在暗部、**只露一只眼**、不刻画五官
- [ ] 红只在剑尖一处，不超过 15%
- [ ] 墨有浓淡层次、纸纹可见（不是一片灰）

出来偏亮/偏灰 → 先跑 `调色匹配.py` 对齐参考，别急着重抽。

## 第 5 步 · 07 W1（1 段视频，4s）

**判据**：

- [ ] 墨在动（对照首末帧，差异放大后能看到结构边缘）
- [ ] 人物与剑**没有移动**
- [ ] 没有变回实色

**如果一动不动**：直接放弃 W，改用静帧 + 后期极缓推近（1.00→1.03）——效果差一点，但稳。

## 第 6 步 · 发给我的东西

这一轮只要 5 个文件（或把节点名告我，我按名字找）：

1. `K1` 成图
2. `E1` 成图
3. `V1` 视频
4. `I1` 成图
5. `W1` 视频（如果跑了）

我拿到后做**整条 3.2s**：

```
V 实色（掐到动作结束） → 1 帧白 → 墨凝 12 帧（墨凝.py，爆点用 I1 的剑尖）
→ I1 定格 1.5s（极缓推近）→ 渐暗 3 帧
```

并顺带测三样：白闪帧数、明暗分布（对比参考）、静态段占比。
