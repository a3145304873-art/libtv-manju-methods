# 18｜可复用管线：换角色/武器，出一组高光动作

> 2026-10-30 用户：*「我想的逻辑是，我们能够后续根据不同角色的武器，设计对应的动作，然后可以剪辑出他们的高光动作，比较帅气，参考我们的对照。」*
> 所以交付物不是一条片，是**三层可替换的模板**：动作库（按兵器）→ 出图模板 → 高光剪辑。
> 换角色只改「资产」和「动作库里的三行」。

---

## 1 三层结构

```
① 动作库        兵器 → 三个动作 → 发力点/前景构图/水墨爆点
② 出图模板      K 起势 / E 到位 / I 冲击帧 —— 每层只管一件事
③ 高光剪辑      选高光帧.py（自动找动作峰值）→ 白闪 → 墨凝 12 帧 → 定格 → 渐暗
```

**换角色的成本**：资产 7 张（A0–A6）+ K/E 6 张 + I 3 张 + V 3 条 + 一次剪辑。动作用动作库里现成的，不用重新想。

---

## 2 动作库（兵器 → 动作 → 构图）

| 兵器 | 动作 A | 动作 B | 动作 C | 发力点 | 前景构图（I 的夸张层） |
|---|---|---|---|---|---|
| **剑** | 刺 | 横斩 | 上挑 | 剑尖 | 剑尖直指观者 / 剑身横贯下 1/3 / 剑尖出画右上 |
| **刀** | 劈 | 撩 | 抹 | 刀锋前段 | 刀锋压向画面下缘 / 刀身斜向上 / 刀刃贴画面横切 |
| **枪** | 扎 | 崩 | 拦 | 枪尖 | 枪尖指观者 / 枪身横扫 / 枪杆竖挡前景 |
| **双刀** | 交叉斩 | 回旋斩 | 突刺 | 双刀交叉点 | 双刀成 X 压前景 / 一刀指观者 |
| **拳/掌** | 冲拳 | 肘击 | 推掌 | 拳锋/肘尖 | 拳头贴近镜头 / 肘尖朝画 / 掌风带墨 |
| **弓** | 拉满 | 撒放 | 转身射 | 箭头 | 弓弦与箭指观者 / 弓身斜切画面 |
| **扇** | 开扇切 | 合扇点 | 扇挡 | 扇缘 | 扇面占前景 / 扇骨指观者 |
| **鞭/软兵** | 甩 | 缠 | 抽 | 鞭梢 | 鞭梢出画 / 鞭身缠臂入前景 |

每条动作在出图时只要填三个值：**发力点**（I 的墨爆位置）、**K 的藏**（剑收哪）、**E 的送**（剑到哪）。

---

## 3 出图模板（每层只管一件事）

| 层 | 只管 | 不该写 |
|---|---|---|
| **K 起势** | 朝向（侧 3/4 / 背对 / 低头）、剑藏在哪、重心压哪条腿 | 前景、透视、留白、墨 |
| **E 到位** | 转正到哪、手臂伸到哪、剑指哪、重心压到哪 | 同上 |
| **I 冲击帧** | 三层景深、前景夸张透视、墨势方向、黑白高光 | 真实感、握法细节 |

**K/E 只挂「脸」一张参考**（A1）。挂全身图会把姿势拉回“站姿”，挂武器白底图会把剑拉成“横在腹前”——这一轮踩过。

---

## 4 高光剪辑（工具已就位）

```bash
python 02_画布/选高光帧.py --in V1.mp4 --fps 24 --out-dir frames
```

它输出：动作段起止、峰值帧、**高光帧（到位那一帧）**、定格帧，以及一条建议时间线。

实测（旧的 V1 刺）：4.04s 的片子里，动作只占 **1.29–1.96s**，高光帧在 **1.88s**（就是“剑尖指镜头”那一下）。

然后照时间线接：

```
0 → 1.29s   起势
1.29 → 1.88s 动作（可抽 1 帧加速）
1.88s       冻结 1 帧
+1 帧白 → 墨凝 12 帧（墨凝.py）→ I 定格 1.5s → 渐暗 3 帧
```

---

## 5 换一个新角色的三步

1. **资产**：把新角色的截图换掉 P1/P2，跑 A0–A6（同一套提示词，只改设定文字）；
2. **动作**：从动作库挑三个动作，填进 build 脚本的 `CONFIG`（动作名、发力点、K 藏哪、E 送哪）；
3. **出片**：K/E（1K）→ V（2.0-mini·frames·4s）→ I（黑白水墨）→ `选高光帧.py` + `墨凝.py` 剪。

一个角色约 **16 次生成**（7 资产 + 6 姿势 + 3 冲击帧）+ 3 条视频。

---

## 6 这一轮踩过的坑（写进模板的硬约束）

| 坑 | 约束 |
|---|---|
| K/E 挂全身图 → 姿势回退成站姿 | K/E **只挂脸**（A1） |
| 挂武器白底图 → 剑横在腹前 | 武器图只给 I 用，不给 K/E |
| 剑身发光 → 形状糊掉、看不出朝向 | 写“**不发光、只留一道冷白高光**” |
| 2.0-mini 用 `reference` 模式 → 首尾帧不生效 | 必须 `_reference_way: "frames"`，`reference_images: []` |
| 5 秒里动作被摊平 | 4 秒 + “0.5 秒打完” + 负向禁慢动作 |
| 实拍帧写“前景剑占 1/3” → 模型两头为难 | 夸张构图只写在 I，实拍只写身体与手 |

---

## 7 缺口

- **动作库只填了剑**（其他兵器是按常识推的，没验证）；
- 动作库里“K 藏哪 / E 送哪”目前是文字，还没做成 build 脚本能直接读的 JSON；
- 高光帧挑选对“连续两个动作”的片子会挑错（只取最大峰值），多动作要分段跑。
