# 燕云双页面设计与外部参考包（候选）

> 日期：2026-11-04｜状态：**候选参考包，待确认后逐帧学习**｜用途：在同一项目内规划两张独立的设计页/画布页，不写连续剧情。
>
> 用户目标：①通过冲击帧做角色帅气画面；②用大招展现恢弘画面。两页都以既有角色形象与藏音·龙跃霄汉为锚，重点修复大招不够恢弘、人物动作设计偏弱的问题。

## 先说判断：大招缺的不是更大的名词，是动作因果链

现行 8 秒方案用了“万剑、巨龙、天门、冰坑”等大奇观词，但旧版结果被记录为“四拍像四个风景镜头、命中无顿挫”。角色的脚步、腰胯转动、肩臂带剑、剑锋路径和命中反作用没有成为镜头主角，特效就会自己演完大招，人物只像站在场景里的触发器。

因此两页要分别解决两种阅读任务：

- **冲击帧页：**一眼看懂角色是谁、剑往哪走、定格在哪个帅气瞬间。把动作压缩成有张力的一击，不堆完整大招。
- **大招页：**先设计全身动作和兵器轨迹，再让剑气/阵法/龙形/环境变化沿这条轨迹发生。奇观规模来自“角色做了什么、世界因此怎么变”。

## 页面 A｜冲击帧：藏音一剑·角色高光

**页面目的**：做一条约 3 秒的角色帅气画面，主视觉是一张足够有力的持剑定格；前后运动只负责把观众带到这个定格。

**参考包（候选）**

- 主：用户先前提供的《道之极》与《拔剑》——结构、定格、明暗与人物/兵器构图；待恢复视频后核具体时间码。
- 辅：燕云剑招动作展示——校准角色真实握剑和重心；《剑之极》作为光/眼部进入画面的对照。
- 只学：一个动作的预备、击发、停顿；角色和剑如何占画；冲击后如何变成能读清的角色海报。

**页面骨架（设计草图，未确认）**

1. **起势**：3/4 身中近景，角色重心落在后腿，右手持剑贴身蓄势；剑身压在画面斜线，脸、手、剑至少两者同框。衣摆与发丝沿同一预备方向受风。
2. **击发**：一次清楚的踏步/转胯带动挥剑，剑锋走一条明确斜线；镜头不要同时乱摇、乱推、乱绕。剑气只在剑路后短暂出现。
3. **冲击定格**：以剑锋越过画面、角色肩胯反向制动的姿势停住；短闪/墨凝/冰裂选一个主手段。停顿后留清脸、手、剑的轮廓和武器颜色锚点。

**本页验收看点**：角色是否做出可读的身体动作；剑路是否一眼可追；定格是否“角色在发力”而非站姿换背景；脸、持剑手和剑是否保持一致；墨/光效是否遮住剑刃和脸。

## 页面 B｜大招：角色一剑打开天地

**页面目的**：约 8 秒展示一个完整大招事件。场面可以宏大，但必须让角色动作是视觉起因，剑锋路径是力量路线，撞击后的世界变化是结果。

**参考包（候选）**

- 主：燕云剑招动作展示——先拆角色和武器运动，不先写特效词。
- 辅：忌炎官方展示——学习角色与巨型龙形力量的尺度关系；《For Honor》幕后——学习招式排练和动作链规划。
- 辅：R02 的时间轴/分镜写法与现有四候选，只作为本项目候选结构；提示词截图没有生成证据，旧片/新版状态要先对齐。

**页面骨架（先动作、后奇观；设计草图，未确认）**

| 拍 | 角色与武器动作（主） | 画面/特效（跟随动作） | 需要观众看懂 |
|---|---|---|---|
| 蓄势 | 低重心、脚下扎稳；右手持剑回收到身体一侧，肩胯形成反向扭转；左手保持简单、稳定的姿势 | 近景从手/剑格抬到眼；霜沿剑脊聚集，环境风雪受力向剑侧偏 | 谁在出招，力量从哪来 |
| 蓄力展开 | 角色踏出一步并转胯，剑由回收位带到头顶/身侧；全身动作有明确起点与终点 | 地面阵纹/冰裂从脚下沿剑势方向扩张；镜头拉开交代人与场景尺度 | 剑势怎么把力量送出去 |
| 释放命中 | 一次完整的大幅挥斩/下劈；脚、腰、肩、肘、腕依次带动剑锋，剑路穿过明确空间并打到目标 | 剑气/剑阵/冰龙或墨龙只选一种作为主奇观，沿剑路高速冲出；命中采用短顿挫，镜头沉落回弹 | 角色确实出手、力量确实到达目标 |
| 收势结果 | 角色因惯性完成制动，剑尖落向明确位置；身体从发力姿态回到稳定姿态 | 雪浪/冰裂/墨痕按命中方向扩散，远景揭示尺度；尘雪延迟落下，最后回到角色 | 这一剑留下什么，角色如何收招 |

**大招验收看点**：动作在无特效白模/剪影下仍然成立；剑锋起点、轨迹、终点说得清；身体动作和剑运动同一拍发生；命中产生停顿与反作用；大场景跟随力量路线变化；远景不让角色完全失去辨识度。

**对现有四候选的建议**：先不同时重做四条。优先挑一条“招式能被身体动作承载、剑路容易读清”的候选做基准；万剑归宗、冰龙、天门或泼墨都只是力量形态。选定之后再将该形态绑到剑的动作轨迹和命中对象上。

### 合并后的两页工作顺序

1. **先锁资产与动作身份**：A1/A2 定角色外形比例，A5 定剑形；另写一张“角色动作档案”：准备姿态、重心支点、步法、腰胯/肩/臂带剑方式、剑路、制动与恢复姿态。每项都由本角色外形和藏音的重量/握法推导，不从外部范例照搬招式。
2. **先画角色与剑的运动路线**：标出脚下支点、重心移动、身体朝向、剑锋起点→弧线/斜线→目标/画面落点→收势点；相机路径单独画一条。动作参考只控制身体轨迹/发力，运镜参考只控制摄影机，角色图不负责替动作参考。
3. **冲击帧页先做动作闭环，再挑定格**：起势姿态 → 一次可见挥剑/突进 → 冲击点 → 有控制的收势；从这条动作里选最有张力的一帧做主视觉。镜头只帮助读清剑路，闪白/墨凝/冰光只选一个主爆点，不能拿特效替代动作。
4. **大招页先做白模/剪影动作，再接奇观**：蓄力支点与身器状态 → 身体转动带剑 → 剑路驱动唯一主奇观（剑阵、冰龙、巨剑/天象或水墨择一）→ 明确命中点 → 受力方向与场景变化 → 角色制动/收势。先证明这个动作本身成立，再按 I07 增加尺度、能量状态与环境余波。
5. **镜头按可读职责分配**：交代角色和路径、追随位移、看清剑锋/命中、揭示尺度结果。不要让同一镜同时负责环绕、猛推、拉远和震屏；接触瞬间不要用过近特写把剑锋和落点藏掉。
6. **失败时单变量返修**：人物没发力/动作被删，先改动作链；动作发生但看不清，改景别、机位或剪切；剑形/握法漂移，改资产锚点与参考职责；动作清楚但不够恢弘，再改空间尺度和特效层级。一次只改“动作 / 镜头 / 参考素材”一类，才能知道是否解决问题。
