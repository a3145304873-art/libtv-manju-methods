# 34｜手部持剑姿势规范（可判 · 可写 · 可验）

> 2026-11-04。起因：握法连续返工四轮。第一轮嫌措辞不够狠、第二轮发现参考没打开看、第三轮发现特写角度与目标角度不一致、第四轮发现**全身图里手只占 6% 画面高，根本画不出握持**。
> 结论：握法不是"写得够不够狠"的问题，是**先要有一套能看出来的判据，再要算清楚这个尺度上能不能画出来**。
> 关联：[25 握法规范](25-握法规范.md)（握法类型与条款）、[33 号 §7](33-关键帧四设计-静帧验证-v1.md)（本轮逐轮记录）。

## 1. 判据：一张图里"手是否真握着"看八条

每条都能直接看，不需要猜。括号里是它能排除的错法。

| # | 判据 | 合格的样子 | 不合格的样子 |
|---|---|---|---|
| 1 | **遮挡**（最关键） | 剑柄被四指压住，**剑柄的轮廓在指缝处断开**、看不见一条连续不断的柄 | 剑柄从手掌前面**完整穿过**、手像贴在柄后面；剑柄从掌心穿出 |
| 2 | **指尖绕到远侧** | 能看到——或至少看得出——四指指尖越过剑柄，落到柄的远侧 | 只有四个指团排在柄的近侧，指尖消失 |
| 3 | **柄两侧都露** | 拳的两边都能看到剑柄：剑格一侧约半个手宽，剑首一侧约一个手宽 | 柄只在一侧露，或两头都被手/袖吞掉 |
| 4 | **虎口的接触** | 虎口贴住剑格下沿，手掌与柄之间有接触阴影、不留缝 | 手掌整片贴在剑格上（握的是护手不是柄）；手掌与柄之间透光 |
| 5 | **拇指归属** | 拇指横压在中指第二指节上（手背朝镜头时只看见虎口鼓起，指尖被手挡住是正常的） | 拇指竖着翘起；拇指与四指同侧；完全没有拇指的隆起 |
| 6 | **指节成弧** | 四个指节排成一道弧（因为它们绕的是圆柱） | 四指并排成四条平行香肠、指节一条直线 |
| 7 | **腕不折** | 护腕轴线与剑柄轴线的夹角：共线握 <15°，自然握 25–40° | 夹角 >60°（折腕）；或剑柄与护腕走向完全无关 |
| 8 | **数量** | 一只持剑手（五指）+ 可选一只剑指手；画面内共两只手 | 三只手、两只右手叠握、六指、指头融合 |

**判定规则**：1、2、3 是"是否握住"的必要条件，缺一即判"没握住"；4–8 判"握得对不对"。

## 2. 尺度预算：多大才判得出（决定性变量）

这一条是本轮最贵的教训。同一段提示词，特写能成、全身必败，差别只在手的像素高度。

| 手占画面高 | 能验到哪几条 | 实际观感 | 结论 |
|---|---|---|---|
| **≥25%** | 1–8 全部可验 | 指节、指尖、指缝、接触阴影都能看清 | 握法可作验收项 |
| **12–20%** | 1、3、4 可验；2、6 勉强 | 读得出"握住了"，但指节细节糊 | 需要"前景＋柄两头露"辅助 |
| **6–10%** | 只有 3 勉强可验 | **只能读出"手在那儿"**，读不出握 | **不要在这一帧要求握法**，换景别或交插入镜 |
| **<6%** | 无 | 手是个形状 | 同上，且需检查手数（易多指） |

**实测对照**（本项目出图，目测估算，方法：拳的像素高 ÷ 画幅高）

| 图 | 手占画面高 | 表现 |
|---|---|---|
| 握法特写 G2 v4 | ≈39% | 八条里过 7 条（腕、指节、柄侧、遮挡都对） |
| K3 v1 半身水墨 | ≈14% | 过 1、3；2、6 糊；腕折 |
| K3′ 全身水墨 | ≈8% | 只过 3；手指成团 |
| K4′ 全身实色 | **≈6%** | 只过 3；**读作"手掌扶着剑格"** |

**推论**：全身景别（脚到头顶 ≈ 7.5 头身）里，手大约是画幅高的 1/11–1/13；要让手达到 12%，画面只能收到膝上；要到 25%，只能收到腰上或更近。**"全身入画"和"握法可读"在同一张 16:9 里互斥**——除非把手做成前景（近大远小）。

## 3. 提示词写法：把判据翻成句子

形容词一律不用（"握紧""用力握住""一条直线"）。只写能画出来的观察条件。

### 3.1 正向（按 1–8 顺序写）

```
【握持·遮挡】剑柄从拳心穿过，四指压在剑柄的**近侧**、指尖绕过剑柄到**远侧**；剑柄被手指压住，在指缝处断开，看不见一条连续不断的柄。
【握持·两侧】拳的两边都看得到剑柄：剑格一侧露出约半个手宽，剑首一侧露出约一个手宽。
【握持·虎口】虎口贴住剑格下沿，手掌与剑柄之间有接触阴影、不留缝；手掌不要贴在剑格上。
【握持·拇指】拇指横压在中指第二指节上；手背朝镜头时只看见虎口鼓起，拇指尖被手挡住是正常的。
【握持·指节】四个指节排成一道弧，因为它们绕的是圆柱；不要四条平行香肠。
【握持·腕】共线握：护腕的轴线正对剑尖，夹角小于15°。自然握：护腕与剑柄夹角25–40°，不许超过45°。
【握持·数量】画面里只有两只手：一只持剑，一只成剑指。
```

### 3.2 负向

```
手指平摊、手掌贴在剑格上、握着护手不是剑柄、剑柄从掌心穿过、剑柄在指缝处连续不断、
看不见剑柄、剑柄被袖口吞掉、四指并排成平行香肠、拇指竖起、折腕、三只手、两只右手、
双手同握一柄、六指、指头粘连、手悬空不接触剑柄
```

### 3.3 一条经验

「剑柄在指缝处断开」这句比"握紧"有效得多——它把"遮挡"这个**可见结果**写了出来，模型照着画就自然产生握的形态。

## 4. 两种握法的姿势参数（供选型）

| 参数 | 共线握（刺／前指／终结定格） | 自然握（持剑／蓄势／待机） |
|---|---|---|
| 臂—剑夹角 | <15°（护腕延长线穿过剑尖） | 25–40°（A6 实测 30–35°） |
| 手背朝向 | 侧向或朝上，取决于机位 | 朝镜头（A6 如此） |
| 拇指 | 屈压食指、被手挡住 | 同左 |
| 剑首位置 | 拳后、短而圆，不超过一手宽 | 同左，可略长 |
| 典型失败 | 画成握锤式（臂剑垂直） | 被写成共线，腕被迫折 |

选型规则：**先定动作类型，再定握法，最后才写句子**。反过来（先写"共线"再看动作）就是本轮三轮返工的来源。

## 6. 结论与下一步

1. **"握法成立"必须写明尺度前提**。以后一律写「手占画面高 X%，判据过几条」，不再写笼统的"握法成立"。
2. **全身帧不要承担握法验收**。全身 + 握法可读在 16:9 里互斥，只能三选一：
   - 收到膝上／腰上（手 15%–25%），牺牲脚；
   - 手做前景（近大远小），牺牲身体占比；
   - 全身帧只管动作与制动，握法交一张特写当插入镜。
3. **下一张图先报尺寸再动手**：画出构图后先算手占画面高，低于 12% 就不要指望握法，直接换方案。
