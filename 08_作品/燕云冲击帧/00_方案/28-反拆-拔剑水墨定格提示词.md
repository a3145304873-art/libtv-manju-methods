# 28｜反拆：这张图是用什么提示词生成的？

> 方法：先看画面里"有哪些现象"，再反推"要写出哪句话才会得到这个现象"。
> 反推出来的提示词不是唯一解，但它把**可复用的措辞**固定下来了——我们参照的就是这些措辞。

---

## 三、我们怎么参照（三条）

### ① 结构照搬：六段式

`风格句 → 角色 → 服装 → 武器与握法 → 构图 → 光影 → 负向`

我们之前缺的是：**"握法"单独成段**、**"剑不发光"写进正句**、**"纸白/近黑百分比"写进光影**。

### ② 措辞照搬（这几句是命门，别改）

| 必留措辞 | 作用 |
|---|---|
| 炭笔线条＋水墨块面混合 | 定"线墨分工"，防止整张糊墨 |
| 五官只用极少线条，各一笔 | 防止脸被画成写实 |
| 剑以纸白为主、浅灰渐变，一条暗线勾刃口 | 防止剑变成发光晶体 |
| 不发光、无任何光效（正句＋负向各一遍） | 同上 |
| 手轮廓完整、以明亮剑身为背景形成剪影 | 解决"手搭在剑上" |
| 两端都出画 / 跨度超过一条对角线 | 解决"剑太小" |
| 纸白约 12%、近黑约 23% | 解决"画面发虚" |

### ③ 只换两段：角色与武器

换人物 → 改「角色」「服装」两段；
换兵器（刀/枪）→ 改「武器与握法」一段，并套用 `26-兵器招式库` 里对应的握法条款。

其余（构图/光影/负向）**原样保留**，因为它们是这张图"高级"的来源，与人物无关。

## 四、与"我们之前写的"逐句对照

| 我们写的 | 反拆出来的 | 差别后果 |
|---|---|---|
| "黑白水墨冲击帧" | "炭笔线条＋水墨块面混合" | 前者→整张糊墨；后者→线墨分工 |
| "剑身晶莹、冷白高光" | "纸白为主、一条暗线勾刃口、不发光" | 前者→剑变光团，剪影丢失 |
| "持剑手占画面 12–15%" | "手占 8–10%、轮廓完整、亮底衬托" | 前者→手过大失真 |
| "留白两成五" | "纸白约 12%" | 前者→画面发虚 |
| "剑斜指画外" | "两端都出画、跨度超对角线、47°" | 前者→剑太小 |
| （没有握法段） | 独立「握法」段 | 前者→手不握 |
