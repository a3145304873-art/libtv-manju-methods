## 1 一句话结论：它不是"水墨写意"，是"线＋墨＋白"三分工

这张画最反直觉的地方：**该用线的地方全是线，该用墨的地方才是墨**。

| 区域 | 画法 | 占画面的墨量 |
|---|---|---|
| **脸** | **极少的几笔线**（眉、眼、鼻线、唇），**大面积纸白**，只有极淡的一点阴影 | 几乎为 0 |
| **斗笠** | **细线密排的竹编纹**（唯一"画得细"的地方） | 低 |
| **手** | **线＋一点灰**，手指轮廓清楚 | 低 |
| **剑身** | **大面积纸白 + 灰阶渐变 + 少量墨点**（最"干净"的区域） | 极低 |
| **头发** | **浓墨块 + 飞白丝**（块面为主） | 高 |
| **衣袍** | **排线 + 飞白 + 墨块**混合，白袍大面积留白 | 中 |
| **背景** | **泼墨块 + 墨点喷溅 + 干笔擦痕** | 高 |
| **腰带/扣件** | 细密暗部（唯一"重"的细节） | 中高 |

**推论：我之前写的"黑白水墨冲击帧"会被模型理解成"整张糊墨"**，于是脸和手全被墨吃掉——这正是握法看不清、脸不对的根因。

## 2 四处局部的具体观察

### A 手与剑格（这张最关键的局部）
- 手**确实握着**：四指从剑柄右侧绕过来，指节可见；
- 手**在剑格的近身一侧**，剑格（缠绳护手）在手指左侧；
- 手之所以看得清，是因为**手背后是亮的剑身**——靠"亮底暗手"的剪影关系，不是靠细节；
- 手在画面里只占宽约 **8%–10%**，但**轮廓完整**；
- 手腕向下偏右，**与前臂成直线**；剑穗的细绳从剑首垂下。

> 结论：手不需要大，需要**轮廓完整 + 亮底衬托**。我之前"手占 12–15%"反而过大了。

### B 脸与斗笠
- 斗笠**占画面上部近一半宽**，帽檐上翻，竹编纹用细线画出；
- 脸是**纸白**的，只有 5–6 笔线：两道眉、一条眼线（另一只被帽檐阴影吃掉）、鼻梁、唇线；
- 眼睛是**细长的、半垂的**，不瞪；
- 头发从帽下向左飘，**浓墨块 + 飞白丝**，方向一致（朝左）。

> 结论：脸靠"少"取胜。**不画五官细节，只给线的位置**。

### C 剑身中段
- 剑身**大面积留白**（不是发光，是纸白 + 浅灰渐变）；
- **一条清晰的暗线**勾出刃口；近端宽、远端窄，有明显**透视缩短**；
- 剑面上有**墨点与墨块**（喷溅感），还有横向的灰色锻纹；
- 剑身与画面约 **47°**，**两端都出画**（跨 121% 对角线）。

> 结论：剑是"白"的，不是"发光"的。发光会毁掉剪影。

### D 衣纹与袖
- 袖子是**排线（hatching）+ 飞白**，不是整块墨；
- 白袍大面积留白，只有边缘几道墨线；
- 腰带处有金属扣件，是全图最"重"的暗部；
- 下摆墨色渐变，越往下越重。

## 4 对提示词的六条直接结论

1. **分区写画法**，不要笼统写"水墨"：
   「脸与手用**细线**画、纸白为主；头发与背景用**墨块与飞白**；剑身**纸白＋灰阶**，只有少量墨点」；
2. **剑是白的，不许发光**——负向加 `发光、晶体、能量、光效`；
3. **手不必大**，但要「**轮廓完整、背后是亮剑身**」，写成"手背对镜头、四指绕柄、以亮剑身为背景"；
4. **脸只给线**：「眉、眼线、鼻梁、唇线各一笔，其余留白；一只眼被帽檐阴影遮住」；
5. **头发与衣摆方向一致**（这张全朝左）；
6. **背景是泼墨块＋墨点＋干笔擦痕**，不是"水墨晕染的背景墙"。
