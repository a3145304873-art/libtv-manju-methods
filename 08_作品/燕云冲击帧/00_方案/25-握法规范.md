# 25｜握剑规范（按武术与 HEMA 资料）

> 2026-11-03 用户指出生成图里握法有问题，要求找开源/他人分享的资料学习。

## 来源

| 来源 | 要点 |
|---|---|
| 太极剑持剑基本功（搜狐 a/348107525） | **钳把**：虎口靠近剑格，以食指、拇指与虎口的夹持劲钳住剑柄，其余三指自然附于剑柄 |
| 剑的正确把法（taiji.net.cn article-32232） | **压把**：拇指与食指掐握剑柄，**虎口贴附于剑格之上**，无名指与小指压在剑柄后端（防剑尖下垂） |
| 同上 | **正握**：手握剑柄，拇指屈压于食指第二指节；**剑与臂成一直线** |
| HEMA（swordfight.uk gripping-the-sword） | 前手贴护手，后手托剑首；**手腕始终伸直**，力量才能传递 |
| r/wma 入门 | “Always keep the wrists straight.” |

## 落成提示词的五条

1. **虎口紧贴剑格下沿**（不是握剑格、不是握剑身）；
2. **食指扣住剑格**形成支点，**拇指屈压于食指第二指节**；
3. 其余三指环握剑柄、**掌心留一点空**（不攥死）；
4. **剑与小臂成一条直线，手腕不许折**；
5. **剑身自拳头上方（拇指一侧）延伸出去**，绝不能从掌心穿出。

## 比例（为什么图里“没有剑柄”）

剑柄（含剑首）约占整把剑长度的 **1/5**；手宽约为柄长的 **1/3**；护手宽度约为柄长的 **2 倍**；剑身长度约为剑柄的 **4 倍**。

生成图里剑柄几乎不可见、剑从掌心长出，就是因为没写这条比例——模型把“巨剑”画成“从手里长出来的光”。

## 负向

`握在剑身上、剑从掌心穿出、手指穿过护手、剑格嵌进手掌、折腕、无剑柄`。

## 适用范围

K3 / K4 / E1 / E3 / E4 / I1 六个持剑帧；E2（眼睛特写，只有剑刃边缘）不需要握法；K2（纯光刃、无人）不需要。

## 补：为什么"藏手"会失败（2026-11-03）

第一版我写"持剑手在画面外／被剑身遮住"。结果是：**模型干脆不画手**，剑直接从袖口长出来，观感变成"人没握着剑"。

原因：**剑身贯满画面时，手只剩画面宽度 3%–5%**，模型画不出"绕柄的手指"，于是把接触点省略。

### 改成"前景握把"后要写死的五条

1. 持剑手在**画面右下角前景**，**手占画面高 12%–15%**（能看清手指）；
2. **剑柄横穿手心、两头都露在手外**（下端露剑首、上端露剑格）；
3. 四指可见地环握、拇指压在食指上；
4. 手臂从右下角伸入、袖口在手腕之外；
5. **剑柄不许被护手、剑身或衣袖盖住**；画不清楚就让手更靠近镜头。

一句话：**要让人看出"握"，手必须够大、柄必须露两头。**
