# 07｜三招：劈 / 砍 / 刺（同一人物同一武器，差在力的方向）

> 2026-10-30 用户提议：*「可以设计不同的动作，同样的人物和武器，可能不是不同姿势，比如劈砍刺什么的。」*
> 我的判断：**对，而且比"三种站位"更对**。理由和代价都写在下面，画布已按这个改（v6）。

---

## 1 为什么"动作"比"姿势"更适合做一组

冲击帧的差异感来自**力的方向**，不是人物站在哪儿。劈 / 砍 / 刺 正好是三个正交向量，每一个都自带一套构图语言：

| | 力向 | 画面主轴 | 冲击帧的速度线 | 爆点 |
|---|---|---|---|---|
| **劈** | ↓ 向下 | 垂直 | **垂直墨瀑**从上砸落 | 剑尖（画面下方中线） |
| **砍** | ↔ 横向 | 水平 | **横向墨痕**贯穿左右 | 剑尖（画面左侧） |
| **刺** | → 纵深 | 透视（近大远小） | **向心放射**，像浪扑向镜头 | 剑尖（中心偏左，贴近镜头） |

三个向量，三套爆点，三种红的落点——观众连着刷三条，不会觉得"同一条换了个角度"。
之前的 v4 三镜是"横指 / 上撩 / 直刺"，其实两条都是"指/刺"，向量撞车；换成劈砍刺才真正分开。

**顺带**：如果还想保留"拔剑"，最省的做法是把它做成"砍"的起势——**出鞘即横斩**，一刀就带出拔剑的意味，不用加第四镜。

---

## 2 代价（说清楚）

| 代价 | 具体 | 处理 |
|---|---|---|
| 劈要压低身体 | 之前定的纪律是"不弯腰不下蹲"（为了人物挺拔） | 放宽为**允许上身前倾 15°、膝微屈、重心下沉一档**；仍禁弓步/蹲下/脚离地 |
| 刺的透视难稳 | 4s 里模型很容易把"刺"画成"横着举剑" | 用近景＋剑尖朝镜头＋负向写死"剑身横贯画面" |
| 三招都容易加戏 | 模型爱给你砍三下 | 每镜负向都写"第二个招式 / 连续劈砍 / 不重复" |

## 3 三招明细

### ① 劈（中景全身，力 ↓）

| 段 | 内容 |
|---|---|
| 起势 K1 | 双手握剑、举过头顶右上方、剑尖朝后上；身体后倾蓄力 |
| 招式 V1 | 0.5–1.5s：剑沿中线向下劈落，划一条完整垂直弧线，到腰下停住；上身前倾 15°、膝微屈、重心下沉 |
| 定格 T1 | 剑停在身前下方、刃口朝下 |
| 冲击帧 I1 | 剑尖向下炸猩红墨爆；一道垂直墨瀑砸落当速度线；白发衣摆向前下甩 |
| 声音 | 举剑衣料 → 破空 → 触底闷响 |

### ② 砍（半身，力 ↔）

| 段 | 内容 |
|---|---|
| 起势 K2 | 剑收在右侧腰际、刃口朝外；上身右拧蓄力、左肩朝镜头 |
| 招式 V2 | 0.5–1.5s：从右向左横扫，划水平弧线，停在左前方与肩平；上身转正再向左多转 15° |
| 定格 T2 | 剑横在左前方、刃口朝外 |
| 冲击帧 I2 | 剑尖向左炸墨爆；一道横向墨痕贯穿画面；衣摆白发向左甩成飞白 |
| 声音 | 金属摩擦 → 横扫「唰」→ 收势轻响 |

### ③ 刺（近景，力 →）

| 段 | 内容 |
|---|---|
| 起势 K3 | 剑收右腰、剑尖朝前（朝镜头略偏左）；重心压后腿 |
| 招式 V3 | 0.5–1.5s：蹬后腿、拧腰、右臂直线贯出，剑沿纵深刺出，近大远小明显 |
| 定格 T3 | 剑尖最远、贴近镜头 |
| 冲击帧 I3 | 墨从剑尖向四周向心放射；剑身透视缩短；眼里一点纸白 |
| 声音 | 吸气 → 破空短促 → 钉住闷响 |

## 5 还没验证

1. 劈的"前倾＋下沉"会不会被模型做成蹲下/弓步（负向已写死，但要跑一条看）；
2. 刺的纵深透视在 4s 内稳不稳（最容易退化成横向举剑）；
3. 三条的定格帧够不够"不一样"——都用同一套光、同一个雪原，容易看起来像同一条的三个角度；必要时给三镜换天气（雪 / 风 / 暮）。
