## 结构 v2（组＝跑序，组内并行，组间连线即依赖）

```
00 上传与设定   P1 人物 · P2 武器 · S1 设定      ← 已预填同账号存储，可直接跑
01 起势首帧     K1 横剑前指 / K2 拔剑上撩 / K3 回身直刺   ← 这是招式**开始前**的姿势
02 定格水墨     I1 / I2 / I3                      ← 这是同一招式**结束**姿势的水墨版
03 视频 4s      V1 / V2 / V3                      ← first_frame＝K，把中间 1 秒的招式走完
04 制作说明     S0
```

模型：生图 `gpt-image-2`（**统一 1K / medium**，2026-10-30 用户指定）；视频 **`seedance-2.0-mini`**（最短 4s → 三条都按 4s 写；16:9 · 720p · `generate_audio: true` · 不挂音频引用）。
三条视频 prompt 实测 755 / 643 / 614 字（保持 <1200，给后续加描述留余量）。

## 导入后怎么跑

1. **00 组不用跑**。先看 P1/P2 是不是你这两张图（我核过 md5，是同一账号里的裁剪版）；
   不一致就直接把新图拖进节点替换，节点 ID 不变，下游引用不用改。
2. **01 整组跑**。三张首帧是三条片的构图地基——不满意的先重跑这一组，别急着往下。
3. **02 整组跑**。I1/I2/I3 是"视频尾部要变成的那张水墨画"，画风不统一就重跑。
4. **03 整组跑**。每段 4s（seedance 最短档），跑完逐段看；每段最多抽 2 条，不删旧 URL（留对比）。

## 剪辑三步（白闪先量再决定）

- 先剪头：V1 剪 1.0s、V2 剪 0.6s、V3 剪 0.9s → 成片 3.0–3.4s（静帧是蓄势；**V2 别剪过 0.8s**，会把眨眼吃掉）；
- **量白闪**：`python 量白闪.py <成片.mp4>` 数炸白几帧——1 帧不动 / 2–3 帧接受 / ≥4 帧或干脆没有炸白，才在原来那段里替换「1 帧白 + 1 帧负片」（不切段）；
- 三条之间用 2 帧黑硬接，不叠化。

## 改版纪律

- 换角色/武器：替换 P1/P2 → 同步改 K/I/V 九个节点提示词里的人物与武器描述（否则画风会分裂）；
- 改接线：只改 build 脚本再重跑，然后**必须**再跑 `检查画布接线.py`，有 ERROR 不交付；
- 改完在平台里关掉项目再重开，不要保存内存里的旧版。

## 已知限制

- 本画布是 **16:9 母版**；9:16 要重构图（人物与剑尖会出画），不是裁一刀能解决；
- seedance 最短 4s：写 3s 平台不会给，只会拉长或截断；要 3s 成片请剪头，不要改时长；
- 炸白的**帧数**由模型决定，不由我们决定——但可以先量再决定补不补，见 `量白闪.py`；
