### 迭代后加入的项目规则候选

大招分镜的释放格必须能看清完整身体发力与剑路；命中／收势格要同时读到角色制动和环境结果。纯远景若角色缩成不可辨认的小点，不能单独承担动作或结果镜头；应以前一格已读清动作、并在结果格保留可辨认角色为前提。特效必须从剑锋路线连续生长并命中明确目标。
