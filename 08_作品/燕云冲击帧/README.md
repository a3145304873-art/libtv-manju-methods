## 三招一句话（v7：刺 / 斩 / 撩）

1. **刺**（近景，力 →）：剑收右腰 → 蹬地拧腰纵深刺出 → 向心放射扑向镜头。
2. **斩**（中景，力 ↔）：收剑右腰蓄 → 横扫至左前方 → 横向墨痕贯穿画面。
3. **撩**（半身，力 ↗）：剑尖垂右下 → 斜向上撩至肩上 → 斜向墨痕向上炸开。
