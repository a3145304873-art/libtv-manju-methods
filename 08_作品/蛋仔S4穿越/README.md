## 一句话

一个玩了四年蛋仔的大二生，穿进自己入坑的 S4 赛季，成了全场唯一的"白模鹌鹑蛋"。他记得这个游戏之后三十个赛季的所有改动。

**他带着未来的版本，回到过去打现在的人。**
