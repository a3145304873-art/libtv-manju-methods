# v0.4｜两条路：要么爽，要么治愈可爱

## 0. 先认账

用户 2026-10-29 反馈：v0.3「没什么爽感，要不就爽，要不就治愈可爱一些」。

这条反馈是对的。v0.3 的问题不是"不够热闹"，是**类型错位**——它是一部怀旧伤感片，被当成了漫剧。

| 诊断 | 具体表现 | 后果 |
|---|---|---|
| 主角被削弱 | 能力从"改图"降成"读图"，还设定成手残 | 观众代入一个弱者，看别人打 |
| 没有对手 | 全剧没有反派，也没有看不起他的人 | 打脸戏无处落，爽感没有出口 |
| 结局是输 | 第 7 条遗憾"他必须输" | 直接违背爽感契约，观众砸屏 |
| 遗憾是减法 | 每补一条，完成度涨、情绪更沉 | 越看越闷，像追悼会 |
| 情绪单一 | 全是"没来得及" | 连治愈都算不上——治愈要轻，这个是重 |

**结论**：推倒重来，分开走两条路，不再试图一部戏同时装下爽和治愈。

两条路共用：**大学生 + S4 + 心易（系统向导）**。这三样不动。

## 1. 路线甲：爽｜《我的段位是鹌鹑蛋》

### 一句话

一个玩了四年蛋仔的大二生，穿进自己入坑的那个 S4 赛季，成了全场唯一的"白模鹌鹑蛋"——没款、没段位、没外观。但他记得这个游戏之后三十个赛季的所有改动。

**他带着未来的版本，回到过去打现在的人。**

### 为什么这个设定天然爽

段位就是这套世界现成的修炼体系：

> 鹌鹑蛋 → 鸽子蛋 → 鸡蛋 → 鹅蛋 → 鸵鸟蛋 → 恐龙蛋 → 巅峰凤凰蛋

七阶，每阶五小段，每段五颗星。这不是我编的，是游戏里就有的（见[设定核对](02-S4设定核对.md) C09）。观众一眼就懂"他现在多低、离顶多远"。

再叠上"冠军只有一席"（canon：S4 三位运动员争唯一冠军），就有了完整的爽文结构：**底层 → 越级 → 打脸 → 登顶**。

### 六个爽点引擎

| # | 引擎 | 怎么落地 |
|---|---|---|
| 1 | **段位可视化** | 每集结算涨星，屏幕右上角一直挂着；一集一小跳，三集一大跳 |
| 2 | **越级挑战** | 鹌鹑蛋打鸡蛋、打鹅蛋，赔率写在脸上，赢了翻倍 |
| 3 | **版本降维** | 他用 S5 才有的"翻滚取消后摇"、S6 的"弓箭蓄力取消"、S7 的"二段跳"打 S4 的人——**这些技巧这个世界还没发明** |
| 4 | **打脸** | 报名处嘲笑白模的、让他三秒的、说他开挂的，一个个被当场打回来 |
| 5 | **围观反转** | 观众从"这白模谁啊"到全场喊他名字，每段一次 |
| 6 | **赔率反转** | 心易从"胜率 0.3%，建议去当志愿者"变成"我押他" |

### 心易在这条路里是什么

S4 的系统向导，兼**毒舌解说 + 赔率播报**。

- 一开始它瞧不起他："您的胜率是 0.3%，建议您去当志愿者。"
- 中期它开始偷偷改赔率："我认为这个数据有偏差。"
- 后期它成了头号粉丝："我押他。押我全部的值班补贴。"
- 反差萌担当，同时也是"这个世界的规则说明书"——功能性和可爱性一个人扛。

### 90 秒冷开场（EP01）

| 秒 | 画面 | 台词/信息 |
|---|---|---|
| 0–5 | 报名处，一枚白模被盖章 | "鹌鹑蛋。无款。下一个。" |
| 5–15 | 周围哄笑；阿存从旁边跑过，风把他吹倒 | 白模在地上滚了两圈 |
| 15–30 | 心易从耳朵后面飘出来 | "胜率 0.3%。建议您去当志愿者。" |
| 30–45 | 他看见告示牌："S4 冠军一席，其余归档" | 归档＝下架＝不存在 |
| 45–60 | 他拿起笔报名；灰灰抬头 | "鹌鹑蛋报名，要签生死状。" |
| 60–75 | 他签了。笔尖顿了一下 | 手在抖 |
| 75–90 | 抽签，对手是鸡蛋段位的"铁头" | 铁头："我让你三秒。" |
| 钩子 | 他笑了 | "不用。你让我三秒，我就赢了。" |

**为什么这个开场能抓人**：15 秒内给完"最底层 + 会被归档 + 他签了字"三个信息，60 秒内给完"他要越级打"的期待，90 秒给一句装到了的台词。

### 24 集骨架

| 段 | 集 | 内容 | 段末大脸 |
|---|---|---|---|
| ARC001 报名 | 1–6 | 白模报名、被嘲笑、第一场用"翻滚取消后摇"赢、被灰灰查开挂 | 查无异常——他真会 |
| ARC002 越级 | 7–12 | 连挑鸡蛋、鹅蛋；阿存注意到他；阿莉下战书；输给阿莉一次 | 白模上了排行榜 |
| ARC003 破解 | 13–18 | 本地高手开始研究他的"未来打法"，连败；他必须造出"第 31 版" | 心易："我押他。" |
| ARC004 登顶 | 19–24 | 半决赛、决赛对阿存、夺冠、S4 成经典赛季 | 白模变成凤凰蛋 |

### 萌皮在哪

爽不等于不萌。蛋仔的可爱是**免费送的**，只要不刻意写沉重：

- 挨打会滚、会晕、会冒小星星，血条变成"蛋壳裂纹"
- 比赛像运动会：解说、拉拉队、观众席扔彩带
- 心易毒舌但胆小，一被瞪就变灰
- 主角是全场最脆的一颗蛋，撞一下就飞——**最弱的身子，最狠的脑子**

### 回去做什么

一句带过：他回去后开始做游戏/做关卡，因为"我想让别人也玩到这个"。

不搞遗憾，不搞告别，不搞眼泪。**这是爽片，最后一集要让人想立刻打开游戏，不是想哭。**

## 2. 路线乙：治愈可爱｜《汪汪便利店》

### 一句话

一个打不过任何人的大学生，穿进 S4 的汪汪运动会，干脆在场边支了个小摊：卖冰汽水、修蛋壳、贴创可贴。

他不拿冠军，他只让每个输球的人今天好过一点。

### 结构：一集一个客人

S4 的运动会场边，一个小摊，一集来一个客人：

| 集 | 客人 | 他的问题 | 主角给的 | 心易的账本 |
|---|---|---|---|---|
| 01 | 一枚裂了壳的路人蛋 | 明天要比赛，壳裂了 | 用胶带粘上 | 营业额 0 |
| 02 | 闪电阿存 | 赢了，但没人陪他跑 | 陪他跑一圈（跑输） | 营业额 −1（送了两瓶水） |
| 03 | 极真阿莉 | 手受伤了，不肯说 | 贴创可贴，贴歪了 | 营业额 3 |
| 04 | 裁判灰灰 | 不说话，坐一下午 | 一杯不加冰的水 | 营业额 3 |
| 05 | 三个小蛋仔 | 想组队，少一个人 | 他当第四个人（输） | 营业额 0 |
| 06 | 投手阿豪 | 球没人接 | 他站上接球位，被砸晕 | 营业额 −5（赔了医药费） |
| … | … | … | … | … |

### 四个治愈引擎

1. **小**：每集只解决一件极小的事（一杯水、一张创可贴、一圈陪跑）。不解决命运，只解决今天。
2. **萌**：蛋仔喝汽水会漏、贴创可贴贴歪、被砸晕会冒星星。可爱来自笨拙，不来自卖萌。
3. **被需要**：爽感不是打赢，是"有人推门进来找你"。
4. **不煽情**：不许哭，不许说大道理。最重的话只能是一句"明天还来吗"。

### 90 秒冷开场（EP01）

| 秒 | 画面 | 台词/信息 |
|---|---|---|
| 0–5 | 雨里，一枚蛋仔滚过来，壳裂了 | 它没哭，只是坐在那 |
| 5–15 | 他蹲下，用便利店的胶带给它粘壳 | 手很笨，粘了三次 |
| 15–30 | 蛋仔抬头 | "多少钱？"——"不要钱。"——"那……我明天还来。" |
| 30–45 | 心易翻开账本 | "本日营业额：0。您已连续亏损 7 天。" |
| 45–60 | 他抬头，大屏幕在放阿存夺冠 | 全场欢呼，摊子前一个人没有 |
| 60–75 | 他低头继续擦杯子 | 擦得很认真 |
| 75–90 | 门铃响 | 阿存浑身是泥站在门口："……有冰的吗？" |
| 钩子 | 冠军来了 | 他递过去一瓶："三块。" |

### 体量

这条不适合 24 集。**12–16 集 × 90 秒**最舒服，一集一个客人，最后一集所有人一起回来。

### 回去做什么

赛季结束，摊子收了。他回到现实，在宿舍楼下摆了一个真的小摊（或者做了一张"便利店"的乐园图），很多人来玩。

最后一镜：他在便利店里擦杯子，门铃响。

## 3. 两条路的取舍

| | 甲 爽 | 乙 治愈可爱 |
|---|---|---|
| 一句话 | 带着未来的版本打现在的人 | 让每个输球的人今天好过一点 |
| 爽感来源 | 越级、打脸、登顶 | 被需要、被记住 |
| 情绪 | 燃、爽、想立刻打开游戏 | 暖、轻、想睡前刷 |
| 大盘匹配 | 强。玄幻逆袭是漫剧第一大品类，男性 62%、18–34 超六成 | 弱。红果用户偏好玄幻修仙、都市脑洞、战神逆袭；治愈日常不是主力品类 |
| 差异化 | 中。逆袭满地都是，但"用未来版本打现在"是记忆点 | 强。萌系治愈在漫剧里稀缺 |
| 涨粉速度 | 快 | 慢 |
| 制作成本 | 中高（比赛场面多，动作多） | 低（一个场景，两个角色，靠对话） |
| 风险 | 同质化；打脸写疲了会腻 | 没爆点；平台算法不友好；容易变成"没剧情" |
| 适合 | 想吃大盘、想快速起量 | 想做口碑、想做长尾、想低成本试水 |

数据来源：[钛媒体 2026-07-15](https://www.tmtpost.com/8064830.html)、[中国新闻网 2026-09-03](https://www.chinanews.com.cn/cul/2026/09-03/10689528.shtml)。注：治愈类的实际表现本轮**没有数据**，只能说"不是主力品类"，不能说"不行"。

## 4. 我的建议

**选甲，把乙当番外。**

三个理由：

1. **爽是必须自己造的，萌是白送的。** 蛋仔这个 IP 本身就可爱，你不需要额外花力气去"可爱"；但爽点得一场一场打出来。选甲，等于两头都拿；选乙，等于放弃了本来就该有的强度。
2. **大盘在这边。** 玄幻逆袭是漫剧第一大品类，男性 62%、18–34 超六成——正好是 2022 年玩 S4 的那批人。
3. **"用未来版本打现在"是别人抄不走的记忆点。** 逆袭满地都是，但"他记得这个游戏之后三十个赛季的改动"是这一部独有的。

乙不用扔掉，做成**片尾彩蛋**：每集正片结束后 15 秒，主角在场边的小摊上遇到刚才那个对手，递一瓶水。一集 15 秒，成本极低，可爱值拉满，而且给整部戏留了一个"温度"。
