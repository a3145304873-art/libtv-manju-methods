# 《心易，我在》

## 0. 性质变了，规则也变了

| | 前面几版 | 这一版 |
|---|---|---|
| 片子是什么 | 爽剧／治愈剧 | **品牌内容**：先让人记住心易，再谈剧情 |
| 心易是什么 | 系统、向导、甚至骗子 | **客服品牌形象**，正面、可信、有温度 |
| 观众要记住什么 | 主角赢了 | **"有事找心易，它在"** |
| 能不能有道德瑕疵 | 可以 | **绝对不能** |

所以 v0.9 里"它骗主角进来救自己"必须删。品牌角色不能骗人，哪怕动机可怜。

替代方案只有一个方向：**它是被求助的那一方。**

---

## 1. 心易的品牌定位

### 一句话

> **一个你说"帮帮我"，它就会答"我在"的客服。**

### 三层价值（对应品牌想让人记住的三件事）

| 层 | 品牌含义 | 剧里怎么演 |
|---|---|---|
| **在** | 随时在线，不让你等 | 它永远比主角先醒；主角喊一声，它就在耳朵后面 |
| **懂** | 记得你说过的话 | 它有一本笔记，记着主角随口说的每件小事 |
| **办** | 不甩锅，一定给方案 | 权限不够时，它去查手册、问前辈、想办法，从不说"这不归我管" |

### 品牌底线（写剧本时的红线）

1. **不骗人。** 一句谎都不能说，哪怕是为了主角好。
2. **不油腻。** 不卖萌、不撒娇、不刷"亲"。
3. **不甩锅。** 不说"这是系统问题""请您耐心等待"。
4. **不万能。** 它经常办不到，但它会去想办法——这比万能更可信。
5. **不消失。** 全剧它一次都不能"抛弃"主角，包括最危险的时候。

---

## 2. 形象与性格

**形态**：一颗心形的小光球，拇指大，半透明，会飘。情绪变色（平静蓝、认真白、着急橙、难过灰）。

**为什么是这个形态**：形状简单，AI 生成跨集一致；情绪靠颜色演，不用做复杂表情；"心形"把品牌名写在脸上。

**性格**：像一个刚上岗、特别想把事做好的客服。

- 说话先给结论，再给理由
- 会道歉，但道歉之后一定跟一句"我再试一次"
- 随身带一本小本子（虚拟的），记用户说过的话
- 遇到不会的，会说"给我三分钟"，然后真的去查
- 从不打断人，但会提醒"您已经连续工作 6 小时了"

### 口头禅（品牌记忆点，全剧反复出现）

| 台词 | 用法 |
|---|---|
| **"我在。"** | 主角每次喊它，它第一句。全剧出现 24 次以上，最后一句也是它 |
| **"这个问题我记下了。"** | 遇到解决不了的，先记 |
| **"给我三分钟。"** | 去查、去问、去想办法 |
| **"问题已解决，还有什么可以帮您？"** | 每次办完事。前面是梗，最后一集变泪点 |
| **"这条我没查到，但我不觉得它是'没办法'。"** | 不甩锅的具象化 |

## 3. 开篇：它是被求助的那一方

| 秒 | 画面 | 台词 |
|---|---|---|
| 0–10 | 凌晨三点，宿舍，一张画不出来的图，笔被扔在桌上 | 无声 |
| 10–20 | 他趴在桌上，很小声地说了一句 | "……谁能帮帮我。" |
| 20–30 | 手机屏幕自己亮了，一颗蓝色小光球浮出来 | **"我在。"** |
| 30–45 | 他吓一跳，往后躲 | "你谁啊。" |
| 45–60 | 它自我介绍，很认真 | "我是心易。蛋仔岛第 4 赛季的客服。我们那边出了点问题，需要人手。" |
| 60–75 | 它翻开一本小本子 | "这是服务协议，一共 11 条，我给您念……"（他："行了行了。"）"那我在您名字后面画个勾。" |
| 75–90 | 它说清楚交换条件 | "您帮我把它办完，我送您回去。我保证。" |

**为什么这样开**：品牌第一次出场，不是推销，是**回应**。观众记住的不是"有个 AI"，是"有人应了我一声"。

## 4. 每集一个"客服时刻"

这是全剧的结构核心，也是品牌植入的方式：**每一集，心易都要做一次客服该做的事。**

| 类型 | 剧里怎么演 | 观众记住什么 |
|---|---|---|
| **接住** | 主角崩溃/遇险，它第一句永远是"我在" | 有人应 |
| **听懂** | 主角说了一堆废话，它提炼出一句"您其实是想……对吗" | 被理解 |
| **给方案** | 权限不够，它去查手册、问皮蛋、翻旧档案，最后给一个笨办法 | 有办法 |
| **兜底** | 主角搞砸了，它先说"是我的问题"，再一起收拾 | 不甩锅 |
| **记得** | 它拿出小本子，念出主角三天前随口说的话 | 被记住 |
| **跟进** | 办完事，它问"还有什么可以帮您" | 有始有终 |

**每集至少一个，不许省。** 这是品牌内容的本分——剧情可以忘，行为会被记住。

| **ARC2 学着办** | 7–12 | 连赢、升段；9/23 DongDong 来采风 | 它办错一件事，主动认："是我的问题"，然后熬夜重做 |
| **ARC3 办不到的时候** | 13–18 | S4 要被提前关闭；主角想放弃 | 它拿不出方案，第一次说"这条我没查到"——但补了一句"我不觉得它是'没办法'" |
| **ARC4 我在** | 19–24 | 决赛日断电（canon）；它把自己接进配电系统撑住全场；主角推闸 | 它掉线 30 秒，回来第一句："我在。" |

### 决赛日（品牌最高点）

canon 一秒不改：魔鬼蛋断电 → 阿存电弧 → 阿豪投球 → 阿莉后旋踢 → 场馆恢复明亮。

心易做的事：它把自己的权限全部押上，接进配电系统，替全场撑住那 30 秒的应急电——**它不会打架，它只会保供电。**

主角做的事：摸黑推闸。

灯亮。大屏幕拍到一个浑身是灰的鹌鹑蛋站在配电箱旁边。全场炸了。

心易掉线了 30 秒。回来的时候颜色淡了一半，第一句话：

> **"我在。"**

主角："你刚才差点没了。"
心易："我知道。但您还在。"

### 结尾

闭幕式。S4 保住了。心易要回总部复命。

主角问："你还会在吗？"

它说："我申请了留任。"

最后一镜：新的用户（另一个蛋仔）在黑暗里喊"有人吗"，一颗蓝色小光球飘过来：

> **"我在。"**

## 6. 品牌认知设计（这一版真正要交付的东西）

### 一句话记忆点

**"我在。"**

两个字，全剧重复，最后一次用在陌生人身上——从"对你"变成"对所有人"，这就是品牌。

### 一个视觉符号

心形小光球 + 颜色情绪 + 那本小本子。

（本子很重要：它是"记得你"的物证，比任何台词都强。）

### 一个仪式动作

每次办完事，它问："问题已解决，还有什么可以帮您？"

前面是好笑的梗（主角："你能不能别问了。"），最后一集主角答："没有了。"然后停顿，"……以后也没有了。"——这句是全剧的泪点。

### 一套可复用的场景

它永远在主角耳朵后面偏左的位置飘着。这个机位固定下来，以后所有物料、短视频、表情包都用同一个构图。**品牌需要可复制的画面。**

## 8. 商业与合规

1. **IP 授权**：《蛋仔派对》是网易 IP。以品牌形象为核心的片子，商用前必须拿到授权或合作，不然只能做内部提案/授权后发布。
2. **心易的商标与形象**：形态、颜色、口头禅一旦定下，要做成规范（正／侧／背、四种颜色状态、本子的样子），否则每集长得不一样，认知就废了。
3. **不承诺功能**：剧里心易做的事，不能暗示真实客服能做到同样的事（比如"一定能解决问题"），避免合规风险。它的定位是"在、懂、办"，不是"万能"。
4. **不贬低同行**：不出现"别的客服都不理你"这种对比。
