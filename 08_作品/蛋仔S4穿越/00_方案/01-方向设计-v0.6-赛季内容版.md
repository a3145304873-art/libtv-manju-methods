# 《第4赛季：外卡选手》

## 0. 认账

v0.5 的问题：把 S4 换成 S5、S6，一个字都不用改。那不叫"写 S4"，那叫"套了个蛋仔壳"。

S4 真正独有的东西，官方已经给全了：

- 一场**汪汪运动会**（不是冒险，是比赛：开幕式、赛程、奖牌榜、闭幕式）
- **三个天才争唯一一席**（官方原话："冠军的宝座只有一席，三方剑拔弩张"）
- **一块被魔鬼蛋偷走的奖牌**（官方唯一一段赛季小故事）
- **S3 的马戏乐园刚搬走**，原址建起汪汪运动场

这四样东西凑在一起，本来就是一个完整的故事。我前几版全绕过去了。

## 2. 新主线

### 一句话

大学生陈默穿越到刚竣工的汪汪运动场，正撞上魔鬼蛋偷奖牌，混乱中被记成了第四位选手。他要在一个自己打不过的运动会里，抢下唯一一席——因为那一席，是唯一能离开这座岛的东西。

### 三幕

**第一幕：误登记**
他落在工地，撞见偷奖牌（官方画面：断电、阿存的电弧照亮走廊、阿豪一球砸中、阿莉后旋踢）。混乱中报名册被风吹乱，灰灰按规程把他的名字填进了选手名单——"报名已生效，不得撤销"。

于是全场都知道：今年的运动会有第四个人。一个连款都没有的鹌鹑蛋。

**第二幕：三强与一个外卡**
三场比赛下来，他一场没赢过正面，却场场进前三。阿存开始把他当对手，阿莉开始研究他，阿豪开始给他递水。灰灰开始头疼。

观众开始喊他的名字。奖牌榜上，第四名的名字越来越靠上。

**第三幕：奖牌**
他查到偷奖牌的是魔鬼蛋——上一季马戏团的人。马戏乐园搬走了，他们没有项目、没有看台、没有名字，只能靠偷一块奖牌证明"我们来过"。

决赛那天，他把奖牌带回来了。不是抢回来的，是**换**回来的：他答应在闭幕式上，给他们留一个节目。

## 4. 爽点：钻运动会的规则

他打不过任何人。他赢在**运动会本身有规则，而规则有缝**。

心易是组委会系统，成天念规程。于是每集的结构就固定了：

> 心易念一条规则 → 他照着这条规则把对手玩了 → 心易崩溃"这不合理" → 灰灰判定"合规"

| 规则（心易念的） | 他怎么用 |
|---|---|
| "选手不得携带非组委会器材" | 那就不带，用场地——把对手引到会掉的地板 |
| "掉出场外判负" | 他从不主动撞人，只负责站到安全的位置，让别人自己冲出去 |
| "允许抱起队友" | 抱人原来是玩笑，他把队友抱起来当跳板、当盾、当移动奖杯架 |
| "比赛开始前不得越过起跑线" | 他不抢跑，他站在线后一步——枪响的瞬间他已经起速了 |
| "弃权需提前一局报备" | 他"弃权"一局，绕开最强的对手，进败者组刷分 |
| "得分以裁判判定为准" | 他去跟灰灰讲规则，把对手的得分讲没了 |

**这是运动会特有的爽：不是打赢，是赢在规则里。**

---

## 5. 三个对手，三种"必须赢"

| 人 | 他为什么必须赢 | 他怕什么 |
|---|---|---|
| **阿存** | 跑了四年，只有赢了才有人记得他跑过 | 没人陪他跑 |
| **阿莉** | 动作必须完美，因为所有人都在看 | 有人看见她不完美 |
| **阿豪** | 只要球投出去，总有人接 | 球掉在地上 |

主角是第四种：**他不必须赢，他只是想回家**。

这个反差是他最好用的地方——三个人都背着自己的命在跑，他一个人只想着回家，反而跑得最轻。

## 6. 结尾

决赛最后一棒，他和阿存并肩。

他赢了，但他把奖牌借给了魔鬼蛋——挂在闭幕式的舞台上，挂一天。

闭幕式上，马戏团的人在运动场中间翻了个跟头。全场鼓掌。

他站在出口，心易念完最后一条规程："本届运动会，闭幕。"

他回到现实，凌晨三点，屏幕上是没画完的图。

## 7. 和前一版比，改了什么

| | v0.5 | v0.6 |
|---|---|---|
| 世界 | 蛋仔岛，一场运动会（背景） | 汪汪运动会就是主线本身 |
| 目标 | 赢（模糊） | 抢那一席（唯一能离岛的东西） |
| 反派 | 没有 | 魔鬼蛋，有动机、有来处 |
| 悬念 | 无 | 奖牌在哪 |
| 心易 | 系统客服 | 组委会系统，念规程的 |
| 爽点来源 | 他玩过（meta 优势） | 规则缝（运动会特有） |

"他玩过"还在，但降成辅助——**他比 S4 的人多懂一点这个游戏，但真正让他赢的是他敢钻规则的空子。**
