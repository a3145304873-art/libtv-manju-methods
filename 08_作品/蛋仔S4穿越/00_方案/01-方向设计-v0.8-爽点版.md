# 《册子上没有我》

## 0. 认账：v0.7 错在哪

| 我写的 | 问题 |
|---|---|
| 高潮是"没人看见他推闸" | 这是文学，不是爽片。爽片要全场看见 |
| 主角"求被记录" | 被动。等别人写你的名字，不爽 |
| 心易只是"实习向导" | 背景板。它没有目标、没有冲突、没有用处 |

改三处：

1. **从"求被记住"改成"自己写下名字"**——主动才爽。
2. **从"没人看见"改成"全场看见"**——被看见才爽。
3. **给心易一个 KPI**——让它有私心，才不是道具。

---

## 1. 心易：一个怕扣绩效的实习向导

**它是本届运动会的登记系统，实习期，转正条件只有一条：零事故办完这届运动会。**

于是它和主角天然对立：

| | 心易 | 主角 |
|---|---|---|
| 要什么 | 别出事，让我转正 | 我要赢，我要被记住 |
| 怕什么 | 断电、奖牌丢、有人闹事 | 闭幕式一结束，等于没来过 |
| 手段 | 按规程办事 | 钻规程的空子 |

**它越怕出事，主角越惹事。** 这是全剧的喜剧引擎和冲突引擎。

### 它给主角的三样东西

1. **规程**——它背得出每一条。主角问"规程第几条说不能这么干"，它念，主角照着钻。它每次都被迫背书，然后被前辈皮蛋骂。
2. **数据**——它报段位、报赔率、报对手战绩。主角赢了，它的数据被打脸。这是全剧最稳定的爽点来源。
3. **登记权**——只有它能往册子上写名字。**这是最后一集的钥匙。**

### 它的弧光

从"按规程，您不该存在"，到"规程第 1025 条：特殊情况，由登记员补记"。

**第 1025 条是它自己编的。** 一个系统，第一次为了一个人改了规则。

### 皮蛋

官方岛上的向导（2022-09-22 公告：<蛋仔精灵>改名<皮蛋>）。它是心易的前辈，出场就念公告、打官腔、扣绩效，负责好笑，也负责"官方视角"。

## 2. 主角：主动，不是等着被画

**陈默**，建筑系大二，画图的手比跑步的腿快。蛋仔老玩家，手残。

落地姿势：从看台脚手架掉下来，砸翻报名处的墨水瓶，名字洇在册子上——**他自己爬起来的第一个动作，是把名字描清楚。**

这个动作就是全剧的题眼：**不等别人写，自己写。**

- 会什么：看图纸。场馆刚竣工（canon），他知道动线、闸门、配电箱在哪。
- 不会什么：跑不快、撞不过、段位最低。
- 赢在：**知道这场地是怎么盖起来的。**

## 3. 爽点结构

| 爽点 | 怎么给 | 频率 |
|---|---|---|
| **打脸** | 笑他"册子上没有你"的、让他三秒的、说他作弊的 | 每集一次 |
| **越级** | 鹌鹑蛋打鸡蛋、打鹅蛋，赔率写脸上 | 每三集一次 |
| **升段** | 屏幕角落的段位牌跳一下，从鹌鹑蛋一路到恐龙蛋 | 每三集一阶 |
| **钻规则** | 心易念条文 → 他照着钻 → 灰灰判"合规" → 心易崩溃 | 每集一次 |
| **全场喊名字** | 观众从嘲笑到喊他名字，每段一次 | 每段一次 |
| **数据打脸** | 心易报"胜率 0.3%"，赢了改口"更新：100%" | 每集一次 |

**一句话：他每一集都赢一次，而且赢得让人不服又没话说。**

### 决赛日：把"没人看见"改成"全场看见"

canon 一秒不改：

1. 魔鬼蛋混进场馆，切断电源，全场黑
2. 阿存跑起来，电弧照亮走廊
3. 阿豪一球砸中偷奖牌的魔鬼蛋
4. 阿莉一记后旋踢，把魔鬼蛋踢翻
5. 场馆恢复明亮

**第 5 步是他干的，而且这次被看见了。**

- 黑暗中所有人都在喊"电闸在哪"
- 他答："我知道。"（建筑系，他看过图纸）
- 他摸黑走到配电箱，推闸
- **灯亮的瞬间，大屏幕正好切到那个机位——全场看见一个浑身是灰的鹌鹑蛋，站在配电箱旁边**
- 阿存跑过他身边，电弧扫过他的脸
- 全场安静两秒，然后炸了

接着是连着的三个爽点：

1. **灰灰吹哨**："按规程，救场者记特别贡献，破格升段。"——段位牌从鸡蛋直接跳到恐龙蛋
2. **阿存夺冠**（canon），冲线后把金牌摘下来，挂在他脖子上，说"没有他，这馆还黑着"，然后拿回去
3. **闭幕式**：DongDong 的画被投上大屏，画里那个空框里，画了一个歪歪扭扭的小人。全场鼓掌

**最后一镜**：心易把登记册推给他，说"第 1025 条，特殊情况，由登记员补记"。他拿起笔，自己写。

## 6. 为什么这版爽

1. **每集都有一次赢**，而且赢在"他懂场地"，不是靠天赋。
2. **每集都有一次打脸**，被打脸的人各不相同。
3. **段位牌一直跳**，观众追的是那个数字。
4. **心易的数据一直被打脸**，它越不信，主角越赢。
5. **高潮是被看见**，不是被埋没。全场喊他名字，段位破格，阿存借他金牌。
6. **最后一笔他自己写**——不是等别人记住，是我自己签字。

爽点之外还留了一层：他最后写的不是"陈默"，是"第 1025 号"。因为**编号是他自己挣的，名字是别人起的**。
