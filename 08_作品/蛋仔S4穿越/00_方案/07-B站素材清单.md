## 2. 突破口：图文页能通

2026-10-29 找到一条绕路——**视频下不了，但文字能拿**：

| 资源 | 状态 | 方式 |
|---|---|---|
| 视频文件（m4s/mp4） | ❌ 407 | 所有 `*.bilivideo.com` / `*.hdslb.com` 被代理拦 |
| 图片／封面 | ❌ 407 | `i0.hdslb.com` 同样被拦 |
| YouTube | ❌ 407 | 整站不通 |
| `www.bilibili.com` 图文页 | ✅ 200 | **专栏/opus 全文明文可取** |
| `api.bilibili.com` | ✅ | 需先取 `buvid3` cookie，否则 412 |
| `comment.bilibili.com` 弹幕 | ✅ 200 | 直接取 XML |

**关键发现**：官方把赛季故事写在**专栏**里，而不是只放在视频里。所以"看不到视频"并不等于"拿不到故事"。

### 抓取方式（可复用）

```powershell
# 1. 取 buvid3（否则搜索接口 412）
#    GET https://api.bilibili.com/x/frontend/finger/spi
# 2. 搜索：x/web-interface/search/type?search_type=article&keyword=...
# 3. 专栏页：https://www.bilibili.com/read/mobile?id=<文章id>
#    会 302 到 https://www.bilibili.com/opus/<opusid>，正文在该页 HTML 里
```


- 系统代理：`http://webproxy05.go:9000`（IE 设置，已启用）

- 实测：`api.bilibili.com` **能通**；`upos-*.bilivideo.com`、`i0.hdslb.com`、`upos-hz-*` **全部 407**

**也就是说：能查，不能下。** 视频画面/音频一律取不到，只能拿 API 元数据。
